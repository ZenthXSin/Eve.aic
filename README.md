# Eve

为 Eve 重做的 TS 基座：一个极小的内核，其余全部是可以热换的插件，Eve
自己的主循环也是其中一个。完整设计见[设计文档](./docs/设计文档.md)。

## 现在有什么

当前是重做候选：内核、联网模型、独立 QQ
适配器/手机、原生脚本和持续意识流已接通；正式主程序的监督与上线组合仍在开发。

- 插件：每个插件一个 Deno
  worker，权限按清单授予，默认不能读环境变量、不能联网、不能读自己目录以外的文件。
- 依赖：插件只依赖契约，调用由内核转发；按依赖顺序启动、逆序停止，有环、缺依赖、版本不满足都拒绝启动。
- 生命周期：加载、启用、停止三段，登记的清理动作在停止时逆序执行。
- 换版：先过契约兼容与类型检查，再暂停调用、排空、拍快照、换
  worker。成功信号三段：就绪、健康探测通过、首批真实调用成功；没有真实流量时由内核探测确认。
- 回滚：任何一段失败或超时，回到旧版本并恢复快照；失败版本写下的状态另存，不丢弃。
- 状态提交：成功回执等待实际保存；写入失败传播给调用和停止。
- 幂等调用：显式带键的动作先落盘再执行，超时仍跟踪原动作，重启后复用结果或保留未知。
- 示例轮次循环：用于基座回归，完整成功轮次保存后可恢复；它有8次请求上限，失败输入不入完成历史，不能当正式意识流部署。

持续意识流候选已有持续循环、持久休息/提醒、预算观察和完整块的机械上下文保护，见
[持续意识流](./docs/持续意识流.md)。独立所有权仲裁与 QQ 出口检查见
[所有权交接](./docs/所有权交接.md)。双版本监督、意识流/命令出口令牌接线、便签、记忆、精确 token
计量和管理面板仍待开发；不能启动两个内核同时写同一业务目录。

联网模型插件现在支持 Chat Completions 与工具往返，私有组合目录按外部配置授予网络和密钥文件
访问权限；本地假模型仍保留作内核回归。传输行为与未贯通项见 [模型接入](./docs/模型接入.md)。

QQ 的独立 HTTP 传输组件已具备认证、身份读取与文字发送验证，现已接入适配器服务和手机插件。
消息缺少平台编号、发送超时或异步审核时保留未知，不自动重发。官方能力与未覆盖范围见
[QQ 接口核对](./docs/QQ接口核对.md)，不能把回环测试视为真实 QQ 上线。

手机已有按页浏览、长文展开与附件卡片接口，以及参考 qq-bridge 独立整理的 QQ 交流
提示词候选；提示词已接入意识流候选，真实表达效果尚未验收。参考源码、取舍和未验收项见
[QQ 交互参考](./docs/QQ交互参考.md)。主人已允许贯通后上线测试，发送范围只限私信；当前还未上线。

官方 C2C/群事件的事实投影和私有入站日志已支持落盘后去重、跨重启复用，以及损坏时保留原件
报错。发送组件也具备私信测试范围限制。WebSocket和通知查询已接通；意识流候选使用同一手机契约，见
[QQ 入站与私信测试](./docs/QQ入站与私信测试.md)。

独立接收器现在接上官方 WebSocket、持久恢复序号、心跳/退避和同目录排他锁；仍不运行模型或
发送消息。实现与验证边界见 [QQ 网关接收](./docs/QQ网关接收.md)，不能把接收就绪称为 Eve 上线。

发送动作账本现已能在网络前登记动作、保存实际回执并跨重启查询；结果未知的原动作不自动重发。
现已接手机、脚本与意识流候选，范围见 [QQ 发送回执](./docs/QQ发送回执.md)。

适配器可独立进程运行，手机 worker 通过本机受认证接口浏览和发送，原消息与发送回执可跨
重启继续定位。真实子进程贯通证据与未覆盖项见 [QQ 手机适配器服务](./docs/QQ手机适配器服务.md)。
正式主程序尚未上线；主人平台身份在私有配置中通过一次真实私聊短码绑定。最新屏幕的通知水位与实际展示范围须分别记录，此已读语义已在
Issue548 确认，接线尚未完成；上线私信通知尚未发出。

原生 `execute_script` 工具已接候选，默认异步、按当前契约检查类型；手机发送、任务查询与
动作回执能在脚本中使用。账本独立于插件回滚，强制终止后不重放原脚本。具体行为与未完成 能力见
[原生脚本与动作回执](./docs/原生脚本与动作回执.md)。持续意识流已有贯通候选，不作为已上线证明。

## 运行

需要 Deno 2。

```bash
deno task test    # 真实起 worker、换版、回滚，以及超时和保存失败回归
deno task demo    # 演示启动、轮次循环、一次成功换版、一次回滚
deno task check   # 类型检查
deno task test:qq # QQ HTTP 传输验证，只访问本机回环服务
```

## 目录

- `guardian/`：独立持久所有权仲裁，本候选尚未包含完整双版本监督。
- `kernel/`：内核。注册与依赖图、worker 监督、调用转发、状态与快照、换版与回滚。
- `sdk/`：插件作者面对的接口与共享手机屏幕渲染。
- `contracts/`：契约，只有类型，与实现分开。
- `plugins/`：插件实现。每个目录一份 `manifest.json` 和入口模块。
- `plugins/phone/`：手机 worker 与本机适配器客户端，按私有配置生成注册清单。
- `prompts/`：身份与 QQ 交互提示词，组合层接入持续意识流候选。
- `adapters/`：独立平台传输组件；QQ 不启动内核或模型，令牌模式使用共享出口协议与持久工具。
- `tests/`：测试与夹具插件。

## 持久化与恢复

状态怎么存、换版和回滚时发生什么、数据损坏时怎么处理，见[持久化与恢复](./docs/持久化与恢复.md)。原则是：失败不静默丢状态，损坏的数据不自动清空。
