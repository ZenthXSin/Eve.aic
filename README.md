# Eve.aic

用 Rust 构建可持续运行、可扩展、可演化的认知系统底座。

我们希望以现有 LLM 为基础，让模型、记忆、推理与工具围绕持续内部状态协作。先做好稳定的插件运行时，再逐步接入认知能力；内核负责运行与协作机制，具体能力通过公开接口组合和替换。

## 我们想实现什么

以下为未来方向，尚未实现：

- **认知与记忆**：持续认知状态、记忆、世界模型和推理。
- **人格与动机**：人格、内生驱动与自主目标。
- **学习与演化**：学习、能力形成、自我模型、元认知与自我改进。
- **插件生态**：在核心稳定后评估 WASM、独立进程插件、版本化协议、安装更新、沙箱与资源配额。

这些能力都以插件接入，保持定义层、实现层、组合层分离。详见[企划案](./docs/企划案.md)与[开发计划](./docs/开发计划.md)。

## 已实现功能

- **插件管理**：注册/卸载、SemVer 依赖校验、异步生命周期、逆序清理与失败回滚；隔离 panic。
- **协作能力**：同步事件广播、类型安全服务发现、停止后失效的 Context、权限声明检查。
- **状态与恢复**：内存和 JSON 文件后端、插件命名空间、独占锁与进程恢复。
- **任务扩展**：前后台、立即、延迟、定时、重复任务；自定义类型与调度、取消及退出确认。
- **日志与诊断**：结构化日志、过滤与内存记录；插件和任务查询、停止错误汇总。
- **宿主控制**：提交、查询和确认生命周期操作；取消等待仍继续收尾。
- **配置插件**：版本化普通配置、来源优先级、请求快照、备份与回滚；密钥库等安全配置在后续实现。
- **最小 LLM 工具闭环**：`eve-llm-api` 定义 Provider、上下文和工具契约，Runtime 支持 Mock 与 Responses Provider，完成模型请求、批量工具调用和最终回复；支持工具排序、并发上限、串行作用域、超时、协作式取消、权限与生命周期校验。
- **任务控制插件**：显式取消、完整代际标识、旧事件过滤、工具析构与保存收尾；失败不自动重跑。
- **消息关系插件**：可替换判断、多意图原文范围、明确命令重规划与澄清；副作用未知不重跑。
- **会话插件**：用户绑定、完整工具历史、同会话在途保护、跨进程恢复与中断记录；保存失败保留原状态，旧工具不自动重放。

## 运行与测试

需要 Rust 1.89+：

```bash
cargo run -p eve-runtime
cargo test --workspace
cargo run -p eve-runtime --example configuration
cargo run -p eve-runtime --example session_recovery -- <独立状态目录>
```

## 项目结构与边界

`plugin-api` 定义契约，`kernel` 实现能力，`example-plugins` 演示插件，`runtime` 装配验收。详见[文档中心](./docs/README.md)。

Responses 非流式文本/函数调用已通过真实验收，普通配置由插件提供。会话已通过本地多轮、HTTP 与进程恢复验收，见[会话恢复](./docs/会话恢复.md)。流式与工具进度已有本地验收，见[流式输出](./docs/streaming.md)。显式取消见[任务控制](./docs/任务控制.md)；明确命令判断与重规划见[消息关系](./docs/消息关系.md)。Jev、自然语言判断和 reasoning 续传后续实现。

当前支持单进程可信静态插件；权限检查不是沙箱。仅恢复字节状态，任务和服务由插件重建。退出时须显式停止并刷新日志。
