# 联系人备注与艾特

群聊与私信共用手机设备的备注和唯一短名索引：

```ts
await tools.phone.settings({
  conversationId: "qq:group:实际平台群编号",
  remark: "我的研究群",
  alias: "研究群",
});
return await tools.phone.history({ conversationId: "研究群" });
```

备注最多 128 个 Unicode 码点，允许重名。短名为 1 至 64 个码点，不含空白、控制字符、斜线或冒号；群与联系人之间也必须唯一。`alias:null` 移除。改名后旧短名失效，原始会话编号始终可用。冲突或无法解析时拒绝，不猜目的地。普通手机方法的顶层 `conversationId` 及消息 `handle.conversationId` 都接受当前短名，回执保留真实原始编号。

设置写入手机设备的独立事实日志，随手机 worker 或 Eve 换版不回滚；不写平台名称，不改变任何人的身份。会话列表、通知和历史中的 `conversation` 字段同时提供真实平台名称（若平台确实提供）、备注和短名。搜索可匹配本机备注、短名与平台名称；不会因此标记消息已读。

艾特根据平台事件的 ID、昵称和本会话已知发送者解析；名称缺失时保留 ID 并标记未解析。正文的 `body` 和 `phone.text` 始终保留原文与原偏移，`displayBody` 是增加名称的独立可读预览；替换后重新按 Unicode 码点应用 80/160 字符预算。`mentions` 保留原始 ID、名称是否解析及中间件补充的可信关系，Web 将名称和身份并列展示。

“主人”仅由手机中间件的 `ownerPlatformUserId` 可信配置映射，昵称、备注和正文里自称主人不提升身份。发件人的身份与正文提及的人是不同字段。没有平台群名时不拿群成员昵称冒充群名。
