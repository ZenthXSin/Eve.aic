# 环境与能力模型

环境模型把有来源的观测、执行前预测、执行后的独立工具回执放进同一条证据链，能力画像由这条证据链计算，不依据 Eve 自报“完成”增加成功次数

公开契约位于 `eve-cognition-api`，实现为 `eve-cognition-plugin::WorldModelPlugin`，宿主持有 `WorldModelController`，通过 `WorldModelAdmin` 写入。插件不发布管理服务、不装配模型工具、不执行实际操作，也不申请额外步数、工具权限或模型调用

## 观测与预测

`WorldObservation` 保存来源、可见范围、环境版本、证据摘要、观测时间和失效时间。用户提供的观测仍标记为 User，不能冒充工具回执。不同渠道可以归入同一宿主绑定用户，但用户绑定和权限校验由宿主完成

`WorldPrediction` 必须在执行开始前成功保存，冻结执行 ID、能力类别、环境摘要、引用观测、预计成功率和独立检查。环境摘要应包含模型、提示词、工具清单、配置单调修订及授权范围，不能只用模型名称。同一任务多项检查使用稳定的任务 ID 加检查序号分别登记，不能在结束后补选已成功的检查

引用观测必须在预测创建时有效，环境相同且预测不能扩大观测的可见范围。预测允许没有历史观测，这时不伪造证据来源。来源、正文、工具输出和能力类别的 Debug 均脱敏

## 独立结果与自身能力

`resolve` 接收真实执行产生的 `WorldReceipt`，自行匹配执行 ID、工具、完整参数摘要和执行前固定的 JSON 检查点。回执中的 `environment_sha256` 必须由宿主在取得回执时重新读取，环境变化归为 Inconclusive，不能把新环境结果计入旧画像。宿主必须绑定真实工具来源、时间和最后工具批次标记，不能把模型文本包装成回执

结果只有三种：工具成功且最终检查值一致是 Verified；具有有效最终检查值但与预期不一致是 Failed；缺少证据、工具失败、非最终批次、检查点缺失或回执超时是 Inconclusive。不确定结果不增加已知成功或失败次数，网络错误不会被误学成能力不足

能力画像按完整 `WorldScope` 独立聚合，包括环境版本、能力类别和可见范围。提供已验证成功数、已知失败数、不确定数、待结算数、Beta(1,1) 平滑成功率和预测误差。未知能力的平滑值为 50，不代表已获得半数成功证据；规划器应同时看样本数和误差，不能依据概率自动授权或突破原有预算

`reader(ReadAccess)` 由宿主绑定访问身份，读取时再指定当前环境。公共读者看不到用户或内部证据，不同用户不能互相读取；用户能力画像不混入公共统计。读接口返回独立 `WorldModelView`，只含预测、效果、回执摘要和结算时间，不返回完整工具输出，避免检查之外的字段随画像泄露。过期观测不再用于实时上下文，历史预测保留观测 ID 用于宿主回溯；只读视图不是可恢复快照，不能交给管理接口或完整账本验证器

## 持久化与恢复

状态独立保存在 `eve.world-model/world-model.v1`，包含格式版本、认知主体和修订号，不改变原 `CognitiveState` 的序列化格式。观测、预测和结算使用稳定 ID 幂等写入；重复相同内容不增加修订，复用 ID 换内容或改写已结算效果被拒绝

每次修改先复制、校验并编码，再持久化，最后替换内存。写入错误可能属于后端已提交但响应失败，此时整条管理和读句柄失效，必须重新装配后从磁盘读取，不能使用旧内存继续覆盖。启动严格拒绝重复 JSON 键、不支持的版本、主体不符、重复执行检查、非法引用和与回执重算不符的效果，不清空损坏文件

重启保留待结算预测，不自动重跑操作，不将中断视为成功或已知失败。宿主恢复时可用同一回执结算，无法确定的执行以空回执结算为 Inconclusive，结算后不可事后改判来抬高成绩

账本上限为 256 条观测与预测、4 MiB，并为未结算预测预留回执空间。达到上限拒绝新记录，不静默淘汰证据、不重置画像、不改变执行预算。容量处理应由宿主明确归档或更换受控存储实现，当前插件不提供隐式清空接口

## 当前边界

这是带版本和证据的有限环境／自身能力模型，不是任意世界状态模拟器。检查条件是否真正代表业务目标、宿主是否在执行前登记、工具回执是否可信仍由组合层保证。概率估计只描述已观察样本，不证明跨任务泛化；泛化需要另设未用于学习的验证任务
