# 依赖安全补丁

2026-10-27 将 Cargo.lock 中四项依赖更新到官方已修复的兼容补丁版本：rustls 0.23.46、rustls-webpki 0.103.16、tokio 1.53.3、ctutils 0.4.4。

覆盖 RUSTSEC-2026-0346、0347、0348、0349、0382、0385、0386，涉及 TLS 调试数据泄露、ECH 拒绝后数据发送、证书解压内存分配、密钥协商降级、证书校验、常量时间比较与异步文件描述符安全。这里只变更锁文件中的补丁版本，不改变应用数据格式。

按 OSV 官方接口重新扫描锁文件的全部 204 项 crates.io 依赖，此次没有返回已知漏洞。该结论仅覆盖所用数据库与版本信息，不代表应用没有业务逻辑漏洞；成员网络、网页访问、身份与审核另行修复和验收。官方条目可在 https://rustsec.org/advisories/ 按以上编号查询。
