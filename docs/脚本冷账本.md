# 脚本冷账本

脚本源码和 Succeeded/Failed 终态回执改为不可变内容寻址文件，保存到脚本状态目录的 blobs 子目录。内存和 ledger.json 保留版本身份、依赖、状态模式、活动版本、状态值、回执身份与状态索引；调用或诊断时按当前可信身份读取指定正文。公开 list 兼容完整返回，QQ 列表改用 summaries，不再把全部历史源码放进工具结果。

## 提交与恢复

冷文件先流式序列化、计算 SHA-256 并同步到磁盘，再原子替换账本索引。同名冷文件必须通过大小和摘要检查，损坏时保留并拒绝覆盖。发布未完成只可能留下未引用文件，不会激活插件或授权执行，不自动清理这些现场。

打开格式 1 时先核对原账本 checksum，生成冷文件、逐项验证来源与索引后，原子写成格式 2。旧程序不支持格式 2；回退旧二进制须恢复迁移前完整状态快照，不能只替换代码。备份需包含 ledger.json 和全部 blobs，单独复制索引不完整。

Running 与 Unknown 回执仍保留正文。重启只把 Running 改为 Unknown，不重新执行。人工核对 Unknown 后变为 Failed 并转冷；历史调用 ID 仍在索引中，不能再次启动同一调用。代码版本、调用身份、父调用和状态模式持续核对。启动会逐个读取冷文件验证，内存不会同时保留全部正文；缺块、篡改、大小不符、索引与正文不一致均拒绝。

## 容量与边界

账本索引与单个冷文件各不超过原 64 MiB 上限；历史版本数量上限仍为 256。冷文件累计磁盘占用仍会增长，不称为无限存储，也没有自动删除历史。活动状态、未确认回执、紧凑索引和本次调用读入正文仍占内存。文件系统写入错误不伪造成功；索引提交不确定时关闭句柄，重开核对。

## 验证

已有真实 Python/JavaScript/Rust 沙箱、固定版本热切换、状态迁移、取消、Unknown 恢复与调用链预算测试通过。追加格式 1 迁移、终态回执冷读取、跨身份拒绝、同 ID 不重放、正文篡改拒绝且保留原文件的回归测试。Windows 行为仍以对应 CI 为准；本地只验证 Linux。

## 精确读取源码

QQ 的 list_script_plugins 无参数只读摘要；传 version={script,digest} 读取指定不可变版本的完整 PublishedVersion，包括源码和声明。call_id 仍查询真实回执，两者互斥。工具只使用宿主当前会话身份，不接受请求指定其他用户；未知版本或冷文件校验失败直接报错，不回退到活动版。读取不执行脚本、不更改活动版本或状态，也不写账本。

适配层真实文件测试覆盖同名两版在重启后读取旧版、摘要不携带源码、跨会话及缺失身份拒绝、未知摘要拒绝和账本无写入。

## 进程锁生命周期

账本独占锁由成功打开的 Store 持有，最后一个 Arc 所有者释放时显式解锁，再关闭文件；打开后校验失败也同样释放。并行 fork/dup 暂时保留的描述符不能延长旧 Store 的所有权。仍有所有者时再次打开必须拒绝；新 Store 重新加锁后，旧继承描述符关闭不能解除新锁。锁文件不删除，未知回执及损坏账本规则保持，不添加加锁重试或绕过。
