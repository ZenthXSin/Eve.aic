# 回复时参考资料

QQ 宿主可以给对话装配只读的参考资料。模型回答问题时，用 `search_reference` 搜索，用 `read_reference` 按行读取原文，再引用“资料名/路径:行号”作答。这一项补上的是旧 Eve 的做法：答 Mindustry 问题前先翻源码，查不到就说没查到。

## 用法

```sh
eve-qqbot ... --reference mindustry=/src/Mindustry --reference arc=/src/Arc \
  --reference eve-portable=vendor/eve-portable-knowledge --max-tool-rounds 50
```

- `--reference 名称=目录`：可以重复，至多 8 份。名称只能用小写字母、数字和连字符。
- `--max-tool-rounds`：单轮回复至多几批工具调用，1 至 64，宿主默认 1，全功能体验用 50。用尽后模型仍要调用工具时，宿主不执行这一批，而是追加一条说明、不再提供工具，再请求一次，让模型只依据已有结果作答，并说明没查到的部分；模型仍坚持调用工具时，本轮才以“达到工具调用次数上限”失败。

[全功能体验](./QQ全功能体验.md)会按 v160.7 拉取以下源码，核对提交后装配：

| 资料名 | 内容 | 固定提交 |
| --- | --- | --- |
| `mindustry` | `core/src/`，以及英文、简体中文名称表（`bundle.properties`、`bundle_zh_CN.properties`） | `17012d61d9e4…` |
| `arc` | `arc-core/src/`，即 Mindustry v160.7 的 `gradle.properties` 固定的 Arc 版本 | `7445105cd268…` |
| `eve-portable` | 继承的 186 篇 Mindustry 资料，见[继承资料](./继承-eve-portable-资料.md) | 随仓库 |

## 结构

- **定义层** `eve-reference-api`：`ReferenceLibrary` 契约（列出资料、搜索、按行读取）、参数上限和路径规则。
- **实现层** `eve-reference-plugin`：
  - `LocalReferenceLibrary`：本地目录实现。
  - 两个对话工具。它们只依赖契约，可以换成其他资料库实现。
- **组合层** `eve-qqbot`：解析参数，启动时打开资料库并注册工具；`training-window.py` 和 `qqbot-full.yml` 传入资料目录。

## 语义与边界

- **只读、启动时固定**：资料在启动时一次读入内存，之后不跟随磁盘变化。不提供写入、执行或联网。
- **收录范围**：
  - 只收录常见文本扩展名：`java`、`kt`、`md`、`json`、`hjson`、`properties` 等。
  - 跳过以下内容：隐藏目录（含 `.git`）、符号链接、大于 1 MiB 的文件、非 UTF-8 文件。
  - 目录是 git 检出时，记录检出的提交，读取结果会带上提交号。
- **失败**：以下情况在连接 QQ 之前就拒绝启动，不会少装一份资料继续运行：
  - 目录不存在或不可读；
  - 资料里没有可检索的文本；
  - 名称重复；
  - 总量超过 40000 个文件或 128 MiB。
- **持久化**：不写状态，也没有需要恢复的数据。每次启动都从资料目录重新读取。
- **搜索**：
  - 不区分大小写的字面匹配，不支持正则。
  - 文件名命中排在前面；每个文件至多返回 8 行，一次至多返回 50 条。
  - 可以用 `root` 和 `path_prefix` 缩小范围。
- **读取**：每次至多 200 行、约 24 KiB，保留缩进，每行带行号。
- **不保证模型会查**：工具描述和 [AGENT.md](../AGENT.md) 都要求先查再答，但模型是否真的去查，以及查完是否如实引用，取决于模型本身。进程验收只能证明宿主执行了工具往返、结果真实可用。

## 验收

- `cargo test -p eve-reference-api -p eve-reference-plugin`：
  - 参数上限、路径规则。
  - 隐藏文件和二进制文件跳过。
  - 文件名命中优先、范围限定、截断。
  - 读取带行号并保留缩进。
  - 各类启动错误。
- `connectors/qqbot/test/reference_test.py`：真实 `eve-qqbot` 进程中：
  - 搜索→读取→作答三轮往返。
  - 继承资料可检索。
  - 未装配资料时不注册这两个工具。
  - 目录无效时拒绝启动。
- `cargo test --release -p eve-reference-plugin real -- --ignored`：设置 `EVE_REFERENCE_DIRS` 后，用真实检出核对耗时。在 Mindustry v160.7、Arc 和继承资料上的结果：
  - 加载约 30 ms。
  - 单次搜索 1 至 4 ms。
