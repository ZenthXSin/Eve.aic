# 热重载验收矩阵

本文件定义验收条件，不以接口存在代替通过。结果由对应真实测试和 CI 提供；未运行的平台不得标记为已验证。

| 场景 | 必须观察到的结果 |
| --- | --- |
| 无状态旧调用执行期间激活新版 | 旧调用返回旧版结果；新调用绑定新版；宿主进程不重启 |
| 有状态版本迁移 | 读取已确认的源 revision；转换在无外部工具的隔离环境内执行；提交时再次 CAS |
| 迁移期间源状态变化 | 拒绝提交候选迁移，不覆盖新源状态或当前活动版本 |
| 迁移异常、超时、坏 schema、取消 | 旧活动版本和已确认状态保持可用；记录实际失败而非成功 |
| 回退 | 显式选择旧代码及其版本状态；不重放消息、文件写入或其他外部效果 |
| Rust 插件编译 | 只编译独立插件；不重新编译 Eve；编译产物绑定源码、编译器、目标和选项 |
| Rust 恶意编译输入 | 无法通过 include、构建脚本或编译器参数读取宿主私密文件或运行宿主命令 |
| Rust 编译失败或产物篡改 | 不激活候选；旧插件仍可调用；损坏缓存不能复用 |
| 运行进程崩溃 | 宿主仍可服务；未确认效果为 Unknown；不自动重放外部调用 |
| 父子插件与嵌套依赖 | 共用剩余预算、期限、身份与取消信号，不能重领额度 |
| 容器权限 | 真实运行 UID 不为 0，无宿主 socket、凭据、网络与可写宿主目录 |
| 容器资源与宿主退出 | 有独立硬期限和资源限制；取消清理进程及本次临时资源 |
| 跨平台 | Windows/macOS 实际运行隔离验证；缺少运行环境时报告阻断，不用模拟 CLI 结果代替 |

## 状态切换的限制

无状态版本可独立并存。有状态迁移必须明确如何取得稳定快照，不能为了立即切换而复制正在变化的状态。若当前协议要求源版本静止，应明确报告等待或拒绝，不能宣称已经完成无缝切换。旧调用的迟到结果只能写回其绑定版本，不能覆盖新版状态。

## 本次独立审查关注点

- 容器后端不能在 Windows 自动回退到 root，也不能因宿主源文件属于 root 而让插件以 root 运行。
- 版本句柄与真正并发切换须分别验证：能够保存两个版本，不代表可以在旧调用执行时切换新调用。
- 最小失败包中的轨迹回放不能代替执行复现；复现后的相同退出码或协议阶段也不证明内部根因完全相同。
