# 统一主体、分层唤醒与模拟验收

本次开发不替换运行中的 Eve，不连接正式 QQ 账号，不部署。主体、记忆、脚本、任务与审核通过独立契约和组合层装配。现有会话记录保留原作用域，不能把所有群和私聊拼成一份公共上下文。

## 实际行为

主人可直接用自然语言授权自主探索，由模型调用 configure_subject_autonomy。宿主核验真实身份、原话证据并执行高影响行动审查，通过后保存有限目标和总步数授权。每半小时检查关注和任务，无需用户再次发消息；周期检查不刷新预算。支持以 Mindustry 为主、兼顾其他领域的候选目标。暂停只停止后续自主派发；已执行任务使用已有取消工具处理，不假称撤回已发生的操作。

主体账本记录多窗口任务、关注、优先事件和检查点。重启恢复已确认状态；未知外部副作用阻断，不把未知任务重建成新任务。普通 QQ 对话仍使用既有对话宿主，尚未改成全部通道都经主体租约排队的全局路由。

经验记忆分为当前会话、可信关联个人和经过验证的公共实践。每轮自动检索相关经验，模型可保存、纠正、撤销和归档当前会话草稿。公共实践只从宿主允许的真实验证产物提取，不把群聊原话或私聊内容自动发布出去。群最近消息窗口按真实消息 ID 和数据库序号截止，避免后来的消息挤走本轮所指内容。

进度正文由 LLM 根据事实生成。私聊可报告开始、关键节点和等待；群聊只保留开始、一次中间进度和结尾。必要追问不挤占普通进度节点，但仍使用通道额度。插入消息更新当前轮次，不自动终止内循环。文件先入队，只有取得平台消息 ID 才标记发送成功；query_file_delivery 可查询，Unknown 不自动重发。

## 脚本与热重载

save_script_plugin、activate_script_plugin、run_script_plugin 和 list_script_plugins 提供 Python/JavaScript 候选保存、显式版本切换、执行、预演和诊断。调用绑定不可变句柄，父子调用共用预算、身份、期限和取消信号。只有明确同步宿主叶子可以装配，不能绕工作流再次派发后台任务或子代理。

Linux 使用 bubblewrap、namespace 和 seccomp 隔离；缺少隔离能力时拒绝执行，其他系统不退回原生 exec。只声明工具名称不获得权限；宿主在实际操作前复核调用者权限。dry-run 检查声明、版本、隔离后端与工具权限，不执行脚本，因此不能验证只有运行时才能生成的具体参数。每个实际宿主调用仍检查参数与权限。

状态按版本保留，schema 改变必须提交显式 StateMigration，绑定源版本、revision 和转换后的状态。当前实现是可验证的迁移值，不是任意迁移函数执行器。回退代码选择旧状态快照，不承诺撤销消息、外部文件或数据库副作用。跨脚本临时目录归调用链，结束清理；成功产物单独保留。

## 审核、恢复和升级

审核输入单独保留压缩前最近六条真实用户正文；不能用模型转述代替。工具轨迹、命令和摘要有界；原话不能在总容量内完整容纳时拒绝，不静默裁剪。审核不能替代摘要一致性等确定性检查。

周期触发持久化轮次，不补跑遗漏周期。Blocked 任务仅在安全检查点、原剩余预算及原期限内接续，并共享已有恢复次数上限。失败查询包含阶段、已知/未知效果、剩余额度和隔离复现指引；尚不等同于自动复制所有外部现场的一键重放器。

升级候选使用内容寻址、不可变校验与有期限 lease，重复准备复用同一候选。应用前检查全量空闲及侧账本变化，停机后再次核验；失败启动有界回退。模型只审查计划和风险，不裁决字节摘要是否一致。

## 验收方式和边界

Rust 单元与集成测试覆盖状态机、权限、隔离、坏账本、未知结果和跨进程恢复。QQ 交互使用真实 Eve 可执行文件、本地模型 HTTP 替身和模拟桥接，断言真实宿主路径与回执；这不证明真实模型的口吻质量或 QQ 平台的在线可用性。

另使用真实 PostgreSQL 18 临时实例和 Mindustry v160.7 无头服务端验收，结束删除测试实例。Java 验证器从当前源码用 Java 21 编译成 target 17；本地结果不等同于 Gradle --release 17 API 约束验收。性能及完整 CI 结果以对应测试报告为准，不由功能测试推断。
