# 附件临时目录与每晚自检

生产附件目录为 `/var/lib/eve-workspace/tmp/attachments`，在 Eve 的已有文件工具和终端工作区内。QQ
自动接收附件后保存到该目录，完成后的本地路径可供 Eve 使用；下载回执单独保留在 QQ
私有数据目录中。图片自动下载不改变默认的同模型描述链路。

目录及完成文件应授予 Eve 的运行身份读写权限（当前 UID 996、GID 994），并确保 QQ
服务能够写入。不要把私人配置、凭据、消息或下载回执放在该临时目录内。

QQ 适配器的私有配置使用以下字段；未指定时自动下载到适配器数据目录下的
`tmp/attachments`。共享目录的父目录也须让 Eve 能够进入。

```json
{
  "qq": {
    "attachmentDownloads": {
      "temporaryDirectory": "/var/lib/eve-workspace/tmp/attachments",
      "identity": { "uid": 996, "gid": 994 },
      "maxBytes": 67108864
    }
  }
}
```

自动下载复用官方来源限制、30 秒超时及并发去重，单个附件默认最多 64
MiB。下载在消息持久化之后串行进行，不阻塞网关收消息；失败在屏幕显示，可由 Eve 显式重试。重启恢复最近
24 小时的未完成附件，不重新下载已有回执但已清理的文件。下载中的文件隔离在 `.inflight`
子目录，夜检跳过该目录。管理面板同步展示下载状态和本地路径。

实例私有配置可增加以下可选字段；升级器复制实例配置时会保留它：

```json
{
  "nightlySelfCheck": {
    "timeZone": "Asia/Tokyo",
    "hour": 3,
    "minute": 0,
    "attachmentDirectory": "/var/lib/eve-workspace/tmp/attachments"
  }
}
```

启用后，意识控制在 `mind/index.json` 持久保存下一次时间，每天当地 03:00
产生一条自检提醒。`mind.status`
返回下一次时间、时区及目录。重启继续原计划，升级交接保留计划；停机跨过多个夜晚时，只补最近一次提醒，避免连续唤醒。关闭该配置不再产生夜间提醒。未配置的实例保持原有行为。

提醒让 Eve 自己检查和清理，宿主调度器只发提醒，不删除文件。Eve
先把还需要的附件移到工作区其他目录，然后通过现有文件和终端工具清理超过 24
小时、已完成且未使用的普通附件文件。保留最近 24 小时的文件，跳过下载中、使用中、子目录、符号链接及
`.part` 文件，不递归清空整个 tmp。清理结果应按真实操作留一句简短自检记录。

清理后调用原附件的 `phone.download`
可以重新获取原件；自动预取不会把已清理的历史附件重新铺满目录。重新获取依赖平台原始 URL
仍然有效；回执存在不代表本地原件仍存在。
