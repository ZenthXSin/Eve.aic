# 自我便签与事项浮现

固定身份继续由主人维护。“关于我”是 Eve 自己写、自己改的普通版本便签；不进入系统前缀，不改变可信身份和权限。

用 `notes.create` 创建短名为 `关于我` 的便签，用 `notes.update` 编辑，来源按实际填写。正文最多 2000 token。生产使用已有分词服务的 `o200k_base`，这是明确的计数编码，未宣称与当前模型分词一致；没有分词服务时使用显式标注的 UTF-8 字节安全上界。超额返回实际计数与上限，整次写入拒绝，原件保留，不替她删改。旧版已有超额原件仍可用普通便签接口读取、精简，不自动截断挂入人格。

正文可以这样组织，下面只是示例，不自动写进她的资料：

```text
我喜欢观察细节，也愿意改变先前的看法。

## 最近想做的事
- [ ] 了解一颗星星
- [ ] 做一个自己用的小工具
- [x] 已经完成的事

## 其他
自己的偏好与经历。
```

另可创建短名为 `想弄明白的事` 的便签，每行一件事。两份内容都由她维护；删除条目或把清单勾为 `[x]` / `[X]` 后不再参与浮现。选择时去除相同原话的重复项，不替她改写措辞；回执保留便签永久 ID 和版本。

`return await tools.notes.self({idle:true})` 默认随机提供最多 3 条，`limit` 可选 1 至 10；没有足够条目时按实际条数返回，不编造。`idle:false` 只读取关于我，不翻出待办。自我便签索引按便签水位与回滚代际缓存，日常读取不调用模型、不追加执行事务。

真实模型请求会把当前关于我附在上下文末尾；只在无新通知、无待完成脚本、上次没有继续工具动作的空闲状态附上候选事项。她可挑选，也可不理。浮现不制造 QQ 消息、不触发外部执行；模型决定后才按正常工具流程行动。压缩工具的估算包含这部分末尾内容。候选版本写入的便签遵守现有回滚隔离，未确认偏好不会被回退后的版本当作已接受经历。
