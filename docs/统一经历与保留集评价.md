# 统一经历与保留集评价

本阶段复用交互记忆原始证据、归档、跨会话只读拼接和上下文装配，不复制用户正文到另一个无边界的知识库

## 跨通道连续性

`UnifiedMemoryPlugin` 提供独立 `eve.memory-unified` 状态命名空间，宿主持有的 `UnifiedMemoryController` 同时实现 `UnifiedMemoryAdmin` 与 `MemoryContinuityPolicy`。宿主先核验真实身份与来源用户授权，再写入带 `principal`、授权凭证引用的定向 source → target 绑定；名字相同、自称管理员、模型提议均不能创建绑定

一个授权只覆盖精确的来源和目标作用域，不推导反向或传递授权，不改变工具权限。`interactions=false` 只允许当前有效偏好，允许完整经历须显式设为 true。只接受跨通道绑定；QQ 同通道隐私边界继续由现有 QQ 策略负责。没有授权时新增插件不会扩展任何读取范围

同一作用域不能在历史中归属不同 principal。授权不可覆写，撤销追加新版本；恢复需新的授权 ID。每次读取重新检查撤销，已创建的读取句柄不缓存许可。旧快照或已经送入模型的上下文无法事后收回，下一轮重装配才体现撤销

沿用原记忆的已确认偏好及有效版本，归档原文通过完整快照读取。全局词法命中按分数选择，而不是让第一个来源耗尽全部名额。仍限制最多八个来源、三个命中和 8192 字节；达到来源上限明确标记截断，不声称完整检索了无限历史

## 独立保留集

`register_holdout` 在评估之前固定题目、目标、全部候选来源修订、授权修订与期望证据 ID。题目由可信宿主维护，管理能力不得提供给学习器。`evaluate` 调用实际只读 `MemoryContinuityFactory`，独立重新读取完整原始快照，核对保留集证据存在、命中的类型/版本/来源元信息以及摘录确为原文，再按真实返回证据计算 precision/recall 万分率，助手宣称成功不计分

同一保留集和实现版本只记录一次，重试返回原结果，不择优覆盖失败。实现版本由宿主绑定模型、提示词、索引和排序器的实际版本。授权或来源修订改变、召回失败、响应范围不符、题目与声明的学习输入精确重叠，都不能生成有效成绩。实际评价前后均核对来源和授权；持久化采用 CAS，竞争更新需重新开始

空答案题只有空召回记为完全正确。统计单位为去重后的 `(scope, evidence_id)`，同一交互的用户和助手字段不会重复加分。该指标仅表示固定语料上的召回效果，不表示 AGI 或广泛任务成功率

精确污染排除只忽略大小写和空白，不能证明语义上没有相似训练题；宿主必须真实维护训练输入来源与独立保留集。当前同步评价入口用于跨通道统一策略，传入的 recall 必须以同一 controller 为授权策略；QQ 组合策略增加额外来源时会判定响应范围不符，不能偷偷扩大保留集

## 持久化与恢复

`unified.v1` 保存授权历史、固定保留集与逐版本评价。最多共 256 条记录、4 MiB；每个有效授权预留一条撤销记录及其序列化字节空间，容量满时仍可撤销；满时拒绝新增并保留旧数据，不自动删掉不利评价或撤销历史。JSON 重复键、未知字段、版本不支持、非法历史均拒绝启动，不清空文件

变更先复制校验，再持久化，成功后才替换内存。写入失败可能已经提交，因此关闭当前实例，重新打开确认存储结果，不能继续在旧修订上写入。纯召回评估不调用模型或工具、不写入原始记忆；计算中进程中止没有外部副作用，重新调用可计算尚未保存的结果

此变更只在开发树实现；验证结果以当前集成报告为准，不代表已部署到运行版

## QQ 自然语言定向共享

`manage_memory_sharing` 是受限宿主网关，不把 UnifiedMemoryAdmin 直接交给模型。list 只枚举当前平台身份、既有主人绑定或显式身份组已经核对为同一人的 QQ 来源，返回不含正文的句柄及群聊/私聊类型；每页最多 32 项，可用 offset 翻页。grant 的目标固定为当前窗口，不能传任意用户、principal、目标 scope 或身份绑定。平台群/私聊标识不能互认时，仍需已有可信身份绑定，不根据昵称合并。

授权分为偏好和包含原始交流两档，方向固定且不传递。新授权必须经独立审核：宿主最近六条用户正文完整交付，附真实来源与目标场景；没有原话、审查器不可用、授权不足、委托执行、取消或审核期间身份变化均拒绝。相同有效授权重复提交不增加记录；降低共享范围须先撤销旧的较宽授权。回执只说明后续上下文可读取，不伪造已经召回或发送。

撤销只影响该显式授权，既有宿主自动同人偏好/隐私策略独立生效；不删除原文，不撤回已发送消息。每次读取再次核对实时身份绑定及撤销历史，身份组、主人绑定或总开关变化会影响可见性。跨非 QQ 通道仍由可信宿主单独认证与装配，本工具不代办任意通道身份。

同通道不同窗口的显式授权写入统一账本格式 2；旧的纯跨通道账本继续保持格式 1。新代码兼容两者，旧程序遇格式 2 必须停止，回退须使用匹配的状态快照。授权历史、预留撤销容量、来源和保留集隔离继续保持。
