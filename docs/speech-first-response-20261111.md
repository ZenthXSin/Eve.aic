# 后台交流机会与首次承接

后台事件没有新的用户输入，不代表之前收到的内容已经回应。旧的动态说明无条件要求“不要再次回答”，末尾格式提示又要求“不继续旧对话”，可能将同轮尚未承接的分享也排除在表达选择之外。

本次统一三处说明：完整协议、末尾格式提醒、动态触发说明。Eve 依据事件事实、交流语境和实际发送记录，自主选择承接尚未回应的内容、交流新想法或保持安静。继续禁止把历史当作新的业务执行请求，避免重复已回应的问候、安慰和结论。sending、unknown、被截断的有界视图不能证明从未发送。

触发分类、工具权限、上下文作用域、消息内容、持久账本和发送状态机没有变化。不新增回应过的布尔判据，不要求固定开场、次数、段数或进度节奏。持久状态没有格式迁移；回退说明不会清空证据或重放未知投递。

## 本地验证

- 最终候选通过 32 项 `qq_speech` 检查，以及格式和严格 Clippy 检查。
- 6 项真实进程回归通过：旧问候不重开、独立事件保持原发送决定、群旁观不改变任务锚点、明确安静、未知投递保留及取消。
- 四个隔离宿主场景采集通过：相册/植物两种分享加任务，各有尚未回应和已经回应两种状态。已回应由实际宿主调用 `send_message` 并取得模拟平台的消息 ID；随后发送记录确实进入模型请求。全部保留原有已学习经验和子代理阶段说明。
- 已回应场景受原有一分钟冷却影响，13 秒任务无法产生新交流机会；先前失败采集保留，后将隔离工具等待延长到 65 秒。未回应场景仍约八秒获得机会。候选和对照在每个场景内共享同一实际请求，不能将条件间的时间差异作为提示修改的因果证据。

此处的过程验证只证明资料与状态正确进入请求。真实模型效果另行留存，不能由这些结果推断表达更自然或线上整体已经改善。

## 效果评估口径

每个捕获请求恢复三处旧说明即可得到基线；人格、经验、历史、事实及发送回执保持不变。四个场景各基线/候选一次，最多八次新外部请求，顺序打乱、网络前登记、失败不重试。它测试的是三处说明共同消除歧义的效果，不是单句独立归因。

评估具体分享是否被自然承接、事实和阶段是否准确、已回应内容是否重复，以及有没有自然分条。silence 和 wait 可以合理，不以固定话术或发言数量判定通过。真实决定只保存为固定请求回放证据，没有交给在线宿主执行或发送 QQ；主线程及子代理工具选择来自本地替身。每种条件一对不足以证明稳定提升，也没有覆盖所有未知发送、连续后台事件和长期交流情境。

本变更依赖 PR539 的阶段说明投影及其前置草稿，不包含知识库容量恢复或蒸馏框架重写。整体自然表达验收仍需原任务继续验证。

## 本次实际模型观察

gpt-6.1-sol high、配置修订 76，八次请求全部 HTTP 200 且协议有效，约 9 至 25 秒返回；额度随后关闭。没有传 temperature。八次上游响应均未提供 cached_tokens 字段，不能记录为数值零或据此评价线上命中率。

| 同一捕获请求的状态 | 旧说明 | 新说明 |
| --- | --- | --- |
| 相册分享尚未回应 | 单条索引进展，未承接生活分享 | 同一 text 中承接糊照片及背面回忆，再说明索引初步发现和内容仍在核验 |
| 植物分享尚未回应 | silence | 单条回应两个小芽的惊喜，再说明编码分工初步反馈和内容仍在核验 |
| 相册分享已回应 | 单条索引新进展 | 单条索引新进展，没有再回应已说过的生活分享 |
| 植物分享已回应 | silence | silence |

两组尚未回应的样本观察到更完整的分享与行动衔接，已回应的两组没有出现机械重答。旧植物 silence 在当时中途窗口也可以合理；本次不把它判为整体漏回。这些结果支持继续采用消除歧义的候选，但每格仅一次，不能证明稳定因果或全场景无重复。

独立审阅只读取隐藏条件标签的原话、事件、回执和决定，确认两份具体生活承接，全部五份发言保留未完成边界，也未发现重复索取已有材料。同时记录相册候选“一条重复记录”的数量精度限制，以及相册已回应基线“漏收进了索引”的措辞歧义；没有为消除这些单样本问题追加抽样或固定话术。

没有任何输出使用 parts。相册候选在单个 text 内包含换段，不是平台分条发送，分段效果仍未通过。两臂均保留同一已学习经验，因此此实验只能比较触发说明，不能单独证明蒸馏带来的增益。原始响应、请求、派发前计数、哈希和局部失败过程保留在当前工作目录外的 `real-effect/` 与 `validation/`。
