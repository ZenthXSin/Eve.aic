# 管理员绑定与默认权限

宿主通过 `EVE_ADMIN_BIND_KEY` 配置绑定密钥，不使用命令行参数，不将密钥交给模型。`/bind 密钥` 校验成功后绑定当前可信 QQ 平台身份；`/admin` 直接查询宿主判定，不请求模型。应在私聊发送密钥；如需群内身份授权，需在受信群中分别绑定。宿主只能脱敏自己的记录，不能删除 QQ 平台已显示的群消息。

绑定标识为 SHA-256(AppID, c2c/group, 平台发送者 OpenID)，不包含群目标，因此同一群聊平台身份可跨群使用。QQ 私聊与群聊的 OpenID 属于不同命名空间，不能凭昵称、QQ 号文字、自称或字符串相同自动合并；两种身份分别绑定。旧配置 operators 的会话标识继续有效。

原有 operators 绑定 SHA-256(AppID, 范围, 目标, 发送者)，同一个人换群即产生另一个会话标识。这解释了已配置管理员有时无法识别的一个原因。当前模型上下文会获得宿主确认的 administrator 布尔值；实际操作仍由后端校验。重启后已绑定身份在下一次可信平台消息到达时重新关联。

开发配置 `ordinary_access` 默认为 true，可显式设为 false 恢复仅管理员模式。工具仍需配置装配，不会凭空注册命令或 GitHub 凭据。

| 操作 | 普通用户默认权限 |
| --- | --- |
| 非敏感工作区文件读取、目录列表、文本搜索 | 允许，原路径边界与符号链接限制保留；搜索跳过敏感路径 |
| 非敏感工作区文件创建、精确替换 | 允许，仍需 SHA 校验，不覆盖外部变化 |
| 隐藏路径、AGENT/AGENTS、Cargo 清单、名称包含 config/secret/credential、.pem/.key 文件 | 读取或修改需管理员 |
| GitHub GET | 允许，原资源白名单仍生效 |
| 授权写仓库创建 Issue、PR、Issue 评论 | 允许，仍需已配置凭据与仓库授权 |
| 命令执行、自升级、GitHub 其他写操作 | 需要管理员 |
| 当前会话时间、消息、后台任务触发器及短暂等待 | 允许，不能跨用户操作 |
| 文件触发器 | 在已配置工作目录内允许，仅读取摘要 |
| 进程状态触发器 | 已装配命令能力时允许，只观察运行状态，不执行命令 |

绑定写入状态目录 `admin-bindings.json`，仅保存版本和平台身份摘要，不保存密钥。写入临时文件、同步后原子替换，最后才更新内存；读取损坏、版本错误或写入不确定时显式失败，不清空或自动重试。绑定容量 256，每个平台身份每分钟最多 5 次尝试。绑定密钥轮换不撤销已有绑定；撤销需要宿主管理员修改绑定文件并重启。

`/bind` 原文只保留于处理命令所需的短暂内存中；持久回执使用 `/bind [已隐藏]`，不传给参与者观察器、训练、记忆或模型，重启后不重放。后端使用公开 DeveloperAuthorization 契约，便于替换其他身份系统。
