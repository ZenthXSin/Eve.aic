# 清空会话上下文

QQ 提供两个无参数工具，由 Eve 在用户明确要求重新开始时调用：

| 工具 | 权限与范围 |
| --- | --- |
| `clear_context` | 所有真实用户可用，只清空当前群或私聊中该发送者自己的会话上下文，不影响同群其他人或该用户的其他会话 |
| `clear_all_contexts` | 仅主人或管理员可用，清空所有现有会话上下文，包括内部插话会话 |

目标由工具调用的可信平台身份确定，不接受用户 ID、会话 ID 或模型声称的管理员身份。后台任务、子代理和群观察身份不提供这两个工具。调用成功后 Eve 简短告知并结束本轮；清空从下一轮开始生效，不中断正在执行的工具或任务。

## 持久化与恢复

清空会记录各会话当时最后一个轮次 ID 作为上下文边界，包含正在执行的轮次。之后开始的新轮次只加载边界之后的完整历史；既有摘要必须匹配新历史前缀才可复用，不会把旧对话摘要重新塞回来。已经开始的请求保持其已有上下文，完成后也不会使旧历史越过边界。

原始会话记录、工具回执和副作用、长期记忆、群观察数据库、配置及管理员绑定均保留。此功能重置对话历史，不删除长期记忆，也不抹除整个群的共享原话或学习经验。

边界保存在会话插件独立的 `context-resets.v1` 状态键，格式 1；原 `sessions.v1` 记录格式不变。重启后继续遵守边界。边界损坏、重复字段、未知格式或引用错误身份、越界轮次时拒绝启动并保留原数据；写入失败不报告成功，并停用旧会话句柄，避免使用不确定的边界继续请求。迁移时完整复制状态目录；回退旧版必须选择支持上下文清空边界的程序，早期程序不认识此键，会重新读取原始历史。
