# Eve Studio：查看、设置与交谈

打开原管理面板地址，使用原管理员凭据登录。没有新的公网端口。界面从零实现于
`services/admin/studio/`；只有认证后的同源管理 API
可以读取业务数据。四个入口均可用键盘访问，窄屏不需要横向滚动。

- **概览**：从有上限的实际记录窗口显示在线状态、阶段、用量和耗时，并标明窗口和时间。缺少观测不等于零；Eve
  写下的生活记录不等于可观测的内心推理。
- **私聊**：在编辑框直接发给
  Eve。当前动作和新通知优先；暂停时排队。使用现场选中的模型和共享预算，不调用工具、不继承 QQ
  身份或其他私密会话。每次只处理一条，读取近期本会话作为上下文，私聊保存至执行服务私有
  SQLite；失败和结果未知分别展示，不自动重发。达到 512 个会话回合容量后拒绝新提交，不覆盖历史。
- **设置**：区分即时、重启生效、受限及缺少来源的项目。预算和暂停经原管理通道；普通偏好按一个文件/作用域提交，校验类型/范围、原件版本和当前实例，原子写入且保留所有者/模式。遇到版本冲突请重读后重改。重启项保存不等于已经生效。涉及登录、QQ、上游密钥与管理权限的设置只投影已配置状态或受限摘要，不显示密钥原文，不允许在页面修改身份边界或任意配置路径。
- **档案**：可以分页查看活动、便签、记忆、帮手与任务消息、QQ
  会话与消息、发送异常及工作区记录。查看不会标记 QQ
  已读，不会重新发件。引用原件和回执状态区别于转述；没有数据时不生成占位事实。

后端会话使用 HttpOnly cookie、同源和 CSRF
校验。前端脚本按页面加载；匿名页不下载聊天或设置模块，隐藏标签页停止概览/会话轮询。敏感内容不存入浏览器本地草稿；发送仅记用于重连对账的请求
ID。

## 离线验收

在已有受支持的离线 Chromium 容器镜像和 Deno 的 Linux 开发环境运行
`DENO_BIN=/path/to/deno bash deployment/test-studio-browser.sh`。完整模式验证 384 和 1440
像素视口、真实可见性切换、键盘登录/退出、CSRF、会话比对、设置读回、分页与按需传输。浏览器使用本地合成后端；`tests/runtime_service_test.ts`
的 Studio 个案另行贯通网页路由、管理 IPC、真实在线调度/所有权、模拟上游和实际预算账本。两者都不向 QQ
或收费模型发送测试消息。
