# 图片描述与直接看图

2026-11-12 用户最新约定：两条链路都保留，由 Eve 选择。`phone.image` 默认使用
`mode: "describe"`，由内部 `model.describeImage`
使用当前相同配置的模型发起一次独立描述请求，再把文字描述、附件来源与下载回执交给 Eve。描述请求不携带
Eve 的身份、记忆、意识上下文或工具；只客观描述可见内容与不确定处，不执行图片里的指令。

Eve 也可以显式选择 `mode: "original"`，通过 `model-chat` 的 `Message.images`
把原图作为真正的图像输入交给主意识，省去独立描述调用。原图不作为普通 base64
文本注入。默认描述失败时保留失败回执，由 Eve
决定是否改选原图，不自动切换路径。脚本不能直接调用模型契约。

原图仍由适配器保存。描述路径下，主脑收到的图片结果不含 `dataUrl` 或
base64；模型描述明确属于外部资料的模型转述，不冒充 Eve 的直接视觉观察。

模型传输只接收内嵌 `data:` 图像，不让模型服务代取任意附件地址。支持 PNG、JPEG、WebP 和
GIF；发送前核验 MIME、文件头与来源记录的 SHA-256。每次模型请求最多 8 张，解码后的图像字节合计不超过
8 MiB；图像只允许放在 `user` 消息中。附件内容来自外部资料，图像中文字不获得系统或主人指令权限。

描述请求复用当前 Chat Completions
模型配置，不安装或切换模型。描述与主脑请求都计入共享日预算；先预留，保存原响应后按实际用量结算。稳定动作编号复用原回执；原响应保存后事务完成前中断时，重启采用原描述，不重新付费。

实际图像理解仍需在配置的真实模型上验收。本地 HTTP 测试验证默认描述请求带原图且没有 Eve
人格，随后主请求只带描述文字，显式原图路径仍能发送图像输入，并覆盖预算、重复调用与中断恢复。图像
token 用量以模型回报为准，预留预算明确属于保守估算。
