# 子代理角色与共享预算

开启 `--subagents` 后，Eve 可以用 `run_subagent` 派发独立子任务，在本轮等待结果；后台执行者也可使用同一工具。后台继续禁止再次派发后台任务，叶子子代理禁止所有编排工具，包括再开子代理、创建角色和设置触发器。

## 角色和自定义配置

内置 `general` 通用、`coding` 编码、`research` 只读调研、`review` 只读静态核验四种角色。编码角色继承父执行器实际装配的普通工具，可在当前授权范围内读写代码、运行命令和测试；调研与核验仅装配读取、搜索工具，不因角色说明或模型请求开放写入能力。

`create_subagent` 保存 `name`、`instructions` 和可选 `tools`，返回 `agent_id`；之后调用 `run_subagent` 时传入该 ID。`list_subagents` 同时列出内置和当前范围自定义角色，自定义角色分页查询；`delete_subagent` 按 ID 和 revision 删除。角色名称重复且内容相同时去重，不同内容拒绝覆盖，可明确删除后重建或使用新名称。创建角色不会自动执行任务。

自定义配置的工具只能收窄宿主当前可用工具，不允许编排工具。未指定工具时继承普通工具，指定空列表时仅调用模型；升级后某工具不再装配时不凭旧配置恢复该工具。作用域由宿主绑定的用户与会话共同确定，模型不能指定其他身份。角色不是新的管理员身份，也不绕过普通用户、文件保护或敏感操作授权。

配置保存在状态目录 `subagent-profiles.sqlite3`，单条原子提交；ID 不回收，删除不会把旧 ID 分给新角色。正在运行的子代理使用启动时冻结的角色，之后删除配置不改变它已获准的执行范围。

## 步数、期限和并发

一次前台执行或一个后台任务是独立主任务，主执行者和其全部子代理共用原子步数池。前台每轮 100 步，后台使用任务已批准的 `max_steps`，没有增加默认预算。

每个工具调用计一步，委派本身、失败、拒绝和并行批次也计入。子代理不再默认另领一份步数；缺省继承主任务剩余步数，显式 `max_steps` 只能进一步收窄该子代理自己的上限。多子代理并行时整批准入，不足时该批全部不执行，不会部分扣减后超额执行。主任务共享额度用尽时 Eve 也只能依据已有结果收尾，不再提供工具；模型请求数量单独记录，不将其伪装成工具步数。

例如 10 次委派花掉主代理 10 步，子代理合计最多再花 90 步，而不是每个各自获得 100 步。需要更多步数时在原会话申请，仍走已有明确批准流程，不自动增加额度。

前台与后台共用 `runtime.tasks.subagent_concurrency`，默认 10。槽位按 FIFO 排队，取消、超时和 Future 被丢弃时都移除等待者或释放槽位；降低并发配置后不取消已运行者，后续准入等待现有槽位降至上限以内。不同主任务只共享并发槽，不互相扣减步数。

子代理排队和运行时间都计入它自己的期限，并受父任务剩余期限约束。后台父执行者与叶子子代理使用不同的工具槽位池，叶子之间共享池；双方仍共享原来的串行队列，避免父工具等子代理、子代理反过来等父工具槽位。

## 持久化和恢复

后台检查点保留本执行器调用列表，另存子代理工具调用和模型请求计数。旧格式 1 缺省为零；产生子代理消耗后保存格式 2，新版本可读取两种格式。无子代理消耗时不额外序列化计数字段，原格式 1 保持原样。任务用量包含主、子代理总消耗，恢复时先扣回这些已保存计数，再准入新调用，不能靠重启重新领取额度。

编排调用开始前仍保存 pending 标记。进程中断时若子代理结果未知，保留原记录并阻止自动重放；不能因为角色叫“核验”就假定没有副作用。已配对的结果恢复后不重开子代理。旧二进制不能读取新的格式 2，部署回退须使用兼容的新候选程序，或停机还原完整备份，不能仅替换旧二进制。

角色数据库的损坏、空旧文件、未知版本或缺表拒绝启动并保留文件；运行时存储不确定后关闭配置服务，返回明确错误，不清空或伪造成功。迁移应停宿主后完整复制状态目录，包括 Jev 经验、角色库、任务检查点、会话、配置和管理员绑定。角色说明与委派上下文只是数据，恢复不授予新权限。

验收覆盖原子共享预算、重启余额、后台委派、10 子代理并发、编码实际写入并读取核验、角色重启可用、只读角色拒绝写入和递归、作用域隔离、删除去重及旧数据保留；替身模型验证宿主契约，不代表任务语义质量。
