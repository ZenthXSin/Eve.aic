# 定时任务持久有效

宿主启动配置持续包含 `--triggers`，模型便可以在已授权目标内自行创建一次性时间、文件变化、任务结束、消息或进程状态触发器。创建成功后保存在原会话，跨对话和进程重启有效，不需要每轮重新打开或重新授权。文件、进程和后台工具仍沿用当前操作者权限；授权撤销后取消未开始的触发器。

时间触发器可以用相对秒数或绝对毫秒时间设置，已有记录使用原来的到期时间。重启恢复时即使没有新的用户消息，到期也会在保存的会话中执行并通知原触发者。已经执行或发送结果未知时不重放；过期、取消和权限失效的任务不重新开启。

目前契约是一次性条件触发，未引入未经确定的周期执行语义。不要为了模拟周期自动重复创建同一任务；用户明确提供周期范围和停止条件后，再按相应已装配能力处理。

真实进程验收分别覆盖创建后重启再到期、完成后重启不重复、取消、跨用户隔离及后台任务完成唤醒。
