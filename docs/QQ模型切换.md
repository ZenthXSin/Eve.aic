# QQ 模型切换

主人可以在已绑定的 QQ 私聊中发送完整指令：

- `/model`：查看当前模型和当前凭据可用的模型列表。
- `/model 完整模型名`：切换模型。
- `/model 序号`：选择最近一份已收到的列表中的序号。

模型选择全局持久保存，作用于下一次在线请求和图片描述请求；正在进行的请求继续使用开始时的模型快照。群中的身份标识不能等同于私聊标识，因此群聊和未绑定用户不能操作，也不能查看模型列表。包含附件的消息、自然语言中提及指令都不触发切换。

QQ 私有配置需要显式设置 `qq.modelControl`，字段为绝对路径 `connectionFile`、`keyFile` 和绑定的 `ownerPlatformUserId`。运行时用 `runtimeService.modelControl` 配置相同的连接文件、独立控制密钥及主人标识。该接口仅监听本机，不能替代运行时或管理面板的私有凭据。

启用时记录入站边界，历史消息不会被当作新命令执行。之后以平台消息身份去重，命令状态写入 QQ 运行目录的 `model-commands`，原始入站记录保持不变。发送给 Eve 的手机视图有固定的系统指令标记，并关闭该指令通知，避免 Eve 重复操作。指令回复经过原有发送账本和会话队列，不能越过之前失败、未知或仍在重试的消息。

切换必须有真实成功回执才能回复成功。HTTP 中断或缺失回执保持结果未确认；恢复只查询原切换动作，不自动重新执行。主人可以再次用 `/model` 查询当前状态。列表序号绑定之前已有真实送达回执的列表，模型列表变化不会把旧序号误解为另一个模型。
