# 手机阅读与通知

`phone.open` 打开最新一屏，并在回复前持久保存本会话的通知水位和本屏实际展示编号。
两者含义不同：通知水位消除此前的本机提醒，不证明屏幕上方的消息实际看过。
返回值始终明确说明这一点，也说明长文及附件只展示了预览。`earlierMessagesNotShown`
是这一屏之前的消息数，不是累计未读数。空会话不捏造阅读记录。

`history`（包括最新页）、`search`、单条/长文展开、会话列表和通知预览只浏览，不更新水位。
通知全局消费游标仍用于意识流的事实去重，与每个会话的水位分别保存；打开一个会话不会
清除其他会话或之后新到消息的通知。会话列表返回待提醒数及最近打开的屏幕记录。

状态存在独立适配器的 `phone-reading` 设备目录，与平台事实、发送账本和插件快照分开。
这是手机的本机状态，不是平台消息事实，也不向 QQ 发出已读回执。由独立服务持有它，
让手机 worker 换版和内核回滚不倒退设备水位；其访问同样受当前实例令牌检查。

写入串行化，迟到旧屏幕不能覆盖新水位；提交使用文件和目录同步，失败不会返回成功。
恢复核对编号属于原会话，坏格式、临时文件和链接保留并报错；状态失败会令服务健康
检查失败。目录持排他锁，当前单 JSON 索引上限 4 MiB，达到上限停止保存并保留现场。

本批验证覆盖多会话隔离、通知分页后打开、新消息保留、历史/搜索只读、保存失败、
实际子进程与 worker 重启、旧令牌拒绝修改、并发旧快照和损坏保留。使用本机模拟平台，
没有发送真实 QQ 消息。免打扰、置顶与草稿继续由设备状态扩展，不用阅读水位冒充它们。
