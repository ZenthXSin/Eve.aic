# 工具结果与时间线

模型输入中的主机通知和工具回执使用稳定可读投影：来源、类型、时间、状态、动作编号、内容和关联记录按固定字段样式显示；未知字段继续展示原字段名。脚本输出中的 JSON 文本会作为返回值展开，避免反复转义。正在运行、提交成功、已送达、失败、未知和取消分别保留原义。

只改变模型阅读的副本；意识日志、脚本账本、QQ 平台回执仍保存原件。投影带 `tools.records.text` 的真实记录位置，分页读取不丢原字段；`mind.retain({mode:"raw",...})` 显式选择的回执仍按原始 JSON 展示。长历史既有节选策略与读取原件入口继续生效。

详细发送回执移入 `contracts/phone-details.ts`，日常手机接口继续带必要的队列与重试说明。完整子代理类型不再每轮常驻；按需执行：

```ts
return await tools.scripts.contracts({ name: "phone-details" });
// 或 name: "agents"；长原件按 nextChar 使用 startChar 继续读取。
```

类型检查始终导入完整真实类型，查契约不改变能力或权限。废弃的 `replyTo` 只在兼容类型中接受，不再给模型推荐使用；所有发送仍是主动消息。按需接口只允许固定契约名称，不接受任意文件路径。

管理空间的意识流页按真实记录显示想法、QQ/子代理通知、工具调用与回执、压缩、休息、唤醒与回滚。卡片包含时间、来源编号及原件实际提供的源码版本；有原始决定编号时可直接跳转，动作编号可搜索关联回执。版本未记录时不猜测。完整历史继续经服务端快照游标分页，不依赖浏览器的有界预览缓存。

所有文字通过 DOM 文本节点呈现；记录里的 HTML、代码和链接不会执行。实时面板同样保留分类与关联跳转。管理员阅读不移动 Eve 手机或子代理的阅读水位，不会向她注入面板操作通知。
