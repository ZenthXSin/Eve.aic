# 说法学习失败恢复

说法学习从当前可信会话中攒够 12 条用户原话后提炼词语与表达方式。取出时原话从 pending 转入同一状态文档中的固定 batch，成功持久保存 Running 后才请求模型。只使用原话，不调用工具，也不重放聊天或业务操作。

每批最多三次逻辑尝试。仅明确超时、无 HTTP 响应的网络失败、HTTP 429 和 5xx，或适配器未提供 HTTP 状态码但明确给出的同类限流、服务端暂态分类，可以保存为 RetryWait；第一次失败至少等 60 秒，第二次至少等 120 秒。每次重试都使用原有 phrase 分项和自主总预算；预算不足或学习开关关闭时不领取、不增加 attempt。Provider 内部传输重试另有自己的上限，三次逻辑尝试不等于三次 HTTP 连接。

重试使用原 batch id、可信范围、12 条原话和提炼协议版本。模型长期 session、thread、cache key 和 batch turn 不变，新的 attempt 对应新的逻辑 request id；同一次 Provider 传输重试仍用原 request id。期间新增的用户原话独立进入 pending，不能混入旧批次或重新给旧批次编号。这里不更改模型、temperature 或思考强度，也不根据客户端 cache key 推断中转站缓存命中。

认证、余额、普通 4xx、未分类 Provider、配置与协议错误，以及取消不自动重试。即使 HTTP 400 的正文包含 temporarily unavailable，也按实际状态码处理。格式、逐字摘录和候选数量继续严格核对；不合格结果整批不保存，并持久结束批次。合法空结果同样结束，不能记录为新增学习。成功结果和消费批次在同一次状态提交完成，重复或迟到的 finish 不增加 uses。

state_set 返回错误时，调用方不能假定一定没有提交。说法状态的旧实例停止读取和写入该快照，后台结束并沿用现有宿主保护；不再把 finish 错误送回模型重试。重新打开后只按实际持久状态判断：已完成不重放，已明确保存为 RetryWait 的批次在剩余次数内继续；只见 Running 时视为 Unknown，保留原话和范围名额，不自动请求模型。进程在请求中被硬终止、收到结果但尚未保存、完成保存失败，都可能留下这一未知状态。本次不提供任意崩溃窗口的自动重做，也不承诺远端恰好执行一次或超时后停止计费。

未知批次暂时占住本范围一个未终结名额，其他范围仍可推进；该范围的新原话继续遵守原有 24 条 pending 上限。`/train reset` 可以按现有重置语义明确清除此范围；不会为恢复新增审批、目标或收益要求。正常宿主关闭时，正在执行的请求按明确取消终结；已经保存的 RetryWait 不因退出重新领取次数。

`/train stop` 先持久撤销本范围已有 Running、RetryWait 和 Unknown，再保存停止模式。快速恢复也不接纳旧结果；保留原有 pending 和已学说法。`/train reset` 在 phrase 同键提交中清除 pending、learned 与未终结批次，全局序号不回退，表达去重凭据按既有规则保留。`/train forget` 删除目标说法时，同时撤销此范围已经存在的未终结批次，避免迟到结果立即复活删除内容；这不是永久禁学名单，后续独立新样本仍可形成新说法。配置 learning=false 只是暂停领取，保留待重试批次；已开始的请求按原来的结束路径处理。

mode、conversation、expression 与 phrase 是不同状态键，暂停和重置不是跨键原子事务；中途失败如实报错，不能声称所有组件一起提交成功。phrase 自身的撤销屏障与删除在同一快照内完成，任何说法写入或启停模式提交结果未知时都封住该实例的 phrase 准入，不能让旧内存开关继续领取新批次或覆盖可能已经提交的状态。

容量仍为全局 2 MiB、新范围最多 256 个、每范围 pending 最多 24 条、单条最多 512 字符、已学说法最多 64 条。inflight 和 Unknown 原话与元数据计入总字节与范围并集，每范围最多一个未终结批次；取出不再临时释放范围名额。每个阶段的状态元数据按 128 字节额度计入容量，避免后来的 pending 挤掉保存重试结局的空间。新样本放不下时不进入缓冲，已有数据保留；已领取批次的合法候选若在本地合并、编码容量检查时明确被拒绝，则放弃本批候选、保留原有 learned、uses、pending 和序号，仅持久结束本批并记录 rejected，后台继续。保存这一终态若遇到后端错误，仍按提交未知封住旧实例，不能伪装明确拒绝。不会通过静默淘汰未知批次来腾位置。旧实现形成的最多 512 个可验证范围仍可读，但不能继续新增范围。

状态键继续使用 phrases.v1，权威文档 version 升为 2。新实现严格读取旧 version 1，保留 pending、learned 与 next，视为没有可恢复的在途批次；首次实际写入才保存新格式，空重启不会主动改写。旧版已经删除的原话无法由日志补回。未知字段（包括 Running、RetryWait、Unknown 阶段内的字段）、版本、非法范围、重复批次、非法 attempt、容量或序号异常都拒绝读取并保留原始状态。旧二进制不支持读取 version 2，回退需匹配的完整状态快照，禁止删字段、改 version 或清空状态伪装兼容。

EVE_PHRASES 增加 attempt、max_attempts 与固定结局。只有失败状态已经持久保存才记录 retry_scheduled；empty、rejected、cancelled、exhausted、stale 与 storage_unavailable 都独立记录。日志不加入用户原话或供应商错误正文。Rust 状态测试覆盖重启、故障提交与撤销，QQ loopback fixture 覆盖实际 503 同批恢复和不重放；测试结果由对应 PR 记录，不把测试替身当成真实模型的语义质量证明。
