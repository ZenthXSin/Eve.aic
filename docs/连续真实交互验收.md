# 连续真实交互验收

`connectors/qqbot/test/continuous_plan.py` 生成 58 轮相互依赖的青湾项目对话，`continuous_acceptance.py` 启动隔离的真实 Eve 进程与本地 QQ 桥接，使用同一持久状态完成脚本版本切换、状态迁移、失败复现、文件交付、后台任务、触发、权限隔离、取消及重启。它不会连接正式 QQ；所有项目内容和管理员身份均为测试构造。

真实模型模式必须显式提供已授权的凭据文件、HTTPS endpoint 和模型名。凭据只留在本地代理内存；Eve 子进程只得到随机本地代理令牌。日志包含合成对话、实际模型决策、工具回执和逐轮状态断言，写入指定的隔离输出目录，不应提交到仓库。

默认上限为 240 次请求、500 万累计输入 token、9.6 万累计输出 token、每次最多 2048 输出 token、单轮 180 秒及总运行 45 分钟。每次请求先保守预留 UTF-8 请求字节数再按提供商 usage 结算；上限可能提前拦截。`--resume` 保留状态、原失败、模型、二进制摘要与累计记账，预算调整记录在 attempts 中。中断时未确认效果不能重复执行，续轮必须先查真实状态。

模型调用可以来自当前聊天、后台任务或条件唤醒。请求记录的 `round` 表示当时测试轮，`origin` 区分当前对话和异步/指导请求，完整 messages 保留来源证据。不能把该时间窗内所有工具调用都描述成用户当前轮的直接决策。

同一会话的条件唤醒会等待普通对话结束。在普通对话里调用 sleep 仍占用该轮，不能当成等待后台唤醒的空闲窗口。计划以 `idle_wait_files` 在桥接门关闭后有界等待真实产物，再发送后续查询。

本次真实模型使用既有配置中可用的 deepseek-v4.1-flash；原配置 grok-4.7 的有限探测返回 503，未将其称为可用。当前长程验收的最终轮数与结论以 PR 最新记录为准；确定性替身仅用于故障注入与重复回归，不能代替真实模型结果。
