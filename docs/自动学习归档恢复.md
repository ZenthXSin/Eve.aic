# 自动学习归档恢复

自动确认和候选查询读取热层与归档合并的完整快照，逐项核对提炼批次保留的原始证据。归档不是证据丢失，不跳过核验，也不伪造新的用户原话。归档分块缺失、损坏、作用域或摘要不符时仍拒绝写入，保留现场。

偏好提交可引用本作用域已经归档的证据：在同一写入锁内重新核验归档原文，仍执行修订 CAS，先保存决策意图再写偏好。证据留在不可变归档中，不复制回热层、不重复计数。重启校验完整的来源和偏好操作历史，重复确认不会产生新修订。

首次出现偏好引用归档来源时，记忆状态写格式 4；此前状态继续使用格式 1/2/3。格式 4 启动时核验被引用的分块，旧程序会拒绝此版本，不能覆盖或清空。生产回退须同时恢复升级前匹配的记忆状态备份和原归档目录，不得用旧程序直接打开新的状态。升级和验收前均保留真实状态及归档副本。

## 语义索引的冷层偏好来源

已确认偏好的最新来源可以留在冷层。语义索引先读热层，来源不在热层时通过现有归档分页接口核对真实证据 ID 与修订；只保留偏好引用所需的紧凑映射，不把归档正文复制回热层，不重复生成交互条目。关闭向量分段时仍可解析该偏好，但不额外导入冷层交互。

找到来源后仍完整校验后续分页与总条数。缺失来源、修订冲突或后续坏块均拒绝本次索引，不以归档条数猜测证据，不提前写入部分结果。本修复不改写记忆格式或原始数据；回退到只认热层来源的语义实现会重现故障，应先修复消费方或暂停语义索引，不得删除偏好或恢复陈旧记忆来绕过。

跨会话连续性读取也会先核验目标会话的完整热冷来源流，不能用仅包含热层证据的快照判定冷层偏好来源缺失。即使没有跨会话共享授权，也必须读到当前目标游标的结尾，逐项核对来源、修订与偏好历史；坏页、缺失引用或身份不符时继续拒绝并保留原记录。本路径只保留来源元数据，不恢复整份历史正文到热层，不扩大共享权限。
