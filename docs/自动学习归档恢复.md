# 自动学习归档恢复

自动确认和候选查询读取热层与归档合并的完整快照，逐项核对提炼批次保留的原始证据。归档不是证据丢失，不跳过核验，也不伪造新的用户原话。归档分块缺失、损坏、作用域或摘要不符时仍拒绝写入，保留现场。

偏好提交可引用本作用域已经归档的证据：在同一写入锁内重新核验归档原文，仍执行修订 CAS，先保存决策意图再写偏好。证据留在不可变归档中，不复制回热层、不重复计数。重启校验完整的来源和偏好操作历史，重复确认不会产生新修订。

首次出现偏好引用归档来源时，记忆状态写格式 4；此前状态继续使用格式 1/2/3。格式 4 启动时核验被引用的分块，旧程序会拒绝此版本，不能覆盖或清空。生产回退须同时恢复升级前匹配的记忆状态备份和原归档目录，不得用旧程序直接打开新的状态。升级和验收前均保留真实状态及归档副本。
