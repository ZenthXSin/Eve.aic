# QQ 群白名单与恢复

默认未放行的群只接受已核验的主人本人消息；普通成员需要主人放行当前群。群标识来自通道可信路由，不接受模型自填群号扩大权限。支持 QQ 的 ASCII OpenID（字母、数字、下划线、连字符，最多 128 字节）。

白名单保存在独立 SQLite 数据库，使用事务及 FULL 同步；新建文件在 Unix 下设置 0600。添加和移除后重启继续生效；已有可信回执用于恢复群路由。未知数据库版本拒绝使用，数据库故障不清空原库，也不自动重建丢失的名单；需保留现场后修复或从成套备份恢复。

此分支依赖私聊回复恢复分支，保留已核验的身份字段兼容改动。验收覆盖 OpenID、非法标识、名单持久化及主人/成员边界；进程验收使用本地 QQ 替身，不等同于真实平台送达。
