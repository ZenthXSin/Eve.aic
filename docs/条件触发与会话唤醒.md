# 条件触发与会话唤醒

QQ 启动时增加 `--triggers`。聊天模型可调用 `set_wakeup_trigger` 创建一次性条件，`list_wakeup_triggers` 查看当前会话记录，`cancel_wakeup_trigger` 取消。默认关闭，全功能配置开启。提醒只投递保存的文字；触发器会重新调用模型，在原会话历史和既有工具范围内继续做事。

例如让 Eve 在两分钟后重新检查任务：

```json
{
  "title": "两分钟后检查",
  "instructions": "查看先前任务的实际结果，必要时继续处理并回复",
  "conditions": [{"type": "time", "after_seconds": 120}],
  "mode": "all"
}
```

条件可以使用 `mode: all`（全部满足，默认）或 `any`（任一满足）组合，每条至多 8 项：

| type | 参数 | 观察范围 |
| --- | --- | --- |
| `time` | `after_seconds` 或 UTC 毫秒 `at_ms`，二选一 | 未来时间，宿主记录实际期限；不是定时重复任务 |
| `file_changed` | `path` | 开发目录内相对路径；创建时保存 SHA256 或缺失状态，内容改变、创建或删除时满足 |
| `task_finished` | `task_id` | 同一可信用户、同一会话的后台任务，结束包括成功、失败、取消和中断；是否成功须查看结果 |
| `message_contains` | `text` | 创建后的原会话已完成用户轮次，精确子串匹配；不匹配旧消息、其他会话或宿主唤醒事件 |
| `process_state` | `pid`、`running` | Linux 本地进程是否仍在运行；保存启动标识和 boot ID，PID 被复用不视为原进程仍活着，不读取命令正文或执行脚本 |

文件条件只允许既有开发操作者，单文件不超过 1 MiB，拒绝越界路径；进程条件还要求宿主已开启命令能力。其他三类不需要开发权限。任务和文件来自实际只读服务，检查本身没有模型请求。约每秒扫描，事件是状态观察，不保证捕捉两个扫描之间短暂出现又消失的变化。

`expires_in_seconds` 默认 7 天，范围 1 秒至 90 天。每个会话至多 20 个等待/执行中的触发器，24 小时最多创建 32 个；账本总量至多 512 条或 4 MiB，满时明确拒绝，不删除旧证据。没有无限循环、任意表达式求值或 shell 条件；需要再次观察时明确创建新的一次性触发器。

## 执行与原会话

宿主从工具执行上下文取得会话和用户，模型不能指定别人的会话。满足条件后先保存 Ready；等待 QQ 通道空闲并取得独占唤醒名额，再保存 Running 并提交到原会话的 Control 服务。用户在唤醒过程中发来的消息排队；已有普通回复和分段投递完成前不插入唤醒。

输入带固定的“宿主条件触发事件；不是用户新消息”标记和原先保存的任务。它进入原会话账本，复用会话历史、当前主模型与工具权限；不通过普通 QQ 入站或成功交互观察器，不成为用户偏好/表达训练样本。检查结果是触发证据，不代表业务任务完成。

执行结果先保存为 Completed，再尝试主动投递到**同一个会话**。路由由通道从已验证、已成功投递的原会话回执中取得；群聊留在原群，不能改发私聊。平台可能拒绝主动消息；失败记录为 Failed，不改发其他会话，不自动重试。结果仍可通过列表查询。模型回复会按平台字节上限收窄。

## 持久化与恢复

`eve.trigger/triggers.v1` 由现有状态后端保存，格式 1；触发器 ID 绑定会话、轮次和工具调用，同一次调用不重复创建。定义层为 `eve-trigger-api`，实现为 `eve-trigger-plugin`，QQ 的观察、执行和投递装配位于 `qq_triggers`；Kernel 不理解条件业务。

- Armed/Ready 重启后继续等待，超过有效期记 Expired。
- Running 重启后记 Interrupted，未知工具副作用不重放。
- 模型完成和投递是两件事：Completed/Pending 可在重启后首次投递；Sending 重启记 Unknown，绝不补发。
- 取消会停止尚未开始的执行，执行中请求 Control 取消；无法撤销已发生的副作用。
- 无法读取观察对象时明确失败，停止该条件；损坏、重复键、未知格式或账本写入不确定时保留原数据并拒绝继续使用，后台异常触发 QQ 统一收尾。

验收包括账本跨实例恢复、隔离、容量与损坏保留、五类条件的实际 QQ 子进程流程、原历史接续、群聊路由、取消与重启不重复。模型与 QQ 投递使用本地协议替身；正式平台是否允许主动投递须另外确认。[子代理串并行及并发上限](./子代理并发.md)独立于触发器配置。
