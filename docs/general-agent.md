# 单条 Eve 意识流与通用子代理

Eve 保留原来的意识流、长期记忆、上下文与自主活动，负责交流、决策、派工、交付管理和自己的兴趣。所有执行任务交给子代理；无需为几条命令的小事切回亲自执行。

新增 `general` 类型与常驻 `agent_general`。它没有独立模型或密钥配置，实际请求跟随 Eve 当前的连接、模型选择和思考强度，共享预算。`modelSource: "eve"` 表示跟随关系；会话的 high 默认值不覆盖 Eve 的有效设置。专用编码、审查、调查配置保持原状。

原生 `delegate_task({text, role?, agentId?, newSession?})` 直接等待持久准入并返回任务句柄，无脚本校验和沙箱启动开销。默认交给通用常驻会话；`newSession:true` 多开独立会话并行，追问用原 `agentId`。创建与派发动作由原工具编号稳定生成，结果未知时保留原号查询，重启不另造任务。

子代理仍用独立持久会话，完整消息与工具回执保留，回复不做 QQ 分段，最终回复照常唤醒 Eve。上下文接续只消费交付和必要证据；原意识流的追加与压缩边界保持原机制。

验证覆盖实际 Chat 请求的模型/密钥/思考强度切换、稳定子代理缓存标识、专用模型隔离、派工准入与重启恢复。更新生成提示前言使用能力标记，旧版提示仍可逐字复原并保留自定义身份。
