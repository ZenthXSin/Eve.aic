[完整合成基准](./速度优化基准-20261019.json)：同一代码、4 MiB 合成状态值（初始 JSON 约 16 MiB）、各五条消息、本地立即回复的模型与 QQ 替身。

| 中位耗时 | 未优化 debug | 优化 release |
| --- | ---: | ---: |
| QQ 入站至主模型 HTTP 发起 | 946 ms | 109 ms |
| 模型完成至写出回复帧 | 633 ms | 76 ms |
| 入站至平台成功回执保存 | 1967 ms | 229 ms |

原始 HTTP 请求的严格相等为 false，原因已定位为两次独立实验新产生的情景记忆 `episodes[*].at_ms`。比较器仅在副本中归零该字段，正文、证据 ID、修订、历史、模型参数和工具定义不忽略，实际请求不修改；归一化后的请求摘要相同。另已核对比较器不会忽略正文变化。不要删除记忆或隐去其他字段来凑通过。

158 项 Rust 测试、29 项优化运行器原生 QQ 测试通过；workspace 全目标严格 Clippy、格式检查通过。原生测试覆盖跨会话记忆、工具与实际读源码、开发工具、请求计时、50 次限制、途中进展、取消与投递恢复。debug/release 都已构建完毕。合成性能证明本地开销减少，不证明真实模型生成更快。
