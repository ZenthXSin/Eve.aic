## 当前状态

项目已跑通第一阶段插件协作验收链，暂不实现 AGI 认知层。事件、服务、状态、权限检查、任务管理和日志均提供独立接口与默认实现；已实现字节状态持久化、独立进程恢复、插件注册/卸载、插件及任务查询、停止错误汇总。插件清单使用严格 SemVer，依赖范围在注册和启动前校验。

任务支持前台、后台、定时与重复执行；插件可通过公开接口定义新任务类型和调度规则，扩展无需修改内核。详见[插件开发](./插件开发.md#自定义任务类型与调度)。

当前优先目标是建立稳定的 Rust 插件 Runtime：

```text
插件注册
    ↓
依赖解析
    ↓
插件生命周期
    ↓
Context 边界
    ↓
事件 / 服务 / 状态 / 任务
    ↓
清理 / 停止 / 恢复
```

插件扩展边界已具备静态工厂与目录。最小 LLM 工具闭环已经以无网络 Mock Provider 落地：Runtime 负责模型请求和工具调用批次循环，Provider 可替换，Context、Memory、Tool 和 Channel 继续作为插件能力。并行安全工具可在宿主上限内并发执行，串行作用域保持模型顺序，单项失败、超时或取消按调用 ID 隔离。真实 Provider、会话恢复和流式输出仍按后续阶段推进。详见[LLM 工具调用](./LLM工具调用.md)和[开发计划](./开发计划.md#phase-6最小-llm-工具闭环)。
