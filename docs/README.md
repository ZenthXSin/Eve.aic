## 当前状态

项目处于第一阶段设计期，暂不实现 AGI 认知层。

当前优先目标是建立稳定的 Rust 插件 Runtime：

```text
插件注册
    ↓
依赖解析
    ↓
插件生命周期
    ↓
Context 边界
    ↓
事件 / 服务 / 状态 / 任务
    ↓
清理 / 停止 / 恢复
```
