## 当前状态

项目已跑通第一阶段插件协作验收链，暂不实现 AGI 认知层。事件、服务、状态和权限检查提供独立接口与默认实现；任务、日志、持久化和重启恢复待后续实现。

当前优先目标是建立稳定的 Rust 插件 Runtime：

```text
插件注册
    ↓
依赖解析
    ↓
插件生命周期
    ↓
Context 边界
    ↓
事件 / 服务 / 状态 / 任务
    ↓
清理 / 停止 / 恢复
```
