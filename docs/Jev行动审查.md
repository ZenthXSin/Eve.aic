# Jev 优先的最小行动审查

行动审查只处理可信身份/访问边界变更和具体动作的直接系统危害。普通探索、阅读、开发、一般写入、未知命令、计划与委派继续经过宿主身份和资源范围检查，不额外调用 Jev 或 LLM。命令策略明确禁止的动作在模型之前拒绝，模型结论不能覆盖它。

## 两条入口与回退

公开定义位于 `eve-developer-api`：`ActionReviewClassifier` 接收完整 `ActionReviewRequest` 与 `ActionReviewMode`，返回带路由分数的 `Decided` 或固定原因的 `Uncertain`。它不执行动作、授予身份或修改权限。`eve-jev` 实现原生 SystemOne 分类，`eve-action-review::FallbackActionReviewer` 组合前置分类与可替换的 `ActionReviewer` 后备，QQ、Web 沿用同一个宿主工厂。

| 入口 | Jev 判断 | 宿主后续核验 |
| --- | --- | --- |
| `review_system_safety` | 完整动作的直接系统影响及判断依据是否成立 | 当前身份、实际路径、目标版本、候选/租约/在线基线；不要求用户逐步授权 |
| `review` | 上述系统影响，以及宿主保存的真实本人原话是否包含该项身份、撤销解锁或隐私范围变更 | 当前真实身份、本人意图、取消/撤销、原话证据和具体共享范围 |

宿主已有的明确撤销、收缩权限、明确解锁等确定性路径保留，不为它们增加一次语义请求。外部文件、工具输出、模型自称、转述、引用、`claimed_confirmation` 和委派说明都不能成为权限依据。

Jev 一次原生 `/v1/systemone` 请求只包含 `model`、完整待判数据 `state` 和窄问题 `questions`，没有执行工具。风险为无直接危害或影响有界时可允许；有具体高危害或严重危害时明确拒绝，授权不能消除危害。身份入口还必须识别真实本人对具体边界变更的明确意图。明确拒绝直接结束，不再向后备寻找许可。

标签、必需字段、未知字段、概率重复键、数值范围、概率总和和选中项最大值都严格校验。分数取相关 choice 自评、选中概率与依据命题分数的最小值，向下取整；路由阈值为 80，未经校准，不表示 80% 的真实正确率。含混、低分、非法输出、HTTP 失败、超时、槽位已满、配置或凭据不可用才调用后备。普通不确定性不会直接变成拒绝或要求用户审批。

后备保留原来的两个 LLM prompt 和一次 `submit_review` 协议。它收到原始完整对象，不加入 Jev 输出，不裁剪参数、原话或源码差异。后备也失败时返回错误，宿主不执行需审查的动作。链内没有重试；LLM 提供方自身已配置的传输策略保持原义。

## 共享客户端、凭据与期限

Jev 使用独立宿主 `EVE_JEV_API_KEY`、`provider.jev` 和 `runtime.models.jev_*` 配置，不借用主模型密钥，也不把 `runtime.model_uses.review_role` 配成 Jev。`review` 用途仍只决定 LLM 后备角色。只有 Jev 凭据时，确定结论仍然可用；Jev 无法判断而没有后备时明确返回不可用。两种凭据都没有时不装配审查服务，普通开发路径不依赖它。

同一 `ConfigService` 实例和独立凭据的消息、群、记忆与行动用途共享 `JevRoleJudge`，因此也共享相同配置选择下的 HTTP 客户端和并发槽。不同宿主或凭据不混用，弱引用池不延长宿主生命周期。配置每次按同一修订捕获，凭据用途、引用和版本先核验；坏配置不能复用上一次有效客户端。在途请求固定自己的选择，新请求使用最新有效配置。

Jev 的完整 wire 请求上限 64 KiB，响应上限 16 KiB。完整动作仍受原有 256 KiB 上限约束：合法动作超过 Jev 容量时，不发 Jev HTTP，完整回退 LLM；超过原有动作容量时在任何模型请求前失败。禁止裁剪或用摘要争取通过。

默认 Jev 阶段最多 10 秒，并受自身配置期限与链总期限一半限制。整链最多 611 秒，容纳原 LLM 最大 600 秒和 SSE 一秒收尾；LLM 自身较短期限不变。宿主工具/任务更早期限和取消始终优先，回退不重新计时、不延长原任务。取消销毁当前 future 并释放本地 HTTP/并发槽，不启动后备；它不证明远端提供方已停止或免计费。

Jev 会话从原审查 `ModelSession` 的 `jev-action-review` 用途稳定派生，不与对话或 LLM 审查共用请求会话。重试/恢复沿用宿主原锚点；没有宿主会话时不从正文、用户名或随机值补造。LLM 后备收到原审查会话。

## 记录、恢复与验证

`EVE_ACTION_REVIEW_ROUTE` 只记录入口、分类路径、路由分数或固定回退原因；它不是实际 HTTP 请求数或计费证据。既有 `EVE_ACTION_REVIEW` 继续记录等级、委派标记与真实结局。只有实际进入 LLM 后备的请求才更新 `review` 健康，不把 Jev 成功伪装成一次主模型调用。日志不输出命令、用户原话、密钥或提供方响应正文。

没有新增持久化格式，也不迁移或重写旧审查账本。宿主原有 action 指纹、真实执行回执、取消、失败、未知状态及文件/候选复核保持原义；重启不补写、补判或重放旧动作。共享客户端、路由观察和健康记录仅在内存中存活，进程恢复时按原配置与独立凭据重新装配。

自动测试覆盖真实环回 HTTP 的两入口允许/拒绝与一次后备、64 KiB 完整回退、独立凭据和会话头、热配置错误、共享并发、超时和取消释放；组合单测覆盖总期限不重置、异常与不合格判断。现有开发后端与身份工具测试继续核验普通动作零模型审查、禁止动作/身份缺失不可由模型覆盖、证据变化和执行前身份重验。运行结果以当前提交远端 Rust CI 为准，未运行的验收不记作通过；合成 HTTP 不代表真实 Jev 自然语言判断质量。
