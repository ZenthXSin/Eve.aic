# 文件自动入库

`send_file` 接受产物 `path`，宿主自动复制进 `qq-outbox/files`；可选 `name` 指定交付名。例如 `{"path":"build/报告.txt"}` 无需提前搬文件。只有 `name` 时沿用原约定：操作者从发件目录取文件，普通成员从自己的 `exports/` 取文件。

普通成员的 `path` 相对于自己的项目根目录，也接受 `/work/` 下的绝对路径；目录句柄逐级读取并拒绝父目录、链接、目录和设备，不能访问宿主或其他成员的项目。操作者按既有授权访问宿主文件。源文件在复制期间发生变化时不排队。

同名文件不覆盖。`报告.txt` 已存在时，新的交付物依次命名为 `报告_1.txt`、`报告_2.txt`；并发导入使用原子排他提交，中文文件名按 UTF-8 边界保留。每次发送保存独立快照，源文件后续变化不影响已排队的内容。

入库文件写盘后才写发送队列，队列成功落盘后才报告 `queued=true`，这不等于平台送达。保存队列失败时不发布内存状态，已入库文件保留供恢复。发送开始和结果回执同样先保存再切换状态。重启后保留待发送项；已开始但没有确认结果的项记为 `Unknown`，不会自动重发。账本损坏时拒绝启动，不清空记录。

验证包括并发同名导入、中文长文件名、队列保存失败、链接与管道拒绝，以及真实 Eve 进程的操作者导入、成员权限和重启零重放。平台使用本地桥接替身，不发送真实 QQ 消息。
