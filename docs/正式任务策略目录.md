# 正式任务策略目录

`eve-qqbot --background-tasks --task-strategy-catalog /宿主私有目录/catalog.json` 装配通用任务策略与世界预测服务。该入口与 Rust 宿主的 `task_strategy_policy` 互斥。旧版二进制、启动命令和数据备份单独保留。

目录由可信宿主维护，不从聊天或模型参数接收。空目录可直接运行：

```json
{"format_version":1,"revision":1,"cases":[]}
```

每个非空 `cases` 条目包含 `owner`（`session_id`、`user_id`）、`family`、`input_sha256`、`kind`（`train` 或 `holdout`）及 `contract`。合同采用 `TaskEvaluationContract`；每个身份和任务族至少两个不同留出输入，训练题不得混入留出。输入摘要按公开 `task_strategy_input` 计算，包括说明、步数和实际委派上下文。目录最多256KiB、128项，重复键、未知字段或版本拒绝启动。

未匹配目录的任务照常执行，不登记试验或虚报已验证经验。匹配任务每次读取当前配置修订、实际任务模型、提示、真实工具定义、执行器设置、身份授权及子代理版本；不同环境隔离旧策略。子代理创建水位和当前身份实际配置共同参与摘要，删除后重建不能恢复旧环境，幂等创建不增加水位。

目录在启动时固定；修改后需重启装配，执行中发现变动拒绝使用旧范围。重启沿用策略与世界账本，只补结算，不重复派发、工具或预算。上线运行机制不代表已经学到候选；没有匹配验收条件的结果不会用于晋升。
