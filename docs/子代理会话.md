# 子代理会话

默认提供 `agent_review`（审查）、`agent_coding`（编码）、`agent_investigation`（调查）。
思考强度默认 `high`；Eve 可用 `agents.create` 多开同类或不同类实例，用
`agents.configure` 分别设置名称、模型、思考强度、补充指令和生成 token 上限。
配置在发送时固定，不影响已经入队的任务。省略模型则跟随共享模型选择。

交互像私信：`send` 只确认持久准入，`status` 查询真实执行结果；
`list/open/history/message/search` 查看联系人、未读、历史和完整正文。
正文没有业务字数上限，不自动拆条。列表显示预览，完整读取或分页读取仍对应同一条原消息。
上游模型自身的上下文和生成 token 限制仍适用；不能保证任意长度的输入都可被上游接受。
管理面板的“子代理”页只读，不消耗 Eve 的未读水位。

每个实例保留独立长期上下文。同实例任务按发送顺序执行，不同实例并行，空闲不调用模型。
子代理可使用共享工作空间的文件、命令和网页工具；审查和调查默认只读，由 Eve 明确要求时可修改。
不同编码实例应由 Eve 划分文件或使用独立工作树，避免同时修改同一原件。
模型请求复用现有连接池，独立会话缓存标识，全部用量计入共享预算。
预算、会话状态和通知使用增量索引；正文独立持久保存，读取预览不加载历史全文。

最终回复完整保存为一条消息，发出一次通知。Eve 在工具步骤完成后的通知检查中接收它，
可以从休息中被唤醒；不会打断当前工具步骤。内部模型与工具回执另行保留，不分段冒充聊天回复。
取消会阻止后续步骤；已经执行的动作仍收齐真实回执，取消不代表撤销。

重启保留配置、历史和未读水位，不自动重放未完成的任务。若已有完整最终模型原件，恢复真实回复；
否则标记结果未知并通知 Eve，避免重复付费或重做有副作用的工具。相同动作 ID 的重试不创建重复任务，
参数不一致则拒绝。服务暂停与替换会收拢子代理任务及 ownership 许可。
