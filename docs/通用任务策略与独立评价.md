# 通用任务策略与独立评价

状态：源码、正式 CLI 目录与本地宿主协议替身验收已完成；真实供应商效果和正式 QQ 验收仍待完成，未部署。实际验收记录见[本批集成说明](./内生驱动后续阶段集成.md)。

本切片把实践专用的方法版本机制扩展到后台任务。原有 `TaskStatus::Completed` 仍表示执行器交付了结果；策略学习另用执行前固定的评价合同核对宿主工具回执。方法建议不作为系统提示，不产生权限、额外步数、自动重跑或新的后台任务。

## 结构与接入

- `eve-task-api` 定义任务策略范围、候选版本、评价合同、对照臂、结算、宿主环境读取器和可替换策略接口
- `eve-task-plugin::TaskStrategyPlugin` 保存独立策略账本；控制句柄只交给可信宿主，不注册为对话工具
- `PairedTaskStrategyPolicy` 根据固定留出任务目录，给实际已派发的任务选择控制臂或试验臂
- `TaskPlugin::with_strategy_learning` 将策略服务接入任务管理器
- QQ 的 Rust 组合入口 `QqBotOptions.task_strategy_policy` 接受宿主策略对象，要求开启 `background_tasks`；默认 `None`。正式 CLI 也支持[可信任务策略目录](./正式任务策略目录.md)，两种入口互斥
- 后台执行前先保存策略选择，将方法和评价合同作为有来源数据附加到任务；每轮调度及任务结束后仅对账已保存结果

`TaskStrategyEnvironment::scope` 必须读取当前有效的模型、提示、工具清单、子代理角色、执行工作目录、环境和授权版本。`runtime_sha256` 应包含单调递增的配置修订，使配置改动后再改回也不会复用旧环境记录。不能缓存启动时的旧指纹。组合层每次准入和结算都会调用它；结果不匹配时停止旧选择的接续，已结束结果只记为不确定。

策略范围包括用户与会话、任务类别、运行环境摘要和评价器版本。不同范围不共享候选、对照或结果。提供 `TaskStrategyPolicy` 的 Rust 宿主属于可信计算边界，其配置不从模型参数或群聊文字读取。

## 候选与对照

宿主通过 `proposals` 或管理句柄提交候选，包含来源 ID、来源任务输入摘要、来源证据摘要和方法建议。提议本身不代表有效；同一范围与来源 ID 重复提交相同内容幂等，换内容拒绝。每个范围同时至多一个候选，新候选冻结当时有效版本作为父版本。

自动候选由 `PairedTaskStrategyPolicy::with_training_cases` 启用。训练输入和固定验收合同在首次执行前保存；只有同一来源存在实际“验收不符 → 后续工具成功操作 → 最后验收通过”轨迹，才提炼工具顺序与检查方法摘要。候选不复制参数、工具输出或用户正文，不把模型自述当作证据，也不额外请求模型。来源消费状态持久化，重启不能重复提炼，训练输入不得作为留出题。这个方法只提出相关性候选，仍需独立双臂验证。

固定任务目录包含至少两个不同输入的留出任务及评价合同；候选来源题排除。输入摘要包含任务说明、步数预算和完整委派上下文，不含新任务 ID 或展示标题，不能靠改 ID、改标题重复计分。首版只识别精确输入，不保证识别同义改写。

配对策略对同一范围、同一输入：

1. 第一份真实派发任务使用控制臂：已有父版本或原流程
2. 控制臂有独立通过证据后，下一份同输入、同预算且评价条件相同的真实派发任务可以使用候选
3. 两个不同输入均通过，且每题工具调用数与模型请求数均不多于对应控制臂，候选晋升
4. 启用版本在已有对应控制基线的任务中复用，复用不增加独立验证次数
5. 明确效果不符或对照成本退步使版本被拒绝；状态投影重新选择同范围仍有效的最近版本，没有则回到原流程

账本不会为了凑两臂自动重复操作。宿主须使用允许重置输入环境的留出任务，实际初始状态应纳入环境指纹。派发任务、给出执行授权、重置实验环境均不属于策略插件的能力。

没有配置评价合同的任务照常执行。已启用方法的首版复用仍限于宿主登记的任务输入；面向未登记任务的泛化选择需要独立的范围和质量评估，尚未实现。成本比较目前只有工具调用和模型请求次数，不能据此声称 token、延迟或费用下降。

## 独立效果评价

评价合同固定工具名、完整参数、结果的 JSON Pointer 与期望值。只读取真实宿主 `TurnCheckpoint` 中的配对工具回执，不调用模型自评，不重新执行检查，也不单凭最终回复中的“完成”结算。

合同要求评价工具属于最后一个工具批次，且该批次不包含未声明动作，避免检查之后修改产物或并行交错操作仍被认作成功。宿主应提供具有独立观察意义的只读检查工具，并在任务原始授权中包含它；例如由检查器读取产物、执行受信测试并返回结构化实际结果。`echo`、`task_progress`、`run_subagent` 和 `dispatch_task` 不能作为评价工具。

- `Verified`：任务结局和检查点已保存、工具结果已确定、所有指定结果符合合同，用量完整
- `Failed`：宿主检查实际返回了与合同不符的结果
- `Inconclusive`：取消、接口或执行失败、缺少回执、检查字段缺失、存在未知效果、用量不完整、环境已变化或源任务被淘汰

缺少检查器或模型没有执行检查只会得到不确定，不晋升，也不据此扣为方法失败。普通任务通知仍沿用原语义；该切片不把通知中的“完成”改成“独立验证通过”。

## 持久化、恢复与容量

独立命名空间 `eve.task-strategy`、键 `strategies.v1`，格式 1。保存候选、父版本、选择、冻结评价合同和结果证据摘要；晋升、退役与回退由记录投影，不保存可单独切换的启用标记。

选择提交后才执行。安全恢复复用同一选择，不重新抽样；已有检查点但从未参与策略的旧任务不会中途加入试验。任务结束后策略结果未保存就退出，下次只从任务账本结算，不请求模型、重跑工具或重发通知。已经结算的源任务仍在时核对与通知无关的执行证据摘要，内容变化拒绝继续。

任务账本和策略账本不共用事务。若结束任务在结算前已被原任务账本淘汰，记录不确定，不凭摘要猜测成功。已结算的源任务被淘汰后保留既有结算摘要；备份应同时包含原任务及策略状态，以保留可追查的执行证据。

来源、版本与选择总计至多 256 条、状态至多 4 MiB，每个待结算选择预留 512 字节。容量满后不新增候选和选择，普通执行继续，已有选择可结算。不自动淘汰策略来源、不清空账本。重复 JSON 键、未知版本、非法父版本和损坏记录拒绝打开；保存确认失败关闭管理句柄，须重新打开核对，不能以旧缓存覆盖。

## 环境与能力组合

QQ 组合入口在提供 `task_strategy_policy` 时同时装配 `WorldModelPlugin`。`TaskCognition` 在实际执行前保存每个固定检查的预测，并在策略账本结算后用真实回执字段核对；环境或验收条件变化、缺失回执只记不确定。只投影合同指定字段，不保存整份工具输出。能力范围进一步绑定任务所有者、会话、环境和验收合同，历史成功率作为有来源统计传给后续来源任务与已启用方法的应用任务，不代替验收或授权。控制臂与试验臂不注入动态能力提示，以免把其他提示变化误归因于候选方法。

两个账本没有分布式事务。策略已保存而环境预测尚未保存时，首次执行前可幂等补齐；任务已有检查点或恢复次数时，不补造执行前预测。结算只处理本适配器命名空间且能在策略账本找到冻结合同的预测，不会封存其他模块的观测。世界模型容量满时停止增加预测，普通任务继续；其他保存错误阻止继续使用不可靠状态。

可信嵌入宿主可通过 `QqBotOptions.cognitive_services` 接收世界模型与统一记忆管理句柄。管理句柄不出现在聊天工具目录，启动回调失败时不启动通道。完整规则见[环境与能力模型](./环境与能力模型.md)、[长期目标持续推进](./长期目标持续推进.md)和[统一经历与保留集评价](./统一经历与保留集评价.md)。

## 仍需外部提供的条件

宿主必须提供真实运行环境指纹、训练任务与留出目录、只读独立检查工具及执行授权。正式 CLI 可读取由宿主维护的训练/留出目录，不接受聊天参数替代可信合同；当前没有自动生成任意任务验收标准的能力。跨领域泛化与真实模型效果必须通过独立任务进一步测量，不能从确定性回归测试推断。实现完成不等于运行版已经启用。

## 按来源读取对账证据

原生任务管理器现在通过 `TaskStrategyLearning::reconcile_from` 读取冻结来源的完整身份键；`TaskAdmin::evidence_snapshot` 在同一账本锁内只复制命中任务的正文，不再先复制所有任务。已结算来源仍读取并核对原证据，不能只挑待结算结果。世界模型组合随后也只查询策略来源，原任务验收、环境校验、候选生成与未知结果不重放规则保持。

该视图为 `TaskEvidenceSnapshot`，明确区别于完整 `TaskSnapshot`：指定键确实不存在返回缺失；未请求键返回不可用，不能把并发加入但未读取的新来源记为已回收。身份替换、重复 ID 和后续元数据错误拒绝整个视图；读取不修改任务账本，冻结视图不跟随之后的状态修改。提交不确定时原生管理句柄照旧关闭。

原完整快照接口和替换实现的默认兼容路径仍保留，旧策略不会收到伪装成完整快照的局部列表。持久格式、容量、预算、授权及派发次数均不变。任务常驻账本本身尚未冷存，选中正文与元数据仍占内存，不代表全功能恒定内存。
