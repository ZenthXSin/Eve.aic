# 生活接续与休息收尾

`set_focus` 是意识流的原生工具，由 Eve 整体维护自己的近期重心，每项有稳定 id、标题、active/parked/done/dropped 状态、原因和下一步。允许空清单，不自动生成任务。`expectedSeq` 按当前上下文的 focus.record 做版本检查；已提交的同一调用重启只补原回执，不再修改。历史保留在同一事实日志，沿用回滚排除机制。

重心每轮以原话附在上下文末尾，独立于随机事项浮现、通知和上一轮工具调用；跨压缩与重启读取最新有效记录，不额外调用模型或 RPC。历史长记仍可用现有便签维护。

原生 `rest` 必须是本轮唯一工具，携带 reason、unfinished、resume 与可选未来 wakeAt。决定和回执持久化后，下一次脉冲提交休息，先处理新到通知；有新消息或任务完成仍会唤醒。未完成事项不阻止休息，unknown 不自动重放。醒后上下文挂载上次休息决定，结合当前回执接续，不把旧打算当作仍然有效的命令。

兼容旧行为：启用本功能后，普通无工具结尾或旧 mind.rest 会先产生一条 rest_review，提供一次明确的睡前核对。Eve 可以继续行动，或用 rest 直接完成收尾；核对后仍只用文字结尾则保存其原话并休息，不无限追加模型检查。正常使用 rest 不增加收尾模型轮次。待核对状态持久保存，重启和压缩不会绕过。

生产远端实例默认启用；`eve.restReviewEnabled:false` 可用于旧行为兼容。直接构造 EveRuntime 的嵌入方通过同名配置显式启用。它不修改预算、主模型、权限或 QQ 消息策略。
