# EVE.AIC 项目企划案

## 1. 项目定位

EVE.AIC 的长期目标是构建一个以现有 LLM 为基础认知能力、具有持续内部状态和可演化能力的认知 Runtime。

第一阶段不实现完整 AGI，而是先建立可供未来认知层运行的操作系统底座：

> 一个稳定、可组合、可扩展、可持续运行的 Everything is a Plugin Runtime。

## 2. 核心思想

LLM 不是整个 AGI。未来的 Memory、Personality、Learning、World Model、Reasoning 和 Self Improvement 都应通过插件接入 Runtime。

内核只负责运行环境和安全边界，不负责具体认知能力。

## 3. 第一阶段目标

第一阶段使用 Rust 构建单进程、静态编译、可信插件 Runtime，验证以下能力：

- 插件注册和查找
- 插件依赖解析
- 插件生命周期管理
- Context 边界
- Event Bus 协作
- Service Registry
- 插件状态保存和恢复
- 生命周期绑定的任务管理
- 权限检查接口
- 资源自动清理
- Runtime 停止、重启和恢复

## 4. 长期方向

在内核稳定后，逐步接入：

```text
Cognitive State
Memory
World Model
Personality
Intrinsic Motivation
Learning
Capability Formation
Self Model
Meta Cognition
Self Improvement
```

这些能力不应反过来破坏内核边界。

### 通道隔离与统一认知的阶段关系

当前为首次交互测试、消息路由、并发控制和失败恢复设置的通道/会话隔离只是临时执行边界，不是长期的人格或认知划分。QQ、终端和后续通道都属于同一个 EVE 的感知与表达入口；Session 不应永久固定为互不关联的认知主体。

后续进入 AGI 与内生驱动阶段，目标是像真实的人一样，在持续的统一认知主体中关联跨通道经历，共享记忆、目标、经验、人格与内生动机。通道保留来源、用户和权限信息，统一认知不意味着忽略身份或公开不同用户的私有信息。

通道到会话/认知上下文的映射应集中在可替换的组合策略中；未来统一时迁移已有历史并保留来源和执行回执，避免重放旧工具或丢失状态。当前继续使用必要的路由隔离；有界内生反思已交付，统一长期记忆、跨通道经历迁移和完整 AGI 仍需后续切片。

### 外部交流与内部交流

2026-10-02 确认：外部交流与内部交流是同一认知主体的两类交流路径，共享核心状态、目标和记忆；模型角色、插件和通道不各自形成独立人格。

| 路径 | 输入与输出 | 作用 |
| --- | --- | --- |
| 外部交流 | 用户消息、环境观察、工具执行结果，以及面向用户或环境的输出 | 感知需求与变化，澄清、行动并反馈结果 |
| 内部交流 | 状态变化、驱动力评估、候选目标、议程、规划摘要与反馈 | 在没有新消息时也能选择关注点、推进目标并调整下一步 |

内部交流以结构化状态和事件为基础，需要推演时调用模型。内部工作记录按权限保存；对外输出由表达策略选取必要的答复、进度或澄清，内部事件不自动广播到 QQ 等通道。

两类交流都保留主体、来源、关联目标、版本、作用范围、访问权限和因果关联。统一记忆入口按访问权限选择可用经历，保留不同用户信息的边界。外部消息可以更新议程，内部驱动力也可以启动任务；执行统一经过现有 Control、Session、工具权限与生命周期检查。

### 从交互中学习表达方式与分段节奏

2026-10-03 新增要求：Eve 根据实际交互记录和用户纠正，逐步优化语气、称呼、回复长短和解释习惯，并学习像自然对话一样组织分段、停顿和等待回应。按用户确认，这项能力随长期记忆推进，先保存可追溯的交互证据，再学习用户范围内的表达偏好和分段策略。

分段属于同一轮回复，保持完整 Session 记录、Control/Message 代际、取消和回执恢复边界。统一主体不会合并不同用户的私有偏好；当前请求可覆盖旧偏好，学习结果可以查看、修正、重置和关闭。该能力尚未实现，设计与分阶段验收见[表达偏好与分段输出学习](./表达偏好与分段输出.md)。

## 5. 非目标

以下仅指最初的 Runtime 底座阶段，不限制上文已经启动的认知阶段。底座阶段不包含：

- LLM Router
- 向量数据库
- 完整人格系统
- 内生驱动和自主目标
- 自我改造
- 自动生成插件
- 在线插件市场
- 分布式 Runtime
- 任意 Rust 动态库加载
- 不可信代码沙箱
