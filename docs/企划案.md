# EVE.AIC 项目企划案

## 1. 项目定位

EVE.AIC 的长期目标是构建一个以现有 LLM 为基础认知能力、具有持续内部状态和可演化能力的认知 Runtime。

第一阶段不实现完整 AGI，而是先建立可供未来认知层运行的操作系统底座：

> 一个稳定、可组合、可扩展、可持续运行的 Everything is a Plugin Runtime。

## 2. 核心思想

LLM 不是整个 AGI。未来的 Memory、Personality、Learning、World Model、Reasoning 和 Self Improvement 都应通过插件接入 Runtime。

内核只负责运行环境和安全边界，不负责具体认知能力。

## 3. 第一阶段目标

第一阶段使用 Rust 构建单进程、静态编译、可信插件 Runtime，验证以下能力：

- 插件注册和查找
- 插件依赖解析
- 插件生命周期管理
- Context 边界
- Event Bus 协作
- Service Registry
- 插件状态保存和恢复
- 生命周期绑定的任务管理
- 权限检查接口
- 资源自动清理
- Runtime 停止、重启和恢复

## 4. 长期方向

在内核稳定后，逐步接入：

```text
Cognitive State
Memory
World Model
Personality
Intrinsic Motivation
Learning
Capability Formation
Self Model
Meta Cognition
Self Improvement
```

这些能力不应反过来破坏内核边界。

## 5. 非目标

第一阶段不包含：

- LLM Router
- 向量数据库
- 完整人格系统
- 内生驱动和自主目标
- 自我改造
- 自动生成插件
- 在线插件市场
- 分布式 Runtime
- 任意 Rust 动态库加载
- 不可信代码沙箱
