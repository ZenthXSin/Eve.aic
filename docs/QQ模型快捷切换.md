# QQ 主模型快捷切换

- `/model`：查看当前主模型与用法，普通用户也可以查询。
- `/model grok-4.7`：主人或管理员全局切换主模型；模型名使用当前模型服务实际支持的名称。

切换只更新当前生效配置中的模型名。直接配置使用 `provider.openai.model`；显式选择 primary 角色时使用 `runtime.models.primary_model`。接口地址、密钥、输出上限、超时与工具预算保持不变，不改变其他模型角色。

配置通过公开的 `ConfigAdmin` 契约原子保存，使用修订号避免覆盖并发修改；损坏配置或写入失败不报告成功，不清空原记录。重启后沿用保存的模型名，同名设置不会重复写入。该写权限只在宿主组合层授予 QQ 命令，不作为公共服务注册。

新任务捕获最新模型配置，已开始的任务和同轮工具往返继续使用原模型与已有上下文，不因切换重放工具。沿用主模型的后台用途在其下一项工作时生效，因此这是全局设置，不是单个 QQ 会话的独立模型。

切换指令本身不调用供应商，也不声称已验证模型可用；名称是否被服务支持，由下一次实际模型请求确认。参数为空以外的非法格式、超过 200 字节、多余参数和内部控制字符会显示用法且不修改配置。
