# 行动审核工具协议

审核模型只看到本次审核上下文，并且只能提交一次 `submit_review`：风险、授权、放行/拒绝和最多 300 字理由。该工具只返回判定数据，没有文件、命令、网络或执行能力。动作由原宿主在复核权限、审核等级和有效授权后执行，不能由审核模型直接执行。

普通文本、未知工具、多次提交、缺字段、未知字段或越界输出均视为审核失败；不把“审核通过”等自然语言当作授权，不从失败回退到默认放行。最近六条用户正文继续完整保留，工具轨迹仍有界。

健康面板在协议核验完成后记录结局：合法的拒绝也表示审核服务正常，HTTP 成功但输出无效计为协议失败。日志只记录固定类别和风险、授权等级，不输出供应商错误正文。

上游必须保留系统和工具指令。内容拦截应返回错误，不能通过删除审核规则重试。网络发送日志区分 DNS、连接、TLS 和超时；结果不确定的 QQ 消息仍不自动重发，避免重复投递。
