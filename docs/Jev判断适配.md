# Jev / SystemOne 判断适配草稿

`eve-jev` 是独立 HTTP 实现，消费 `eve-message-api::RelationJudge`，不依赖 Kernel 私有实现，也不执行工具或控制动作。协议依据 TypeSafe 官方 Python SDK 固定版本 [`f078f1e`](https://github.com/typesafe-ai/typesafe-sdk-python/tree/f078f1e208a0d885154dc758344ae4fce77ac168)：`POST /v1/systemone`，Bearer 凭据，输入 `state/model/questions`。

当前草稿可编译并有真实环回 HTTP 验收；尚未接入终端/QQ 入口，未自动读取环境或 `runtime.models`，不代表当前机器人已使用 Jev。配置由可信 Rust 宿主明确构造 `JevConfig` 并单独传入密钥。默认 API 为 `https://api.typesafe.ai`，模型为 `jev-latest`；已有主模型密钥不能自动用于 Jev。

一次请求同时询问 `choice` 的单意图关系与 `noul` 的完整单意图条件。只有无需裁剪、整条用户原文可直接使用时，才在本地绑定 UTF-8 全文范围；不生成修订文字。多意图、需要切分、不确定或无当前引用的答复交回现有宿主回退。分数取 choice 自评、选中概率和 noul 概率的最小值再向下取整；概率未经实际数据校准，不代表真实正确率。宿主仍须执行完整代际、作用域、阈值、副作用和原文校验。

HTTP 只允许 HTTPS 或本地环回 HTTP；不跟随重定向、不自动重试。并发满立即返回不可用，期限限 1–60000 毫秒，至多 32 个并发；JSON state 不超过 65536 字节，响应不超过 16384 字节。请求只发送当前任务和最新消息的必要文字，不带路由 ID、epoch、完整历史或工具参数/结果；文字自身可能含敏感信息，不声称自动匿名化。错误只返回公开枚举，不输出密钥、正文或原始 Provider 报错。

适配器不持久化判断、不写学习状态。Future 取消释放 HTTP 请求与并发额度，不保证远端停止；恢复后不得重放旧判断或工具。正式启用、角色配置、主模型回退的组合装配及同标注集质量对比仍待接手完成。

接手顺序：

1. 审查本草稿和实际 CI，保留默认纯规则；把 `runtime.models` 的 Jev 角色、独立凭据和 API 地址接入宿主，不把读取密钥交给插件或 Node。
2. 用已有 `RelationPlugin::with_fallback` 接入“明确规则 → Jev → 每轮解析的主模型 → 澄清”，验证共享总期限、低置信度和一次回退。单选不能替代复杂多意图/原文分段；这些必须继续走内置判断。
3. 为 QQ 增加明确开启的在途消息关系判断，默认普通消息继续排队；确认零工具原文修订、已执行工具保护、旧代回复抑制、会话隔离和停止恢复。不得仅安装判断服务后就宣称 QQ 已接通。
4. 在独立公开标注样本上比较规则、主模型和 Jev：误取消、纠正遗漏、任务完成率、期限、延迟、请求数和回退率；真实语义质量与环回协议测试分别报告。
5. 获得专用配置后再做真实接口验收；未经这些验收的辅助判断不在正在运行的正式训练中启用。
