# QQ 对话复核：这一句该怎么接？

以下是独立写的虚构场景，不是聊天摘录，也不放进提示词。可以用纸面拟答和模拟动作复核，不读私聊、不连模型或
QQ。箭头是下一轮；到那一轮才给新事实，不能用它为前一轮的猜测补证据。

**怎么记：**
每轮记场景编号、候选原句（或未发）、可见的模拟动作和回执，再写「通过／不通过／未观测」及一条理由。按是否接对人、事和时机判断，不按关键词、字数或是否照抄某句打分。只看到文字时可以评措辞，不能据此判定没用工具或已经送达；缺动作证据就把该项记为未观测。
