# 群聊自主交流

QQ 全量群观察把经过平台身份校验的原话交给 Eve。宿主保存事实、限制工具与发送范围、可靠传输；是否开口、何时开口和正文均由同一个 Eve 对话模型决定。出现名字、被回复、关系分类和冷却结束都不会强制它说话。

`eve-qqbot --group-chat` 接收平台实际提供的全量群事件。被提及和名称前缀消息仍进入普通对话，观察后台只保存原话，避免双重回复。命令只推进可信入站锚点，不保存命令正文用于观察或训练。平台是否提供全量事件与主动消息配额仍取决于机器人权限。

## 模型决定与发送

群后台使用 `ChimeEngine::autonomous`，经正常控制服务读取当前群的锚定消息窗口和已有记忆。该群会话的内部身份为 `eve-chime`，不具有工具、管理员或私人记忆权限。生产路径不先调用独立 yes/no 判断器。最终输出只作为内部决定保存，严格接受三种 JSON：

| 决定 | 含义 |
| --- | --- |
| `{"action":"speak","text":"完整一条消息","after_ms":0}` | Eve 决定发送这条原文，可延后 0 至 60000 毫秒。最多 2048 个 UTF-8 字节；宿主不切句、不添加停顿、确认语或称呼。 |
| `{"action":"wait","after_ms":1000}` | 1000 至 86400000 毫秒后重新审视事实，届时仍可沉默。没有正文，不占发送机会。 |
| `{"action":"silence"}` | 结束本次观察的交流决定，没有平台发送或伪造的送达结果。 |

多余字段、普通文本、代码围栏和无效决定不会变成兜底消息。模型失败与取消保留待复审事实，至少等待一分钟；进程中断的审视在重启后以新版本重新判断。只有真实确认送达的正文才进入已回答问答、节奏记录和交流学习。

渠道通过只读 `authored_pushes(after, limit)` 分页扫描已决定的正文，过滤无权限或暂时无路由的群时仍向后推进游标。一页最多 64 条，不修改正文、不提前认领、不把被挡住的记录结算为未知。最终发送前 `claim_authored_push(expected)` 原子比较同一正文、决定版本、身份、到期时间和全群最新人类消息。此后单条发送携带真实观察锚点；SDK 发送前再次核对新鲜度，包括未艾特或被前缀过滤的群消息。

## 配置与预算

`runtime.chime.enabled=false` 继续保存可观察原话但停止新交流审视。`judge=quiet` 暂停模型审视和发送；恢复 `model` 后仍由 Eve 自己决定。冷却、每小时次数、窗口大小、判断超时仍是资格限制，不能替代模型决定；实际送达才消耗群回复次数。`min_confidence` 仅供旧判断器兼容，生产三态路径不依赖自评分。

每次实际模型请求在 `ProviderStarted` 事件、请求发出之前预留 `chime` 自主预算，额度不足即阻止该请求。关系事后整理保留独立预算，只学习后续人类证据，不授予说话许可。

上次发言时间和每小时次数从持久的已确认问答统计，独立于原话窗口；新消息挤出窗口或进程重启不会刷新已消耗的次数。等待、排队、失败和未知投递不冒充已确认发言。

## 持久化与恢复

原话、真实平台锚点、待审视事实在 `group-observations.sqlite3` 同一事务登记。格式为 4，兼容迁移格式 1、2；未知格式、结构损坏或 required 标记存在而数据库缺失时拒绝打开并保留原文件。独占锁防止第二个宿主错误恢复仍在执行的轮次。升级前应停机复制完整状态目录；旧版本二进制不能读取新格式。

存储所有者退出时先关闭数据库连接，再显式释放独占文件锁；其他线程启动子进程暂留的复制描述符不延长旧所有者的锁。取得锁后的打开、校验或恢复失败也会释放锁并保留原错误。正常存储实例仍存在时，第二个宿主继续被拒绝；旧复制描述符随后关闭不影响新所有者的独占锁。此修复不修改数据库格式、原话、等待时间或投递恢复语义。

审视状态为 pending、evaluating、waiting、ready、silence 或 stale，实际投递进入 sending 后才等待平台回执。未认领的 ready/queued 在重启后保留；waiting 保留复审时间；silence 不重放。正在发送而结果无法确认的记录成为 unknown，绝不自动重发。新的人类消息使旧候选 stale/cancelled，属于决定过期，不冒充失败、未知或送达。原始平台事件重复出现不推进锚点，不让旧消息复活。普通群消息和命令均可令旧决定失效；其他群互不影响。

`eve-chime` 标准输入示例也使用同一三态引擎，但不提供 QQ 的持久复审调度。真实进程验收使用本地模型和 QQ 替身，覆盖沉默、等待跨重启、失败不重发、单条原文、真实 Node 桥接与实际送达后的记忆。更早原话的按需检索见 [群消息上下文与按需召回](./Jev群聊关联与积累.md#群消息上下文与按需召回)。
