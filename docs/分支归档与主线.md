# 主分支与历史归档

2026-11-12，按用户确认，将仓库全部分支历史归入 `main`，主分支继续维护当前 TS / Deno Eve。

本轮审计覆盖 525 个远端分支及 14 个本地分支引用。当前实现已包含所有有效 Deno 重建功能；
尚未进入当前提交的历史可由 39 个最大提交覆盖，其中 38 个为旧 Rust 分支，另一个为空白重建根。
旧 Rust 与当前实现没有共同祖先。

依照[设计文档](./设计文档.md)“旧 Rust 仓库只作参考，代码不迁移”的约定，
这些旧分支使用保留当前源码树的历史归并方式接入。合并父提交保留原始提交、分支开发历史及源码，
可以通过 Git 查阅；当前运行代码和开发基座保持 TS / Deno，不重新引入旧 Rust 工程或依赖。
已有分支不删除，不强制覆盖远端提交。归并后校验原分支提交全部是 `main` 的祖先，
并检查历史合并前后源码树相同，再正常快进推送主分支。

后续功能开发以 `main` 为基线；Web 管理面板源码、浏览器历史模块、样式及测试均随仓库发布。
