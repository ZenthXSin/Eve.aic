# 通用任务策略账本

公开契约位于 `eve-task-api`，可替换实现位于 `eve-task-plugin`。`TaskStrategyPlugin` 不执行模型或工具；宿主提供当前范围指纹、执行前固定验收合同、训练和留出任务。后台组合由后续集成 PR 接入。

`PairedTaskStrategyPolicy::with_training_cases` 从真实“检查不符、工具纠正、最终检查通过”的执行轨迹提炼方法候选，不复制工具参数、正文或模型自述。训练输入与留出输入隔离。两个不同留出输入分别完成控制臂与试验臂、实际效果通过且工具及模型次数不超过基线，才晋升；退步拒绝候选并恢复仍有效的版本。插件不自动派发或重复试验任务。

验收依固定工具名、参数、输出字段和期望值读取最后批次的真实回执。缺失检查、未知副作用、环境变化和取消均记不确定；模型声明完成不能晋升。按用户、会话、任务类别及环境版本隔离，不授予额外权限或预算。

`eve.task-strategy/strategies.v1` 独立保存来源、版本、选择、合同与观察，格式1，旧记录的 `sources` 缺省为空。最多256条来源/版本/选择、4MiB，待结算记录预留空间。容量满停止新增，已有记录继续结算，原任务仍可执行。保存不确定时关闭句柄；重复JSON键、损坏、版本不支持拒绝加载，保留现场。

恢复沿用原选择，已有检查点的旧任务不补登记试验。结局已保存而策略未结算时只读取回执补结算，不重放工具。源任务在结算前被淘汰只能记不确定；已经结算的源任务淘汰后保留摘要。备份需同时保留任务与策略账本。

测试覆盖独立留出晋升、成本回退、身份与来源隔离、真实回执、委派用量、自动提炼、重启幂等和损坏拒绝。真实模型泛化质量及正式部署不在这些测试结论内。
