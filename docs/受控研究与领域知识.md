# 受控研究与领域知识

[首个自主学习目标](./自主学习首个目标.md)（#134）的第二个切片。[兴趣观察](./兴趣观察.md)派生的学习目标会在后台，到操作者允许的资料范围内自主研究。研究结果保存为独立的领域知识，带来源网址、抓取时间、适用版本和逐字引用；模型推测单独标为未验证。

本切片只交付“研究 → 有来源的知识”。实践记录（Eve 自己做过的尝试、失败与真实运行证据）要等第三个切片有了实际运行器才有来源，届时再定义，不在这里预留空壳。“来源原文”只说明网页这样写，不代表 Eve 已经验证过。

## 启用

```bash
./target/debug/eve-qqbot --state-dir .eve-qqbot --interest-learning \
  --research-source https://example.org/docs/modding/index.html
```

`--research-source` 可重复，至多 8 个，必须同时开启 `--interest-learning`，默认不研究。入口页面须是 http/https URL，不含用户信息和 `#` 片段，规范化后不能重复。参数无效时在启动桥接、创建状态之前拒绝。研究复用主模型配置与 `EVE_OPENAI_API_KEY`。

- `/knowledge 兴趣ID`：查看为这条兴趣研究到的资料。来源原文附网址、抓取时间（UTC）、版本和原文片段，未验证推测单独标注，最多显示 8 条。
- 还没有资料时，命令说明最近一次研究的状态：进行中、没有找到可引用资料、失败原因或因进程退出而中断。
- 只能查看当前会话自己的兴趣；没有配置入口页面时回复“受控研究未启用。”。

## 访问范围

允许访问的范围由入口页面决定：同一协议、主机和端口下，入口页面所在目录及其子路径。例如入口 `https://example.org/docs/modding/index.html` 允许 `https://example.org/docs/modding/` 下的页面，不允许 `https://example.org/private/` 或其他主机。

- 模型不能引入新的 URL，只能按下标从已发现的候选链接中选择。候选只来自本次实际抓到的入口页面中、位于允许范围内的链接，入口页面本身不作为候选。
- 抓取器只发只读 GET，不带 Cookie 或凭据，也不执行脚本、不加载页面引用的其他资源。
- 重定向逐跳核对，目标离开允许范围即放弃，最多跟随 3 次。
- 只接受 `text/html`、`application/xhtml+xml`、`text/plain`、`text/markdown`。响应超过 1 MiB 即放弃，单次请求 15 秒超时。
- HTML 只保留可见文字、标题和站内链接；脚本、样式和注释都丢弃。正文保存前 8 KiB，超出部分标记截断。
- 学习目标描述（含用户原话）只交给模型，从不发送给任何网页；网页只收到固定 URL 的 GET。

## 一次研究的过程

每个等待中的兴趣学习目标（`Inference / interest.learning`，状态 Waiting），每个目标修订至多研究一次，一个目标累计至多 3 次。同一时间只研究一个目标，按优先级与 ID 排序。用户待办、反思子目标、已取消或已完成的目标都不研究；撤回兴趣后不再研究，已保存的资料仍可查看。

| 阶段 | 先保存 | 再执行 |
| --- | --- | --- |
| 准入 | Running 研究记录、目标修订与当时的入口页面 | 抓取入口页面 |
| 选择 | 入口抓取结果、来源文档、至多 40 个候选链接 | 一次无工具的来源选择请求，按下标选至多 3 个 |
| 抓取 | 选择结果 | 抓取所选页面 |
| 提炼 | 所选页面的抓取结果与来源文档 | 一次无工具的知识提炼请求 |
| 结局 | Completed 及合规知识，或 Failed 与原因 | — |

整次研究最长 180 秒。入口页面全部不可达时直接失败，不请求模型；没有候选、或模型认为都不相关时，以“没有找到可引用的资料”完成。

## 知识的核对

提炼器只能输出两类内容：

- **结论**（fact / procedure / version）：必须引用所给文档正文的连续片段，忽略空白差异后逐字匹配，至少 8 个非空白字符。版本号必须在该文档正文中逐字出现，没有就写 `null`。statement 是模型对引用的一句概括。
- **推测**（hypotheses）：正文没有直接说明、需要后续验证的内容，不附引用，保存为 `Unverified`。

任何一条不合规，整次研究记为 `InvalidOutput`，不保存任何知识。已抓取的来源文档仍如实保留。

两类请求的系统提示与领域无关，不含任何游戏名或关键词。网页正文无论怎样措辞都作为不可信数据交给模型，不能改变规则，也不授予任何执行能力：知识只是可查看的记录，不触发工具、命令或消息。

| 字段 | 含义 |
| --- | --- |
| `status` | `SourceQuoted`：附有来源原文；`Unverified`：推测 |
| `source` | 来源文档 ID 与逐字引用；推测为空 |
| `version` | 适用版本，须在来源正文中出现；未注明为空 |
| `goal_id`、`owner` | 研究所服务的学习目标及其可见用户 |
| 来源文档 | 最终 URL、首次抓到该内容的时间、内容类型、完整响应 SHA-256、字节数、标题与正文 |

同一目标下，同一来源文档的同一引用、或相同的推测只保存一次。之后的研究记为 `Duplicate`，指向已有条目。

## 持久化与恢复

知识账本 `eve.knowledge/knowledge.v1` 经公开 StateStore 保存，文件与 PostgreSQL 后端语义相同。它包含研究记录（各阶段输入、抓取结果、选择、合规输出与逐条结果）、来源文档和知识条目。

| 情况 | 行为 |
| --- | --- |
| 保存准入或阶段失败 | 不执行下一项抓取或模型请求；关闭账本句柄，下次打开读到实际提交结果 |
| 重启发现 Running 研究 | 记为 `Interrupted`，保留到达的阶段，不重放，不伪造完成时间；该修订不再研究 |
| 抓取失败、模型失败、超时、服务停止 | 记为 `Failed`（`Fetch`、`Provider`、`InvalidOutput`、`Timeout`、`Cancelled`），不重试 |
| 兴趣有新的原话 | 学习目标修订提高，可再研究一次，直到该目标累计 3 次 |
| 研究记录 64、来源文档 96 或知识 256 条已满 | 停止新研究（或本次记为 `LimitReached`），不淘汰旧记录；条目已满时新结论记为 `Rejected` |
| 账本损坏、有重复键、版本未知，或引用不在来源正文中、文档无研究引用等不一致 | 拒绝启动，保留原字节，不清空 |

研究不写认知状态：学习目标的状态和修订仍只由兴趣派生器维护。研究次数持久计数，重启、重复事件都不会放大预算。

## 分层

| 层 | 内容 |
| --- | --- |
| `eve-knowledge-api` | 来源策略与范围判定、研究主题、阶段与结局、来源文档、知识条目；可替换的 `KnowledgeAdmin`、`SourceFetcher`、`SourceSelector`、`KnowledgeExtractor`；纯函数 `validate_extraction`、`validate_selection` |
| `eve-knowledge-plugin` | 持久账本与启动核对；`HttpSourceFetcher`（只读 GET、逐跳范围核对、大小与类型限制、HTML 转文本）；`ModelSourceSelector`、`ModelKnowledgeExtractor`（各一次无工具请求、严格 JSON）；串起各阶段的 `Researcher` |
| `eve-app` | QQ 后台研究循环、`/knowledge`、参数校验；`run_qqbot_with_interest_components` 可替换观察器、抓取器、选择器与提炼器 |

## 验收边界

- Rust 测试覆盖：账本的阶段持久化、去重、累计上限、中断与损坏处理；本机 HTTP 服务上的抓取范围、重定向、大小、类型与链接过滤；两类模型请求的严格输出与失败处理。
- 真实 `eve-qqbot` 进程测试（`connectors/qqbot/test/research_test.py`）使用本地文档站点和确定性模型替身，覆盖：
  - 一次普通聊天到有来源知识的完整过程，只访问允许范围、各阶段先保存；
  - 网页注入文字只作为数据；
  - 重启不重放，其他会话看不到；
  - 撤回后停止研究，留出领域复用同一规则；
  - 引用不合规、来源不可达、模型失败均不保存知识、不重试；
  - 提炼途中强杀后记为中断；
  - 未配置时不研究，参数无效时拒绝启动。

以上只证明宿主契约与恢复语义，不代表真实模型的选择与提炼质量，也没有访问真实网站或正式 QQ。下一切片是最小模组的真实运行验证与实践记录，届时知识状态才可能因实践证据而改变。
