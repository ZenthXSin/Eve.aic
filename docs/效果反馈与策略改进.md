# 效果反馈与策略改进

首个切片接入已有真实运行器的实践链路：从失败后修正成功的记录形成版本化方法实例，在后续不同目标中试用，再按实际验证结果保留或回退。无需增加聊天命令或要求用户逐项确认。

## 启用与执行

QQ 启动参数增加 `--strategy-learning`，需要同时开启兴趣学习和一个实践运行器。默认关闭；管理员在部署时开启后自动工作。它独立于技能固化和工具锻造，可以组合开启。

1. 实践最终验证通过，且此前至少有一次结构拒绝或实际运行失败，才可能成为候选来源。保存完整任务、草稿、运行证据和草稿器版本，方法实例由宿主确定性生成，不额外请求模型。
2. 候选和选择均绑定来源用户、完整运行器声明（包括运行环境摘要）及草稿器版本，不跨用户或不同运行环境复用。
3. 后续目标的首次草稿前先持久保存选择，再把历史警告和修正后的产物作为 `guidance` 数据交给草稿器。当前目标与运行器规则优先，旧文件、名称和探测期望不直接当作新任务答案。后续修正沿用同一选择。
4. 原目标的新修订不作为独立验证，去掉空白、大小写后与原题相同的描述也不作为独立验证。同一候选在同一个目标或相同描述中最多试用一次。此去重是确定性规则，不能识别所有同义改写。
5. 两个不同目标、不同描述的实践都实际验证通过，且尝试次数不超过冻结基线，候选才晋升。晋升后的比较上限收紧为这两次验证的最大尝试次数。
6. 实际运行完成但未通过，或虽通过却超过比较上限时，拒绝该版本。若它已启用，恢复最近仍有效的旧版本；没有旧版本时回到原草稿流程。被回退的记录保留，不自动重试。

首版基线是来源修正所花的尝试次数；已有启用版本时，取其当前上限与来源次数的较小值。因此规则只会收紧，不因失败、重启或新增目标而放宽。不同任务本身存在难度差异，这是一种保守的采纳与回退规则，不是同题对照实验，不能据此声称因果提升或模型能力提高。

## 预算和已有能力

不增加模型请求、每次实践至多三次尝试的上限、实践次数或自主运行预算。策略只影响已有草稿请求的输入。选中策略时直接进入草稿，避免技能选择器返回预制实例却被误记为策略验证；没有选中时照常优先尝试已验证技能。原有运行前检查、工具锻造和运行器权限不变。

自定义草稿器必须通过 `supports_guidance` 显式声明支持，未声明时不能装配策略功能。`PracticeStrategy` 可替换，不能靠自述成功晋升；内置实现只接受实践账本中已保存的实际结果。策略数据只供学习方法，不是系统提示、偏好、工具授权或可执行插件。

## 持久化与恢复

独立命名空间 `eve.practice-strategy`、键 `strategies.v1`，格式版本为 1，保存 `Proposed`、`Selected` 和 `Observed` 事件。启用、退役、拒绝、验证次数和父版本从事件重新推导，不持久保存一个可独立修改的启用标记。备份仍需完整状态后端，不能只备份策略事件而省略原实践账本。

- 启动先恢复实践账本，再逐一核对策略来源和已结算结果的完整摘要；缺失或被改写的实践证据拒绝启动。对账只读取已有结果，不运行旧草稿。
- 取消、进程中断、模型接口失败、不适用或运行结果不确定，记录 `Inconclusive`，不晋升、不扣成策略失败，也不自动重放。
- 选择已经提交而模型尚未执行时退出，重启按对应实践的中断结局对账；实际实践已经提交而策略未结算时退出，则从已提交结果完成结算。
- 重复对账不新增事件；策略自己试用产生的修正不立即再形成下一版候选，避免自我循环试验。
- 重复键、未知版本、非法父版本、伪造晋升顺序或损坏状态拒绝打开，保留原字节。写入确认失败会关闭当前句柄，重新打开读取真实提交状态，不能拿旧缓存覆盖。
- 独立账本至多 256 个事件、4 MiB，选择时预留结果空间。满后停止新增候选与选择，普通实践继续使用原流程，已有结果仍能结算。不淘汰原证据、不自动清空数据。

## 范围与验收

这是实践方法实例复用，不是通用编码、任意工具编排、子代理分工或自动改写系统提示。范围按运行器和草稿器版本绑定；首版未建立跨模型版本的对照评测，不把运行模型切换后的结果宣称为某个模型的提升。更完整的策略搜索、同题对照和通用任务适配继续独立推进。

Rust 测试覆盖双目标晋升、原题排除、用户/运行器/草稿器隔离、尝试成本回退、父版本恢复、取消与崩溃对账、提交前后失败及损坏保护。`connectors/qqbot/test/strategy_test.py` 运行真实 QQ 宿主，通过本地模型和平台替身核对请求前落盘、跨进程复用、失败结算和零重放；配置 `EVE_MINDUSTRY_SERVER_JAR` 时另走真实游戏运行器。替身通过不代表真实模型质量或正式 QQ 体验通过。

真实模型合成场景补验：通过生产 SDK 的 `ModelPracticeDrafter`，将历史生命值 520 的修正夹具作为数据，分别生成生命值 700 和 900 的独立作品，两项都经真实 Mindustry 160.7 验证且无警告。首测返回 Markdown 而未通过严格协议检查；补充宿主输出格式约束后通过，原失败记录保留。这是有限合成场景，不是正式 QQ 真人质量结论。复现入口为 `cargo run --release -p eve-app --example practice_strategy`，需要模型环境配置和 `EVE_MINDUSTRY_SERVER_JAR`；只输出核验结果，不投递 QQ 消息。
