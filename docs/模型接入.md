# 模型接入与测试边界

`plugins/model-chat/` 实现一次 Chat Completions 请求；`composition/model.ts` 按私有配置生成
插件入口与清单。模型插件只有启用时才读取密钥，加载阶段只注册处理器。换版或关闭时取消本实例
在途请求；健康探测只检查已启用，不为探测额外调用模型。

当前沿用本机原配置：`gpt-6.1-sol`、high、原中转地址、独立密钥文件。代码仓库没有真实密钥、 AppSecret
或包含它们的配置。模型切换仍由外部配置完成，本批没有替用户换模型。

## 请求与结果

- 使用 `/v1/chat/completions`，已有 `/v1` 前缀不重复追加。
- 不设置 temperature；思考强度按配置发送，未配置则省略。
- 一条 Eve 意识流使用同一配置会话标识，发送 `session_id`、`X-Session-ID` 与
  `prompt_cache_key`；不放当前轮次、用户、时钟或进度到这些字段。这只是稳定请求条件，不能
  保证上游支持它们或据此承诺缓存命中率。
- 函数定义必须带真实参数 Schema，工具调用与回传编号配对；未配对历史、未注册的工具、坏 JSON
  参数和截断终答不被当作正常成功。
- 纯工具响应允许 content 为 null 或省略；空的最终回答仍报无效响应。不会把上游坏响应
  偷换成普通文本或自动再次请求。
- 取消、超时、HTTP 拒绝与无效回包分别作为错误传播；没有隐式网络重试或模型修复请求。
  这些错误不携带服务端任意正文、凭据、URL 或 fetch 原始异常。
- 请求读取受超时和响应字节上限约束；超时覆盖响应体读取，不只等响应头。
- 用量来自实际响应。缓存字段缺失保持未知，明确 0 保留 0，非法统计标注 invalid；这些
  字段是上游报告，不能证明上游是否由真实缓存计数或自行合成。正式运行已接独立共享预算账本，所有在线意识、图片描述和升级观察请求统一核算。

## 组合与验证

组合函数在指定私有目录生成 `mod.ts` 和 `manifest.json`。清单只允许模型 worker 读指定配置、
指定密钥文件和模型代码目录，并连接配置的模型主机。生成入口只有配置路径，没有密钥正文。
仓库不提供默认可运行的模型清单，以免新部署误读别人的私有配置。

本地测试用真实回环 HTTP 与真实内核 worker 覆盖函数调用/回传、固定前缀和会话字段、缓存统计
未知/零值/非法、无效模型响应、拒绝、超时、字节上限及凭据不进入生成入口和回执。

`demo/check-model.ts` 是显式执行的两次真实模型探针，只测 echo 工具往返，不连接 QQ，不启动
自主循环，不证明编程能力、自然分条、交流时机或记忆学习。探针是测试经历，不写入真实意识流。

## 正式运行与上游拒绝

正式持续意识由 `plugins/eve` 承载，内核 `turn-loop`
保留为演示；手机、原生脚本、动作回执、提醒、稳定身份与契约、预算和所有权均已贯通。 QQ
交流原则真实加载，主人平台身份已由私信核验，Eve 已发一次上线通知。真实回复结果与当前部署状态以
`docs/整体验收.md` 为准。

永久性 HTTP 4xx（408/409/425/429 除外）以脱敏 `provider_rejected`
分类传播。在线主意识的原请求拒绝后停止自动重试；QQ 通知、闹钟、普通暂停恢复和服务重启不清除状态。
共享出口可从既有动作账本恢复该状态，管理面板显示 HTTP
状态和请求编号。独立图片请求或观察者失败不自动锁死主意识；暂时性错误保留既有有界退避。

管理员须先暂停，再对当前 blocked requestId 明确执行 `resumeModel`；此操作追加不可变 `model_resume`
管理事实，保持运行暂停。是否恢复真实模型请求仍由管理员决定，不删改旧失败和历史内容，不修改模型或渠道来消除拒绝。
2026-11-12 的真实连续400已通过上游日志核对为 AgentRouter:
content-blocked；同一真实请求在本地通过结构和工具配对校验，未为诊断重复请求模型。
