# Eve 核心对话入口

`eve-app` 是独立组合层，`eve` 二进制把已有 AGENT、普通配置、Responses Provider、Runtime、Session 和插件工具装配成连续聊天。Kernel 和通用定义层不依赖此应用。

## 启动

在仓库根目录设置宿主环境，再启动：

```powershell
$env:EVE_OPENAI_MODEL = "<支持当前 Responses 子集的主模型>"
$env:EVE_OPENAI_API_KEY = "<宿主凭据>"
# 支持 none 的模型可显式设置：
$env:EVE_OPENAI_REASONING_EFFORT = "none"
cargo run -p eve-app --locked -- --state-dir ./.eve --agent ./AGENT.md
```

可选 `EVE_OPENAI_BASE_URL` 接受 API 根地址、版本路径或完整 Responses URL；生产使用 HTTPS，本地验收可使用 loopback HTTP。其余普通字段为 `EVE_OPENAI_TIMEOUT_SECONDS`（默认 120）、`EVE_OPENAI_MAX_OUTPUT_TOKENS`（默认 2048），由 `provider.openai` Schema 提供。配置文件覆盖环境，环境覆盖默认；空模型拒绝启动。模型能力和协议子集沿用[OpenAI 接入](./OpenAI接入.md)，不默认假定任意模型兼容。

输入每行是一轮；空行忽略，`/help` 显示说明，`/quit` 或输入结束后停止所有插件并刷新日志。UTF-8 单行上限 32768 字节，超大行完整丢弃并提示，不截断后当作用户要求。示例：

```text
你好，介绍一下自己。
请调用 echo 回显“核心工具测试”，然后告诉我实际返回内容。
上一轮工具返回了什么？
/quit
```

本切片串行且非流式：先执行工具和完成会话提交，再输出完整回复；使用 `runtime.llm.max_parallel_tool_calls` 约束工具批次。若配置选择 stream，明确报错。现有流事件、取消和消息关系服务仍由各自示例验收，尚未接入此终端；进行中的轮次不消费新的终端命令。强制终止后的状态按会话恢复语义处理，不承诺远端停止或副作用撤销。

## 身份、会话与工具

默认读取本次工作目录的 `AGENT.md`，也可用 `--agent` 明确指定。身份在启动装配时只读一次，本进程轮次和工具往返共享快照；重启读取新版本。缺失或无效身份在打开状态目录前失败，不创建或回退身份。

`--session` 默认 default，`--user` 默认 owner；同一状态目录和相同标识恢复完成历史。用户绑定是宿主提供的逻辑隔离，不是认证。状态根目录保存 `state.json`，普通配置位于 `configuration/config.json`；仅读取默认/环境配置不自动创建配置文件。目录独占、严格恢复和原子提交沿用既有插件；坏文件拒绝启动，不自动清空。

Context 插件提供空资料/记忆/历史，避免虚构用户信息或重复会话历史。echo 是一个可验收的本地插件工具，只回显收到的 text，不访问文件或网络；参数先校验，执行仍受 Runtime 的插件状态、权限和生命周期约束。当前至多一个工具批次，不加入任意代码执行、文件操作或新工具路由。

会话只保存本轮用户输入、完整工具批次/结果和最终回复；身份不作为历史保存。重启只把旧工具作为配对历史送入模型，不执行它们。Provider 失败记录 Failed，失败输入不进入 Completed 历史；后续输入作为新轮次，没有自动重试。最终保存失败时尽力显示已生成回复并停止输入，组合 API 保留带完整输出的原始错误；磁盘保留 Pending。不能再次执行模型/工具来“修复保存”。退出/停止/日志错误全部检查，不静默丢失收尾错误。

凭据只从宿主环境进入 Provider，不写入普通配置、会话、提示词或诊断。普通配置与 Provider/身份在本进程装配时固定，修改后重新启动。

## 验收与下一步

```powershell
cargo test -p eve-app --test console --locked -- --nocapture
```

测试启动真实 eve 子进程，连接随机 loopback HTTP 服务；两轮聊天包含一次实际 echo 执行，第二个进程恢复并完成第三轮，检查请求历史、配对结果、身份变化与磁盘 revision 4 → 6。还验证 HTTP 500 零重试、失败历史排除、损坏状态保留、不同用户拒绝、失败后的锁释放、超大输入和本地命令不产生模型请求；工具实际执行后注入最终保存失败，核对 Pending 保留和后续输入零执行。

此验收证明核心入口和状态组合；外部真实模型的多轮质量与兼容性仍待实际凭据验收。辅助小模型、Jev、语义模型、四角色路由、Web 管理面板及动态 RULE/MEMORY/STATE/DRIVES/AGENDA 仅保留 TODO。下一步先处理核心入口的取消/退出收尾与真实主模型多轮验收，再细化额外能力。
