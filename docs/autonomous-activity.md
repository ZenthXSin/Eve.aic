# Eve 的独处与自我改进

没有新消息时，从现有重心、兴趣便签或真实工具痛点挑一件可推进的事。等待他人、子代理或巡检时间只阻塞对应事项。长实现交给编码帮手，Eve 管理交付、审查、升级和实际效果；不另造目标或记忆系统。

- 修正休息后的活动窗口：原生 `rest` 不算仍在执行的工作，待后台结果也不屏蔽兴趣便签。真实新消息仍优先。
- 未指定唤醒时间的原生休息和无工具兜底，最多十分钟后重新看；显式未来时间保持原值。管理暂停、预算与模型错误保护不变，无工具结尾仍最多补一次核对。
- 子代理内部工具请求的 `_tool_<step>_<index>` 命令完成由子代理处理，不唤醒主意识。主意识保存空通知与游标，命令全文与回执仍在原服务和子代理记录中；最终回复、主意识自己的命令及 QQ 消息照常唤醒。
- 工具改进从复现与真实回执开始，保存到现有重心和便签；交付一项再推进下一项，避免无限轮询、重复日志扫描及同文件并行写入。

定向回归见 `tests/eve_activity_test.ts`，涵盖原生休息醒后兴趣接续、后台等待、通知分流与重启水位、命令/子代理/QQ 唤醒。缓存前缀与休息合法性沿用 `tests/continuity_test.ts`。
