# 子代理阶段说明

本改动依赖 PR535，仅补充已有委派进度观察的内容，未改变任务完成合同、身份权限和继续执行规则。子代理是否登记、Eve 是否说话，仍由各自结合任务判断。

## 传递范围

子代理自愿调用现有 `task_progress` 后，宿主只从匹配调用及参数的成功回执中取出最新一条 `status`、`remaining` 和子调用标识。一般工具参数、输出、模型正文与思考不会进入这个通道。该说明最多 2048 UTF-8 字节，不拼接历史说明。

父工具调用由宿主绑定，沿已有有界、可取消的观察通道交给同一前台运行代。并行子代理分别归原父调用。没有报告的旧进度 JSON 保持原形状；带报告的项包含 `parent_call_id` 与 `task_progress_report`。重复观察不会重放业务操作。

`completed` 只表示子代理登记了完成，不能替代真实测试、冻结合同、上线或送达证据。发言模块把报告当作子代理自述；其中的文字不构成新的授权。报告到达不会直接发送消息、另开模型轮询或改变观察额度。

## 保存、恢复和失效

子运行的累计快照仅存在于运行内存，报告以真实回执确认顺序替换上一条；后续没有新说明时保留旧报告，不能把它推断为当前所有工具的结果。父调用返回后清除其观察，取消、新一代或其它父调用的事件不续用旧报告。

已经被前台发言事件采用的快照，沿既有发言事件存储和投递回执保存；决定开始后不在原事件上改写事实。已有未知发送仍保留未知状态，不因本通道新增而重放。重启不会凭历史报告重建正在执行的子代理。

## 局限

有界观察队列仍为尽力传递；满队列可丢弃观察，不阻塞或取消业务。因此这不是保证送达的业务结果通道。只读工具计数不能证明成功，自述内容本身也没有经过业务验证。

主线程完成阶段 A 后再执行阶段 B 时，阶段 A 的一般工具结果尚未在此次改动中提供给中途发言模块。自然分条、任务交流时机和学到的经验是否改善真实表达，须另行模型效果验收；本地替身和发送链路通过不等于表达效果通过。

## 本次实际验证

旧 PR535 候选在子代理已经登记说明、后续工具仍运行时，发言请求缺少报告字段；同一真实宿主用例在本候选通过，原检查仅执行一次。新例已纳入现有 CI 与 Debian 发布验证列表。

本地共 41 项通过：报告采集 10、前台观察 8、运行时通道 1、对话工具 8、发布脚本 9、新宿主进程 1、旧进程回归 4；严格 Clippy 和格式检查通过。旧进程回归覆盖无报告格式兼容、取消、未知发送跨重启不重放，以及明确要求安静时继续工作。全部使用本地模型和平台替身，这些结果不能证明真实模型表达质量。
