# 对话工具与实际能力

后台插件运行和聊天工具注册是两处接线。QQ 宿主把当前已装配能力适配为公开 Tool，注册到核心工具服务；模型请求、每轮宿主能力上下文和 /help 共用实际 ToolDefinition 列表。没有装配的能力不会公布，后置运行器和认知服务在通道收消息前绑定，未就绪时明确失败。

/help 查看实际聊天工具和常用命令，/help tools 查看工具说明；命令由本机直接回答，不请求模型。/tools 仍查看已经学习并验证的草稿检查规则，其列表可能为空，不能用它推断模型收到的全部函数工具。旧会话中的助手能力自述可能已经过期。

Runtime 每轮从已经绑定并校验的实际 ToolDefinition 生成当前能力系统消息，放在历史之后、本轮用户输入之前；清单与该轮请求的 tools 共用来源。升级、增加或减少工具后，旧会话无需清空历史或另开会话；旧助手关于“没有工具”的回答与记忆召回保留为历史数据，不能覆盖当前能力。该消息不保存成用户记忆、不成为训练问答或替代真正工具权限检查，工具执行仍按当前范围、参数与取消状态校验。

| 工具 | 实际行为 |
| --- | --- |
| echo | 既有文本回显 |
| search_memory | 读取当前会话的真实交互与有效偏好 |
| list_interests、list_goals | 当前会话兴趣、当前用户可见目标及修订 |
| list_knowledge、list_practice | 当前用户的来源知识（附引用它的草稿实际运行的结果）、草稿和独立运行证据 |
| list_skills、list_forged_tools | 当前用户已固化技能、已启用检查规则和验证依据 |
| list_plans、list_outreach | 当前用户的计划和主动跟进状态，只读 |
| show_budget | 自主运行预算本窗口的上限、已用、剩余、按用途用量和多久后重置，只读、不记账；全局用量，不含用户内容；仅在开启 `--autonomy-budget` 时注册 |
| read_source | 只读抓取已配置的入口及同源目录，不带凭据、不执行页面代码 |
| check_practice_draft | 运行器结构与当前启用检查规则的预检，不写文件、不运行 |
| run_practice | 为当前用户既有目标实际运行数据文件产物并保存实践证据 |
| use_skill | 使用当前用户自己已验证并启用的技能，实例化并实际验证产物 |

学习与实践完整装配有十四个工具；开启自主运行预算时另有 show_budget；显式配置开发能力后再增加八个（文件、命令、GitHub 与升级准备）；例如仅启用记忆时只有 echo 和 search_memory。记忆、兴趣和其他工具的身份均来自本轮宿主绑定范围，模型不能传入 owner、会话或工作目录。认知读取使用用户读权限，计划进一步只展示自己目标的记录。结果有大小上限，截断明确标注，空列表不代表已经获得技能。

## 实际实践与恢复

run_practice 需要当前 goal_id、goal_revision 和规范 PracticeDraft。先核对用户、目标状态与修订、草稿引用和运行器规则，随后在与后台共享的实践账本中保存准入；保存草稿及预检结果后才能实际运行。路径完全由宿主工作根和账本 ID 构造，只接受全新目录，保留已有可疑文件。

同一目标修订已有实践时返回原记录，不重放或争抢在途运行。一次调用至多运行一次，失败、中断、取消和超时有持久结局；未知提交返回错误并保留状态。重启沿用既有实践插件恢复语义，遗留在途记录封存为中断。结构预检通过不等于真实运行验证通过，实践成功也不会直接把父目标标为完成。

正式实例升级须等待已准入轮次收尾，保留用户状态、交流来源和原窗口截止时间。工具定义变化本身无需清空旧记忆或历史工具记录。

## 当前范围

来源读取返回不可信资料与出处，不自动把聊天模型的概括固化为领域知识；后台知识提炼仍按来源、引用及持久准入契约运行。实践和技能调用使用当前装配的 Mindustry 数据模组或静态网页运行器。通用文件、命令、GitHub 和自身升级准备是独立开发工具，需要显式宿主配置及可信操作者范围；见[开发工具与自身升级](./开发工具与自身升级.md)。命令可实际编译、验证源码，但不提供任意二进制插件的进程内动态装载。工具锻造仍为已验证的草稿检查规则。

普通默认运行每轮仍支持一个工具批次；开发配置默认允许八批，可设置一至三十二批。每批执行并回传结果后，模型可以选择下一步或结束；全部调用和结果保留配对，逐批校验与取消规则不变。

验收直接检查实际 Eve 进程发送的 OpenAI tools 定义、工具结果回传、用户隔离、非法输入拒绝、真实实践账本及独立进程零重放；模型和 QQ 使用本地替身。配置 EVE_MINDUSTRY_SERVER_JAR 可让对话实践调用实际运行官方 Mindustry 服务端，正式模型质量与 QQ 体验另外取证。
