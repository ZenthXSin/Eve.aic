# 不确定先问一次

Eve 先查已有上下文、配置、代码和回执。关键目标、范围、参数或用户选择仍不确定时，只问一次具体问题，等待回答；期间可做独立工作，不能替用户决定。已有明确授权不重复询问。固定人格文件保留这些工作原则，具体流程与参数由当前工具契约提供。

后台和子代理没有实时问答时，先保留已做步骤，再用 `task_progress` 标记 `blocked`，最终结果写明已有成果和一个待回答的问题。后台账本保存为 `Blocked`，原会话收到一次通知；子代理返回 `completed=false, blocked=true`，由主执行者汇总。完成唤醒和后来查询看到的也是阻塞状态，不能把它作为完成验收。已经通知的问题不重复询问。

阻塞任务不占执行槽、不自动恢复或重放。重启、无关用户消息和查询都不使它继续。用户回答后，主会话先查已做记录，在原授权范围内推进剩余工作；不能重新执行已完成步骤。通知未知时仍沿用原有的不自动重发规则。

含 `Blocked` 的任务账本写为格式 3；只含旧状态仍写格式 2，支持读取旧格式 1、2。旧版本无法读格式 3，回退需要保留新状态并采用相容版本或部署前快照；损坏数据不得清空。最终检查点已经保存阻塞回执但尚未提交任务结局时，重启直接结算为阻塞，不再请求模型。

本机制以模型的显式状态和真实工具回执为依据，不靠猜测自然语言来判断是否完成。模糊需求需要模型正确识别；通过真实模型探测与宿主进程验收分别验证行为和持久化。
