# 私聊在途追问与进度恢复

私聊长任务期间，新消息仍加入同一轮引导，不取消或重复执行正在运行的工具。宿主使用新消息自己的平台路由，立即返回接收确认和当时可核实的执行阶段；确认不依赖进度模型，也不等待旧消息的主动推送额度。确认只表示追加消息已接收，不是原任务完成或模型已经处理补充。群聊继续沿用原来的合并和进度限额。

确认使用现有 Processing / ReplyPending / Sent / Failed / Unknown 回执，不升级数据格式，不计作模型成功交互或训练证据。消息原文先持久化，确认发送前再次落盘；异常重启不重放消息或确认，无法确认的投递保留原记录。取消和代际替换沿用既有检查。

正常进度仍由模型生成；无需播报时返回明确的 NO_PROGRESS 标记，避免空正文触发提供方协议错误。进度模型出错或超时，仅在开始、长等待、压缩或失败事件返回有事实依据的宿主状态，不编造分析结果；明确选择静默时不补发。相同进度正文不重复发送。

一次进度发送失败或结果未知不再永久禁止整轮发言。原正文不重发，新的自动进度冷却一分钟后可以继续；模型主动提出的新问题或新发现仍可尝试发送，受既有平台配额约束。最终回复保持独立。

升级候选校验允许 /data 等父目录别名指向同一宿主目录，仍校验目录范围、文件名、最终文件非符号链接及 SHA-256；不修改候选清单或放宽验证租约。

验收使用真实 Eve 进程、本地模型和 QQ 替身：追问确认在原工具返回之前到达；同一工具仅执行一次；重复输入重启后不重放；进度故障降级不阻断最终回复；不同的新消息可以在早先进度失败后发送。另验证真实升级监督器通过父目录别名切换，并拒绝外部路径和最终文件符号链接。
