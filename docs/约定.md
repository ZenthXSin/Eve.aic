# 约定

Eve 答应了某个人一件之后要做、但不需要按时提醒的事（比如“下次帮你看看地图”“回头整理好发你”），会用工具记下来。同一个人在别的会话里，Eve 也记得还欠着这件事；做完或决定不做时再了结。需要到点提醒的事仍用[提醒](./提醒.md)。

## 怎么记下与了结

启用交互记忆（`--memory`）时，宿主注册两个工具，对所有人可用：

| 工具 | 作用 |
| --- | --- |
| `note_commitment` | 记下答应当前这个人的一件事，参数 `text` |
| `settle_commitment` | 了结一条：`commitment_id`、`outcome`（`done` 做完了或 `dropped` 不做了）、可选的简短 `note` |

只有工具调用成功才算记下或了结，模型不能只口头答应。同一次工具调用只记一条。群聊观察生成的接话不代表任何个人，不能记约定。

## 在哪些会话里可见

约定属于答应时的那个对话参与者。“是不是同一个人、能不能看”与[跨会话个人记忆](./跨会话记忆.md)用同一套授权：

- 同一 AppID 下同一平台账号在不同群里，直接视为同一个人。
- 群与私聊的平台标识属于不同命名空间，只有主人账号绑定或 `identity_groups` 绑定后才关联。
- 私聊里答应的事默认不进群（`share_private_to_groups` 打开后才进）；私聊里能看到在群里答应的事。
- 关闭 `runtime.memory_continuity.enabled` 后，只看得到在当前会话答应的。

了结同样只能针对这些可见的约定。

对话上下文里的 `eve.commitments.v1` 给出当前这个人所有可见的未完成约定（至多 20 条，`made_here` 标明是否在当前会话答应），以及最近了结的 3 条，让 Eve 知道自己做过什么。没有任何约定时不添加这段数据。别人的对话里看不到。

## 容量

- 每个参与者至多 20 条未完成的约定，满了拒绝记新的，模型会如实告诉对方。
- 账本至多 1024 条，满了先淘汰最早了结的记录；全是未完成的约定时拒绝新约定，不丢未完成的约定。

## 持久化与恢复

账本保存在 `eve.commitment/commitments.v1`，格式版本 1：

- 每次记下或了结都先写盘再更新内存。
- 写入失败或结果不能确认时关闭账本，之后的读写都报不可用；重启后以磁盘上实际的内容为准。
- 损坏、字段不合法或未知格式时拒绝启动，保留原字节，不自动清空。
- 不重放、不补记，也不自动替模型了结。

上下文读取账本或核对身份失败时，标出 `unavailable`，本轮照常回复，不当作没有约定。

## 分层

- 定义层：`eve-commitment-api`，约定与账本契约，不判断身份。
- 实现层：`eve-commitment-plugin`，账本与持久化。
- 组合层：`qq_commitments`，工具、上下文，以及用跨会话记忆的授权策略决定可见的参与者。

实际宿主验收位于 `connectors/qqbot/test/commitment_test.py`：覆盖记下、跨群可见、别人不可见、了结、重启保留，以及群与私聊未绑定时不关联。
