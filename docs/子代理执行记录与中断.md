# 子代理执行记录与中断

`run_subagent` 在请求模型前保存原任务、冻结资料、真实授权原话、角色、模型会话、原预算和期限。每次模型请求及工具执行前后，复用 `TurnCheckpoint` 保存该子代理自己的完整调用与回执；父任务和其他子代理的用量不算成本子代理调用，不重置共享预算。

数据放在宿主状态目录的 `subagent-runs.sqlite3`。定义层为可替换的 `RunStorage`，SQLite 实现使用事务、FULL 同步和 DELETE 日志模式；QQ 与独立 Web 分别注入各自存储。冻结资料只插入一次，执行中只更新检查点与结局列，不将长历史写进主 `state.json`，不随每一步重复存入冻结资料。

`list_subagent_runs` 不传参数列当前完整会话身份最近二十项；`offset` 翻页。传入 `run_id` 显示完整原任务、真实结局及十条工具步骤，`offset` 继续读取后续步骤。查询只读，不发起模型、执行工具或发送消息；可能含凭据的行隐藏，持久原文不删除。原调用再次派发会返回已有记录 ID 并拒绝重跑。

进程结束时未结算的记录在查询中显示 `interrupted_confirmed`、`interrupted_unknown` 或 `result_saved_unsettled`。工具已登记但没有确认回执时明确标记未知，不假称完成。已确认工具回执完整保留。缺少验收条件是 `returned_pending_verification`，和真正等待处理的 `blocked` 分开。

本版实现可靠保存与重启后的只读核对，**没有跨进程自动续跑**。不自动复活 Failed 或 Unknown，不重新提交历史副作用，不因读取旧检查点重新领取预算。父 `run_subagent` 未确认完成时，子记录存在也不被当作父调用已完成的证据。

默认逻辑容量 2 GiB，可用 `EVE_SUBAGENT_STORAGE_MAX_BYTES` 设置为 64 MiB 至 64 GiB。不限制历史记录条数；执行准入为每个未结束任务预留最大检查点增长空间，正常结局释放预留到实际占用。未结束的中断记录保守保留预留，因此大量中断可能耗尽准入容量；本版不自动删除或伪造结局来回收。SQLite 同时设置实际页数上限，真实磁盘不足或事务失败停止当前执行并保留上次确认记录，不谎称持久保存成功。

发布、备份和回退须同时保全这份数据库以及主任务状态。运行中用 SQLite backup，或停止宿主后复制完整数据库与可能存在的事务日志。已有数据库必须通过结构与检查点校验；损坏、空旧文件或读取错误不能被重建为空库。旧程序不识别该库时也不得清理。首次新库只创建版本元数据与空表，没有恢复执行或业务行迁移。
