# 管理面板

管理面板是独立本地服务，不经过 Eve 的模型或脚本插件。它读取运行管理者提供的状态、
意识流、便签、记忆和动作回执，并直接向管理者提交暂停、恢复及日预算设置。
预算与暂停恢复由独立管理者持久化；明确恢复被拒绝模型会追加 `model_resume`
事实，生产管理者仍应保留操作回执。

`services/admin/main.ts` 读取私有配置中的 `admin` 段：

```json
{
  "admin": {
    "directory": "/private/eve/admin",
    "tokenFile": "/private/eve/admin-operator-key",
    "backendConnectionFile": "/private/eve/supervisor/admin-connection.json",
    "backendKeyFile": "/private/eve/admin-backend-key",
    "port": 0,
    "publicOrigin": "https://eve.example.com"
  }
}
```

全部文件路径须为绝对路径。`port: 0` 使用随机端口；最终地址写入 `directory/connection.json`。只监听
`127.0.0.1`。省略 `publicOrigin` 时，通过本机访问或 SSH 端口转发打开。配置公开域名时，
`publicOrigin` 必须是规范的 HTTPS origin，不带路径、尾斜线、查询参数或凭据；反向代理须保留公开 Host
和浏览器 Origin，并在代理处终止 TLS。后端不使用 `Forwarded` 或 `X-Forwarded-*`
来决定可信地址，连接文件仍记录本地 HTTP 监听地址。配置公开地址后，本地 Host 不再能访问该面板。

`tokenFile` 保存管理员密码，支持 8 至 1024 个字符，允许普通标点和 Unicode，不允许控制字符。
文件末尾的一次换行会被移除，其他空格保留；文件权限应为 `0600`。管理员密码与后端 IPC
密钥必须独立，不能借用模型、所有权仲裁或 QQ 凭据。IPC 密钥仍须为 32 至 256 位随机字符串。

浏览器登录后使用限时 `HttpOnly`、`SameSite=Strict` 会话，公开 HTTPS 模式额外设置 `Secure`。
密码不会写入 URL、 浏览器存储或静态页面。变更请求须有会话及 CSRF 校验；服务拒绝跨站 Origin、
不匹配的 Host 和跨站 Fetch Metadata，并设置禁止缓存、禁止嵌入及 nonce CSP。
失败口令限速，所有请求正文先按字节限制为 64 KiB。

`startAdminControlServer(backend, key)` 可由独立管理者装配，提供本机 `/admin-control`
出口。该出口使用专用 Bearer 密钥并拒绝全部带 Origin 的请求，
只有管理面板进程读取此密钥。实例、模型和脚本插件不应获得此密钥或其读取权限。
管理后端必须只返回可展示数据，不能返回环境变量、配置私钥或其他服务连接凭据。

后端实现 `services/admin/contracts.ts` 的 `AdminBackend`：

- `status()` 返回运行版本、当前状态、预算与升级状态等可展示信息。
- `query({ resource, operation, args })` 支持意识流、便签、记忆和动作回执。 分页/搜索返回
  `{ items, next? }`，`next` 是下一次的完整 `args`；无 `next` 即本页结束。 详情使用 `{ id }` 或
  `{ seq }`；文本可返回 `nextChar`，前端据此继续读取。 便签还可查询版本。所有记录保留原有时间、关联
  ID 与源码版本标记。
- `control({ action, args })` 接受暂停、恢复、非负整数日预算和显式 `resumeModel`；后端负责持久化、
  跨进程序列化及管理回执。连接中断标记结果未知，前端不会自动重发控制请求。

界面只用 `textContent` 展示原始记录，记录中的 HTML、脚本和附件路径均不会执行。 语义检索模型接入维持
TODO；面板全文搜索由后端执行，不在此服务加载语义模型。

`tests/admin_test.ts` 覆盖登录、会话过期、限速、Origin/Host/CSRF、限量、
四类分页和受限管理操作，以及管理面板经独立 IPC 修改状态的完整链路。

模型被上游永久性4xx拒绝时，状态中的 `runtime.model.blocked` 显示脱敏分类、HTTP状态和请求编号。
“明确恢复被拒绝的模型”按钮只提交当前 `expectedRequestId`；必须先暂停运行，状态变化时拒绝旧操作。
解除模型阻塞不会自动开始运行，普通“恢复运行”也不清除模型阻塞。这样重启或新QQ消息不会反复请求同一个被拒绝的决定。

QQ 失败等待队列使用独立管理通道。QQ 服务私有配置可增加：

```json
{
  "qq": {
    "adminControl": {
      "keyFile": "/private/eve/qq-admin.key",
      "connectionFile": "/private/eve/qq-admin/connection.json"
    }
  },
  "supervisor": {
    "qqAdmin": {
      "keyFile": "/private/eve/qq-admin.key",
      "connectionFile": "/private/eve/qq-admin/connection.json"
    }
  }
}
```

这些是对应配置段的增量示例。路径须为绝对路径，密钥须与其他 IPC 密钥独立；QQ 管理连接不得覆盖
phone、模型控制连接或配置文件。QQ 写出的连接文件只含本机随机端口 URL，密钥留在私有文件， Eve
实例和手机插件不读取此管理密钥。省略这些可选配置时其他管理功能继续工作，QQ 队列查询返回未配置。

“记录 → QQ 失败队首”只列出已确定失败且阻挡同一会话的队首，支持分页，不支持全文搜索。
“保留失败并结束此项”按钮在二次确认后提交当前 `expectedActionId`、`expectedFingerprint` 和
`expectedReceiptDigest`；摘要来自原始回执文件，页面陈旧或原件发生变化时拒绝操作。 系统追加独立
`resolutions/<actionId>.json` 事实并同步落盘，保留发送原件及每次尝试原件。
此操作使后续消息可以继续，不会把失败写成已发送，不会重发被结束的动作。
未知结果、正在发送或退避重试的队首不能从此入口结束。

Eve 的手机工具另提供 `phone.listSendQueue` 与 `phone.cancelSend`，不使用管理员密钥。 列表返回明确的
`canCancel` 及取消条件摘要。Eve 只能持当前所有权许可，取消确定失败的队首，
或取消还被前序阻挡、从未尝试发送的等待项；即使前序持续重试，零尝试等待项也可立即取消。
临近写入取消事实时再次核对所有权。取消结果是 `cancelled`，同时保留原失败详情；
网络中断按结果未知处理，应先查回执，不能推断取消失败或重新创建消息。
这些工具同样经过脚本类型契约、工作进程转发及持久脚本调用账本。

发送遇到明确鉴权失败或明确限流拒绝时，按原动作、原回复序号继续退避；平台提供的有界 `Retry-After`
与基础退避相加。每次尝试重新核对所有权，关闭服务会唤醒退避。
未知结果及未确认的平台错误保持原有未知/失败事实，不猜测为送达。
