# 群回复与触发者

QQ群的每一条回复都艾特触发本轮的用户，包括阶段进度、最终回复的每个片段、故障和容量提示、文件说明及图片说明。私聊保持普通文字。此行为不依赖是否开启全量群消息观察。

即时回复使用 Node 保存的原始平台发送者，不接受模型在发送工具中指定用户。主动群插话使用已核对的来源发送者；后台任务、提醒和文件使用原任务的完整会话标识，从持久回执恢复群与用户。其他群友后来发言不会改变收件人。缺少可信路由时不发送，不用最近活跃群友替代。

艾特在通道发送时加入，原始任务正文、历史和业务结果保持原样，不把艾特内容计入偏好训练。每个片段均添加同一触发者；正文已以同一艾特开头时不重复添加。正文中出现其他用户标记不能改变宿主绑定的触发者。

没有新增持久状态格式。既有消息和发送状态保持原语义：先保存意图，再等待真实平台回执；失败或结果未知不自动重发。重启从原会话恢复收件人，不补发已完成通知。

验收覆盖多群友交错回复、分段、阶段消息、容量、发送失败通知、文件、图片和私聊。实际 QQ 宿主离线验收另覆盖后台任务执行期间其他群友发言、原群原用户通知，以及独立进程重启不重发。
