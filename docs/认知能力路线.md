# 认知能力路线与验收边界

Eve 的后续目标是让记忆、环境观察、议程与受控行动形成可核对的闭环。每项能力分别交付公开契约、可替换实现和宿主组合，并保留可查看的来源与失败记录。任务流程通过不等于模型具备通用智能。

## 当前基线

主线已包含有来源交互记忆、明确偏好与自主候选学习、用户反馈重规划，以及本地文件观察。反思是一个有界子任务：每个父目标修订至多一次，子任务 Completed 只说明草稿已保存并通过结构检查，父目标保持 Waiting。

文件观察记录实际读取的摘要、时间与有限片段。它能触发新的规划，但文件里的陈述仍属于外部数据，不能覆盖用户约束或增加工具权限。学习只从已保存、符合投递条件的交互获得证据；历史模型回复不会自动成为用户偏好。

## 本批推进顺序

| 能力 | 交付目标 | 完成依据 |
| --- | --- | --- |
| 内生议程 | 根据已有优先级、期限、等待与新信息证据选择下一项，说明候选和排除原因 | 只读预览与实际执行排序一致；无新候选时零模型调用 |
| 记忆召回 | 按可信会话和用户检索已保存资料，结果携带来源和版本 | 用户隔离、纠正与撤销生效、结果与正文有界；首版本地词项匹配不宣称嵌入语义检索 |
| 学习决策 | 区分重复、可更新、需确认及应拒绝的候选 | 不因换 ID 重复增加等价偏好，不绕过手动纠正与撤销；决策可解释、可恢复 |
| 受控行动 | 先交付一种明确绑定范围的本地产物创建动作 | 当前草稿与输入前置条件有效，写入后独立读回验证，失败与不确定副作用可恢复 |
| 配套工具 | 本地查看记忆及证据，重复运行认知流程场景 | 使用公开读取契约；默认无正文、显式查看有界；报告包含实际观察而非预设成绩 |

这些切片采用独立 PR。某条线的功能通过不自动证明组合后兼容；整合后另行验收环境变化、候选选择、反思、行动与记忆修正的连接。

## 已实现的组合入口

| 入口 | 用途 | 持久化行为 |
| --- | --- | --- |
| `eve-cognition agenda` | 查看执行候选、反思候选及排除原因 | 仅打开既有状态，不初始化后端或恢复执行中目标 |
| `eve-cognition export-plan` | 明确绑定目标修订、观察文件摘要与新产物路径 | 先保存行动日志，独立读回一致才记为完成；重启不重放 |
| QQ `/recall 关键词`、`eve-memory recall --query 关键词` | 查询当前有效偏好和有来源历史交互 | 每次读取当前快照，不写记忆；CLI 正文须显式开启 |
| QQ `--memory-recall` | 将本轮相关历史作为有来源的有限 Context | 依赖 `--memory`，默认关闭，独立于自主学习开关 |
| QQ `/memory-decision 候选ID` | 查看最近决策、来源与实际记忆保存状态 | 只读查询；决策与记忆分别提交，不能用决策代替写入回执 |
| `eve-memory status/list/show/evidence/scopes` | 查看已有记忆、历史和证据 | 文件与 PostgreSQL 均使用只读入口，仍遵守宿主独占锁 |
| `eve-cognition plan-create/plan-show/plan-step` | 操作者提供有依赖与效果条件的多步计划，逐步执行文件观察或受控导出 | 先保存执行状态再执行；绑定变化使未完成步骤失效，重启封存中断步骤不重放 |
| QQ `--interest-learning`、`/interests`、`/forget-interest` | 从普通聊天观察明确兴趣并派生低优先级学习目标，后台反思；撤回即取消 | 先保存批次再请求，失败与中断不重放；引用须逐字出现在用户原文；目标 ID 确定，重启补齐不重复 |
| QQ `--research-source`、`/knowledge` | 学习目标在操作者配置的入口页面范围内研究，保存有来源、版本与逐字引用的知识，推测单独标注 | 准入与每个阶段先保存再抓取或请求；每个目标修订一次、累计三次；失败不重试，中断不重放 |
| QQ `--practice-mindustry-server` 或 `--practice-browser`、`/practice` | 学习目标在研究后做出只含数据文件的最小模组，在操作者提供的真实服务端中加载并按受限探测核对，依据证据修正 | 准入与每次尝试的草稿、运行先保存再执行；每个目标修订一次、累计两次、每次至多三次尝试；中断不重放，失败不重试 |
| QQ `--skill-learning`、`/skills`、`/skill` | 已验证实践提炼为参数化技能，逐字还原原产物并用宿主选取的参数实际运行通过才启用；后续独立任务选用技能，结果以实际运行证据为准 | 准入、提案、验证、选择先保存再执行；每次实践至多提炼一次；中断不重放，失败不重试；用户停用后新版本不自动启用 |
| QQ `--outreach`、`/outreach` | 学习目标有了已验证的进展后撰写邀请，用户下次私聊时经时机判断附带或操作者开启的主动私聊，以平台回执为准；送达后识别用户回应并据此调整时机；用户提出的想法派生为后续创作目标 | 准入、撰写、判断、投递与回应识别先保存再执行；每个目标只邀请一次，同一用户有冷却期，连续负面反馈时加倍并暂停主动私聊；回应须逐字引用用户原话；后续创作目标记为推断、确定性派生，学习目标关闭时一并取消；安静时不投递；发送中中断记为未知不重发 |
| `eve-cognition plan-propose/plan-confirm/plan-withdraw` | 模型就当前修订建议计划，校验后待确认；操作者确认或撤销 | 先保存请求记录再请求，每个修订至多一次；确认时重核绑定，中断不重放 |
| QQ `--plans`、`/plan`、`/plans` | 用户为自己的待办请求计划建议、确认或撤销；计划只能使用已开启的受控研究与实践验证，由对应后台执行，按账本证据结算 | 步骤先保存执行中再交给后台；待办新版本使计划过时；每个版本各至多一次建议与一次研究、实践；中断不重放 |

完整参数与恢复规则分别见[内生议程](./内生议程.md)、[受控产物行动](./受控产物行动.md)、[记忆召回](./记忆召回.md)、[学习决策与冲突](./学习决策与冲突.md)和[配套工具](./认知配套工具.md)。本地产物创建仅执行这一项已绑定能力；多步执行仍属于下一阶段。

## 后续里程碑

1. **有条件的多步计划**：计划明确依赖、预算、输入修订、可用能力与效果条件。上游条件变化使下游步骤失效；不能依靠反复生成草稿计为任务进展。已交付操作者提供的计划、持久账本、两种能力，以及模型建议经操作者确认后执行，QQ 入口也已交付（受控研究与实践验证作为计划能力），见[多步计划](./多步计划.md)；面板入口与目标完成判定继续推进。
2. **效果反馈与策略改进**：保存动作结果和独立观察，区分成功、失败、不确定及用户纠正。使用可复验场景比较策略，保留版本与回退路径。
3. **长期记忆与语义检索**：在已建立的范围与来源契约上接可替换检索模型，明确输入、调用预算和失效规则；保留确定性检索基线及留出任务。已交付 QQ `--semantic-recall`：可替换的向量模型契约、持久向量索引与后台建索引、词项与语义排名融合，向量模型不可用时明确标注改用词项召回，见[记忆召回](./记忆召回.md#语义召回)；rerank、真实向量模型的留出评估继续推进。
4. **长期目标与资源分配**：评估什么时候继续、等待、请求澄清或停止；长期运行预算不能因重启、重复事件或自造目标被放大。
5. **能力与泛化评估**：采用与开发夹具分开的任务，核对事实、约束、实际效果及资源用量。记录模型、提示、工具和记忆版本，不报告没有定义的 AGI 完成百分比。

## 实施约束

模型建议、用户事实、环境读取和动作回执保持不同来源。新的能力必须由宿主明确装配；更高优先级、更强驱动或模型自述都不能产生权限。状态保存失败不能静默丢记录，执行不确定时不能推断副作用未发生或自动重放。

测试与验证独立于实现负责人，先跑相关确定性流程，再做组合检查。真实模型质量、QQ 体验及正式服务部署分别记录；源码合并不自动改变正在运行的进程。配套测试只管理自己创建的进程和临时状态。
