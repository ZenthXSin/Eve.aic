# Eve 管理空间

面板围绕三个日常问题组织：Eve
能否继续工作、上下文与缓存是否达到目标、哪些等待需要管理员处理。桌面侧边导航和手机横向导航提供相同功能。

## 数据口径

- 总览的运行状态来自监督管理者、执行服务和模型阻塞状态；这不等于 QQ
  每条消息都送达。失败或送达未知的会话队首单独查询，查询失败显示未读取。
- 上下文图从固定水位最近 80 条意识日志中，提取 `model_response` 的已报告 `usage`。最多读取 10
  页，不触发模型请求。输入均值使用所有有效输入样本；缓存命中率仅使用缓存数有效且不大于输入的样本，按输入
  token 加权。缺失、无效用量以及截断而无法读取 usage
  的记录不按零用量计算。展示样本数、时间区间与水位，不代表全天。
- 柱形表示单次总输入，深绿部分为缓存输入，浅绿为非缓存输入，金色代表缓存未报告。柱形按请求顺序等距排列，间距不表示时间。150k
  参考线是平均输入目标，不是单次硬上限。图下说明实际均值与目标的差距；点击或键盘聚焦柱形可读取单次数字，也可展开完整数值表。
- 预算环图采用执行服务的安全记账口径：已知非缓存消耗、未知用量预留、安全剩余。预留不是实际消耗；预算比例也不是缓存命中率。不虚构费用或可用时长预测。
- 意识、便签、记忆和回执水位均为累计日志序号。便签多版本、记忆强化等可占用多个序号，不把水位写成便签或记忆数量。
- 待处理卡片统计已读到的会话队首，不等于积压消息总数；如还有分页，以 `+`
  表示下界。送达未知与失败均保留原始状态。

## 阅读与操作

记录默认从最近 80
条日志范围开始按序读取；可切换全部范围、文字搜索、分页和查看完整原件。便签优先展示短名字、标题、版本与摘要。长正文、关联编号和原始字段按需展开，文本不会作为
HTML 执行。

暂停、恢复、预算和模型解阻仍通过原有受保护管理接口执行。取消消息等待携带原动作编号、指纹和回执摘要；取消前解释可能已送达且不会撤回，操作后保留原件。控制请求连接中断时提示先核对状态，不自动重复提交。

前台每 30
秒同步状态；仅意识日志水位变化时重读用量窗口。隐藏页面和打开详情时不自动刷新。记录本身按需加载；后台同步不覆盖尚未保存的预算输入。状态或用量读取失败分别显示未同步、未读取，不将故障伪装为零消耗。

管理页面可独立更新和重启管理服务，Eve 实例、QQ 通道与监督状态不需要随静态页面更新而重启。原有
HTTPS、HttpOnly 会话、CSRF、CSP、跨站和分页限制保持生效。

## 此刻：实时活动与文字记录

导航中的“此刻”每 3 秒读取受会话保护的只读 `/api/live`。服务端最多保留最近 80
条投影，按固定水位分页读取，水位不变不重读正文，有新记录时增量读取；日志水位回退或跨度超过窗口时重新取有界窗口。同一时刻多个浏览器请求共用一次读取，不触发任何模型调用或额外计费对话。

流程位置来自实际的请求、工具开始、回执、唤醒与休息记录；管理者暂停、模型阻塞或执行不可用优先显示。等待中的模型只显示等待时间，不模拟尚未返回的内容。文字栏原样展示已记录的
`model_response.content`；仅工具调用、没有文字、原件被截断或窗口内没有文字时分别明确说明。投影不展示脚本参数、命令输出或通知正文，需要时打开原件查看。

“暂停画面跟随”冻结观察画面，不提交运行控制操作，Eve
本身继续运行。可以按文字、行动、通知、异常筛选，或打开完整原件。隐藏页面和阅读原件时停止自动轮询。连接失败保留带时间的旧记录，并明确当前状态未确认；不把旧动作持续标成实时已确认状态。工具调用返回不等于后台任务结束，更不等于
QQ 消息已送达。
