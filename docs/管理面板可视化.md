# Eve 管理面板

面板有六个去处：实时、总览、记录、子代理、待处理、设置。桌面端是左侧导航，窄屏收成图标栏，手机改为底部导航加
“更多”面板。外观默认明亮，可在设置里选择跟随系统、浅色或深色，选择只保存在本机浏览器；系统要求减少动画时全部
动效关闭。地址栏的 `#/视图` 记录当前位置，刷新和浏览器后退都回到原处。页面、样式、实时通信和测试随
Git 完整提交， 没有需要从宿主私有目录另行复制的前端源码。外部更新、WebSocket 反向代理和回退见
[管理面板外部更新](./管理面板外部更新.md)。

源码按职责拆分在 `services/admin/`：`styles.ts` 是全部样式与主题变量，`view.ts`
是外壳、导航、总览、记录与设置， `stage-view.ts` 是星图与脉络，`workspace-view.ts`
是屏幕及各应用的只读内容，`live-view.ts` 是实时快照与随记，
`usage-view.ts`、`timeline-view.ts`、`agents-view.ts`、`history-view.ts`
分别是用量图、意识流卡片、子代理和本机缓存。

## 实时：星图、屏幕、随记、脉络

登录后默认进入“实时”。桌面端同时显示四个镜头：上方星图、其下屏幕、右侧随记，向下滚动是脉络；
宽度不足 980 像素时改为四个分页，各自占满余下高度。

**星图**用中央光球表示 Eve 当前所处的阶段，四周是 QQ、文件、终端、便签、记忆、网页和工具七个节点。
光球的节奏只跟随真实阶段：等待模型返回时涟漪加快，等待工具回执时有卫星环绕，休息时放缓，暂停时静止，
异常或同步中断时变为警示色。她最近操作的应用节点会亮起并与光球连线：操作进行中光流由光球流向应用，
半分钟内刚返回的由应用流回，更早的只保留高亮不再流动。节点角标是近期操作账本里该应用的操作次数。
页面打开期间出现新的文字记录时光球闪一次；首帧只记录水位，不补放旧动画。点击节点会在屏幕里打开对应应用。

**屏幕**没有外框。顶部状态栏显示快照时间、当前阶段和观看方式；主屏有“此刻”“最近操作”两个小组件和应用图标，
QQ 图标的角标是通知水位之后的条数，不代表全部未读。屏幕默认跟随近期脚本动作账本中最新的已记录操作，
切换应用时从图标位置放大进入；图标下的小点表示 Eve
最近操作的应用，选中描边表示管理员正在查看的应用， 两者可以不同。点击图标、底部切换条、操作记录或“‹
主屏”进入“你正在手动查看”，不会替 Eve 执行工具； “跟随
Eve”恢复跟随。页面打开期间新到的通知记录会以横幅滑入，几秒后收起；横幅只说明通知已进入意识日志，
不代表已回复。当前操作标有真实方法、状态与快照时间；最近操作不代表对应应用仍持续在前台。
账本没有可确认记录时停在主屏并明确说明，不从脚本代码或来信猜测她正在做什么。

**脉络**只统计当前窗口内的记录，不代表全天：

- 四个数字：写下文字的次数、工具调用次数、成对的模型请求与返回之间的平均等待、异常记录数。
- 活动河流按时间从左到右排开五条泳道：模型等待区间、文字（圆点大小随字数）、工具调用区间、通知、异常。
  尚未见到返回的请求与调用画到最右端并闪动，不推断其结果。点按任意标记显示时间与摘要，可打开原意识记录。
- 应用使用环与图例来自近期操作账本各应用的操作次数，点图例可打开对应应用。
- 节奏条把窗口等分为 36 格，柱高是每格内的记录数。

- QQ 左侧区分群聊与私信，显示真实会话编号、最近消息预览及通知水位后的条数。没有可信群名时保留编号，
  不用发送者昵称冒充群名，也不把通知条数叫作全部未读。右侧按 Eve
  最近明确操作的会话显示最新只读消息， 同时单独标注原屏幕回执时间与最新消息同步时间。最新来信不表示
  Eve 已经看过，原工具屏幕和实际阅读水位
  保留为独立证据。管理员点击会话（包括同一个活跃会话）会持续只读刷新，可加载更早消息；
  标为“管理员手动读取 · 不表示 Eve 看过”，不改变她的已读水位。文字、引用与附件元数据按真实字段
  呈现；附件占位不表示已读取图片。出站消息另外显示发送状态，失败、等待和结果未知保留原义，正文存在不等于送达。
- 文件应用左侧选择真实文件操作，右侧显示目录条目、路径或实际读取的文本文档。搜索只显示已返回的行；
  片段和分页明确提示。写入或替换请求中的拟写内容不当作已保存文件的证明。二进制编码不作为普通文本预览。
- 终端显示真实命令、工作目录、标准输出与标准错误、会话状态和已提供的退出码。轮询回执缺少原命令时说明
  缺失，不根据输出补写命令，不制作虚假光标、进度或滚动输出。
- 便签保留分组、短名字、版本、摘要或实际正文；记忆保留工具返回的记录。列表、检索和正文片段不假装是全量数据。
  这里只读选择，没有伪编辑器或保存按钮。
- 网页应用预留对应位置；目前没有结构化浏览器工具来源，因此明确显示没有可展示的记录。 不通过 URL
  字符串推断浏览行为，不自动加载第三方网页。

“工具”应用汇集全部真实调用，并提供与公开契约一致的工具目录。目录列出原生工具及 `phone`、`notes`、
`files`、`commands`、`memory`、`records`、`mind`、`upgrades`、`scripts`
的全部方法；升级观察阶段的条件原生工具
也按真实可用入口标明。目录不是执行按钮，点击方法只筛选近期调用。文件、终端、便签、记忆复用各自阅读布局；
QQ 的草稿、拟发送正文、送达回执、按序等待队列及图片模式分别用信息卡片呈现。提醒显示请求与排队状态；
升级显示阶段、最终结果和已提供的回退原因；脚本显示独立任务状态、实际文本页；意识记录显示目录或原文片段。
已知工具均保留可展开参数、结构化原件、异常与有界字段提示；未知未来工具仍有完整通用预览，不因名称不认识而过滤。
原生工具来自实际意识记录，脚本子调用来自动作账本，来源分别标注；随记正文只在随记栏的共享投影中出现，工具预览只保留引用。
原生 `execute_script` 返回了任务回执不等于任务完成，能读取任务状态时单独显示；`mind`
的排队与已应用、 升级提交与最终上线分别保留原始状态，不把返回成功等同最终业务完成。

屏幕内容来自近期有界脚本账本及 QQ
只读投影，可能缺少早期操作、长正文或后续分页。每个操作保留脚本记录序号
与可展开的结构化回执；脚本序号和意识日志序号属于不同来源，不混用为跳转编号。没有记录、服务不可读、
正在进行、明确失败及结果未知分别呈现。

“随记”只显示 `model_response.content` 与有效 `execute_script.thought` / `write_thought.thought`
的共享
投影。与上下文使用相同去重规则：同轮相同文字只展示一次，不把同样文字再复制为保存回执；不同轮仍各自保留。
原生保存动作的失败或未知结果在“完整过程”“异常”中保留。“完整过程”还能展开真实工具次数、回执和通知，
不把工具次数推算成文件数或消息送达数。每则文字可打开原意识记录，原件截断时明确提示。

她没有写文字时，“随记”保持空态。面板不从工具代码、命令结果、群友的话或模型等待时间生成内心独白，
也不要求展示逐步内部推演。服务器实时帧使用最近 80 条原始意识记录；浏览器累计保留已经展示过的
活动与工具预览，同一有效登录会话内刷新后可以回看。首屏只展开服务端近期窗口；
点击“加载更早本地记录”才额外展开 40 条旧活动和 32 次旧操作，不一次性铺开全部历史。 QQ
只请求当前会话的一页，点击更早消息才携带对应快照游标分页；回看窗口最多 400
条，点击会话可返回最新页。 旧记录标为历史预览，不替代当前状态。 本地上限为 500 条活动、200 次操作、2
MiB、7 天，达到任一限制便回收最旧记录；不会无限增长。
缓存只在服务端确认登录后恢复，按登录会话的不可逆摘要隔离，不保存会话凭据、实时状态或图片原图；
退出登录或登录失效时清除当前缓存。重新登录会使用新隔离空间，完整业务历史仍在服务端，
可点击“查看完整历史”分页检索。浏览器禁用存储或容量不足时标记“本地保存不可用”，当前同步仍继续。

手机宽度下会话列表与操作列表改为顶部横向滑动，正文占满宽度；会话消息可独立滚动，长文字换行。
管理员翻看前文时保留阅读位置；在底部时跟随新增记录，支持“回到最新”。相同旧文字不会随每次同步反复播放入场动画。

## 实时通信与状态真实性

浏览器使用同源、登录会话保护的 `/api/live/ws` 接收 WebSocket 快照。初次进入与恢复画面时可通过
`/api/live` 获取一份只读快照，正常实时更新由服务端共享广播，每 3
秒同步；不让每个标签页持续重复请求模型或控制工具。 WebSocket
不提供执行命令或发送消息的入口，所有管理操作仍经过独立受保护的控制接口。

“暂停画面跟随”关闭该浏览器的实时连接并冻结观察画面，Eve 本身继续运行；恢复后重新连接。离开实时页、
隐藏标签页或退出登录会关闭连接，退出时清除已展示的屏幕和意识内容。连接中断保留最后一次真实画面并显示时间和
“当前状态未确认”，按有界退避重连；会话过期重新登录。超过 12 秒未收到有效实时帧时主动重建连接， 并用
HTTP 只读快照补拉，防止连接仍显示 OPEN
却停滞。旧回包不会覆盖较新的帧，退出后的在途回包不能恢复私密画面。 QQ
列表和消息按独立水位刷新，不依赖意识日志新增；查询失败保留最后确认内容并标记未同步。超过新鲜度窗口时不继续声称当前已同步。
不支持 WebSocket 的浏览器可以退回只读轮询。部署反向代理必须转发 Upgrade/Connection，不能仅验证 HTTP
入口可用。

流程状态来自真实模型请求、工具开始与回执、唤醒和休息事件；管理者暂停、模型阻塞与执行不可用优先显示。
等待模型返回时只展示等待时间。所有业务字段通过文本节点显示，不执行记录中的 HTML、脚本或附件路径。

## 总览的数据口径

- 总览的运行状态来自监督管理者、执行服务和模型阻塞状态；这不等于 QQ 每条消息都送达。
  失败或送达未知的会话队首独立查询，查询失败显示未读取。
- 上下文图从固定水位最近 80 条意识日志中提取 `model_response` 已报告的 `usage`，最多读取 10 页。
  输入均值使用所有有效输入样本；缓存命中率仅使用缓存数有效且不大于输入的样本，按输入 token 加权。
  缺失、无效用量及截断而无法读取 usage
  的记录不按零用量计算。展示样本数、时间区间和水位，不代表全天。
- 柱形表示单次总输入，绿色为缓存输入，浅灰为非缓存输入，金色为缓存未报告。按请求顺序等距排列，
  间距不表示时间。150k 参考线是平均输入目标，不是单次硬上限；可聚焦单柱或展开数值表。
- 预算环图采用执行服务的安全记账口径：已知非缓存消耗、未知用量预留和安全剩余。
  预留不是实际消耗；预算比例不是缓存命中率。不虚构费用或可用时长预测。
- 意识、便签、记忆和回执水位均为累计日志序号。便签多版本、记忆强化等可占多个序号，不把水位写成记录数量。
- 总览顶部的提醒条只列当前状态中需要处理的事项，可直接跳到对应页面；没有事项时不占位置。
- 待处理数字统计已读取的会话队首，不等于全部积压消息；有后续分页时以 `+` 表示下界。

## 记录与管理

“记录”把意识流、便签、记忆和动作回执放在同一页的四个分页里。默认从最近 80
条范围按序读取，可切换全部范围、
文字搜索和分页；意识流可按想法、通知、工具、异常筛选已加载的记录，筛选不触发新的读取。打开任意一条时从右侧
滑出阅读抽屉（手机上占满屏幕），可继续读取长正文、查看便签历史版本和原始数据，关闭后列表位置不变。
便签优先展示短名、标题、版本和摘要。

暂停与恢复在总览顶部和设置页都能操作；预算、外观和模型解阻在设置页。暂停、把预算设为
0、解除模型阻塞和取消消息等待
都先弹出确认框说明后果。取消消息等待携带原动作编号、指纹和回执摘要；确认框解释可能已送达且不会撤回，
操作后保留原件。操作结果以底部提示条告知；控制请求连接中断时提示核对状态，不自动重复提交。

“子代理”左侧选会话、右侧读消息，手机上先选会话再进入消息。只读查看，不改变 Eve 的未读通知。

其他页面每 30 秒同步状态；意识日志水位变化时重读用量窗口。后台同步不覆盖尚未保存的预算输入。
管理页面可独立更新和重启，Eve 实例、QQ 通道与监督状态不需要随页面更新而重启。
