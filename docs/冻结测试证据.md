# 冻结测试证据

更新日期：2026-11-10。本切片让已准备的固定测试输入在真实运行一次后，能够越过后续进度登记完成验收。范围限于小型纯 JavaScript 测试包，不代表普通编程任务已全面取消重复测试，也不表示已经上线。

## 固定对象与真实执行

新合同 `kind=frozen_node_test` 在执行前固定三个 SHA-256：

| 字段 | 绑定内容 |
| --- | --- |
| `input_sha256` | 完整测试包中的路径与文件字节。 |
| `runtime_sha256` | 宿主提供并完整复制校验的私有运行时，包括指定 Node 与运行所需文件。 |
| `command_sha256` | 运行策略、启动器身份、Node 参数、固定环境、入口和脚本参数。 |

测试包由可信宿主准备，最多 64 个文件、合计 8 MiB，入口必须在包内。依赖随包提供，不临时安装或读取模型指定的工作区路径。运行器需要支持现有权限参数的 Node、完整私有 rootfs 和可信 bubblewrap；它不会自动解析、下载通用依赖。缺少运行条件不能算测试成功。

执行时只读挂载私有运行时及输入，隔离网络，临时写入限于 `/tmp`；Node 策略禁用原生扩展、子进程、worker 等能力，仍配合操作系统隔离。这里的冻结保证针对这些输入与运行时字节，不声称时间、随机数和宿主内核也成为可重放环境。启动器摘要复核不能独自证明外部并发替换没有竞态。

## 复用路径与身份绑定

可信宿主须显式注册输入、合同和运行器，并将工具与 `TaskCompletionEvidenceSource` 接入同一执行路径。模型只选择预注册的 `bundle_id`，不能提交路径、任意命令或自填摘要取得验收权威。当前 QQ、Web 的普通模型入口没有默认装配该能力，新 tag 也不会因定义层可解析就自动获准使用。

真实运行器产生回执后，宿主将见证绑定原 owner、完整 `model_session`、调用 ID、完整参数与工具结果摘要，以及三个合同摘要。后台任务还把模型会话绑定到原 Task ID，同一用户的另一任务不能借用检查点。可见工具 JSON 和模型文字不能自行成为可信见证。

新合同读取同一执行中已保存的见证，选择最近匹配批次的真实结果。退出码为零的固定输入测试可以在后续 `task_progress(completed)` 之后仍通过，不因工具批次位置再跑一次。最新测试失败、同批匹配不唯一、缺见证、未知效果或实际未完成工作不能被较早成功掩盖。原共享预算、期限、取消和权限检查继续生效，取证与收尾不重新领取预算。

这一结论是“该固定测试包在固定运行时上实际测试通过”，不是“当前工作区已经验证”，更不是文件已投递、候选已部署或整个用户目标完成。改动后的源码或新测试包必须有对应的新目标与证据，不能沿用旧包的成功冒充。

## 持久化与兼容

可信见证随原检查点保存；子代理在同一 SQLite 状态提交中保留附属的 `frozen_node_evidence`。增量采集不能替换原调用见证，读取会复核身份、会话、配对、摘要和已保存结局。重启可沿原记录只读结算，不必重新启动运行器或读取当前源码；损坏、冲突或提交失败明确保留错误和原始数据，不能清空账本重建。

未知或取消的执行保留为不可确认，不自动重放。即使可见 `ToolOutput` 是 Success，结构化结果为 Unknown 也不会被当成通过或普通可修复失配。持久查询不恢复子代理，同一个已保存 run 不能再次启动。

旧 `receipts`、`text` 与历史任务保持原合同语义，`require_final_batch=true` 没有全局取消。旧记录没有见证时按空值读取，不补造过去的冻结事实。旧二进制不认识新 tag 或附属字段，会拒绝新记录；开始写入新合同后不能把普通降级当成兼容回退。需要停用时，先停止派发新冻结测试，保留能读取新记录的版本进行只读核对；无法维持兼容运行时停止服务并保留现场。只有已经确认目标旧版本能够完整读取当前状态时，才可按原升级流程切换；不删除账本、删字段或用旧快照覆盖后续回执来换取启动。

## 验证状态与未完成范围

本轮已经通过 15 项运行后端测试、9 项任务验收测试、2 项竞态测试及 11 项应用组合测试；完整 `eve-task-plugin` 回归共 164 项通过，其中已包含前述 9 项任务验收测试，不重复计数。贯通用例使用真实 Node 断言执行，经可信采集、SQLite 保存、进度登记、最终结算，再关闭运行器重开日志；测试只执行一次，重开保留相同见证。其余用例包含取消、未知、后续失败、伪造回执、跨任务错绑及事务失败。严格 Clippy、格式检查、原沙箱限制与跨语言调用两项回归、旧子代理日志六项回归均通过。上述测试结果不等于格式、静态检查或线上验收全部完成。

普通 coding 任务自动准备候选、公开工具的默认装配、父子任务自动认领彼此合同，以及通用依赖分析尚未完成。`eve-app` 公开导出 `FrozenNodeAdapter`、`FrozenNodeBinding`、`FrozenNodeTool` 供可信宿主显式组合，但这不等同默认线上入口已经装配。当前切片不证明所有重复验收已根治，也不替代聊天表达、蒸馏采用和自然分条的效果验收。
