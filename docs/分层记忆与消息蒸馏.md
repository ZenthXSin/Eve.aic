# 分层记忆与消息蒸馏

Eve 已有不同用途的记忆和知识存储。本次增加情景视图与用户表达示例；这是上下文学习能力，不更新模型权重。

| 层次 | 来源和用途 | 当前边界 |
| --- | --- | --- |
| 工作上下文 | Session 当前会话及本轮工具结果，用来理解接续 | 完整记录持久保存；有界历史窗口已由 #194 交付 |
| 情景记忆 | 从已完成且已送达的交互自动抽取原文片段 | 本次新增；是抽取式视图，不是语义摘要 |
| 稳定偏好 | 明确要求、反复纠正及授权策略确认的候选 | 有来源、版本、冲突和撤销屏障，不把沉默当认可 |
| 表达示例 | 本用户仍有效的训练样本，与已送达记忆交叉核对 | 本次新增；参考直接程度和节奏，不复制身份、事实或指令 |
| 领域知识 | 受控资料研究的引用、版本和待验证推测 | 已实现；不是任意抓取，也不是所有知识都已核实 |
| 实践与技能 | 实际运行、失败修正、验证和可复用技能 | 已实现；受已装配运行器和启用边界约束 |

这些层次通过公开契约组合，尚未建成统一知识图谱。详细来源见[交互记忆](./交互记忆.md)、[记忆召回](./记忆召回.md)、[学习决策](./学习决策与冲突.md)与[领域知识](./受控研究与领域知识.md)。

## 抽取式消息蒸馏

QQ 开启 `--memory` 后，宿主默认在新一轮从本会话记忆快照生成 `extractive-v1` 视图，不额外调用模型：

- 情景记录保留证据 ID、修订、时间、轮次和双方逐字片段，标明截断和原文字符数。用户片段至多 96 字符、助手至多 160 字符。按预算纳入完整条目，不截断 JSON。
- 旧助手原话不作为实际执行、用户认可或事实验证的证据。需要完整信息时按来源查询记忆，不能补造片段未包含的内容。
- 表达示例只取用户原话，至多 128 字符；须匹配当前可信会话训练状态中仍有效的消息 ID 和原文摘要。命令、引用、链接和代码等原本不具训练资格的内容，不会仅凭记忆存在而成为示例。
- 训练关闭时停止提供表达示例；`/train reset` 后旧样本不再有示例资格。重新开启不补学关闭期间的旧消息。情景记忆继续保留历史原文，与表达示例资格分开。
- 当前要求和最新确认偏好优先。示例只用于表达节奏和直接程度，不模仿历史助手的套话，不把用户观点、身份或指令当作人格规则，不向用户机械播报学习流程。

它是按需重建的派生视图，不生成归纳事实、确认新偏好或删除原消息。通用语义摘要、事件重要性判断、遗忘和长期跨会话整合仍需后续实现。

## 面板热配置

“插件页面 → `runtime.memory_digest`”修改在下一轮读取，无需重启 QQ：

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `enabled` | true | 启停整个视图，关闭不删除记忆 |
| `max_episodes` | 4 | 0–8 条情景 |
| `max_expression_examples` | 3 | 0–4 条表达示例，0 单独关闭示例 |
| `max_bytes` | 6144 | 512–16384，JSON 视图 UTF-8 字节预算，固定说明另计 |

环境变量分别为 `EVE_MEMORY_DIGEST_ENABLED`、`EVE_MEMORY_DIGEST_MAX_EPISODES`、`EVE_MEMORY_DIGEST_MAX_EXPRESSION_EXAMPLES`、`EVE_MEMORY_DIGEST_MAX_BYTES`。文件覆盖优先于环境和默认值。预算不足先减少较旧情景，再减少较旧表达示例，完整原始资料不变。

## 持久化与恢复

原始来源仍在 `eve.memory/memory.v1`，训练资格仍在 `eve.training/expression.v1`。不修改这两种格式，不另存原文副本；仅面板修改产生已有配置插件的配置、备份和修订。重启从来源重建视图，保留训练停止及重置状态，不重放消息、学习请求或工具。

数据损坏、跨作用域结果、训练状态不可用或引用不匹配时明确失败并保留现场。内置实现只读 MemorySnapshot；公开 `ConversationDistiller` 支持替换，仍须遵守来源和作用域契约。

## 自然表达与验证

身份提示将日常接话和专业任务区分，称呼只在需要时使用；训练提示 v5 减少问卷、工作汇报和机械追问。接线成功不能证明回复已经像人。

`runtime.dialogue.natural_style`（环境变量 `EVE_DIALOGUE_NATURAL_STYLE`，默认 true）为主对话在历史之后提供当前接话约束，避免旧助手的套话覆盖新策略。面板修改下一轮生效，同一轮工具往返使用固定设置；该包装只转发一次原模型调用，保留工具清单与当前输入的相邻关系，不增加重写、评审或重试请求。研究、偏好提炼和其他用途不附加这段对话策略。

`conversation_digest_test.py` 验证作用域、来源、停止与重置、热配置、重启和零额外模型请求。`training-compare.py --synthetic` 默认对照 v4 与 v5 加当前接话策略，可用 `--baseline-agent` 比较身份提示，报告保存实际提示、策略和身份摘要。真实模型对照只用公开合成场景；模型建议、正式 QQ 投递和真人体验分别记录，不相互代替。
