# 工具代码编排与插件热更新

`run_tool_code` 将多步工具调用和结果处理放在一次模型工具调用中。参考 [Codex Code Mode 的工具编排契约](https://github.com/openai/codex/blob/main/codex-rs/code-mode-protocol/src/description.rs)，Eve 复用现有 OS 沙箱与工具授权边界，不引入第二套凭据或权限系统。

```json
{
  "tools": ["read_file"],
  "code": "const results = await Promise.all(args.paths.map(path => tools.read_file({path}))); text(results.map(x => ({path:x.path,sha256:x.sha256})));",
  "arguments": {"paths": ["Cargo.toml", "AGENT.md"]}
}
```

`tools.<name>(arguments)` 返回 Promise，`args` 是本次输入，`text(value)` 选择回传内容。独立调用可以使用 `Promise.all`；宿主按至多8个叶子分组，仅当整组工具明确声明 `ParallelSafe` 时并发，否则顺序执行。源码文件工具目前仍遵循工作区串行契约。写入失败后不启动后面的写入，已经启动的并发调用各自结算；没有已验证结果的调用记录为未知，禁止重放。

每个叶子继承真实会话、原话审核上下文、动态撤权、取消和期限，单独消耗同一原子工具预算并记录操作证据。脚本声明工具名不授予权限，任务、管理、自升级和脚本入口不能成为叶子。代码至多32KiB、回传至多32KiB/64项，单次运行至多30秒；中间响应仍有1MiB协议上限。这里使用沙箱中的 Node JavaScript，不是 Codex 的 V8 宿主；文件、网络、子进程等限制由既有 OS 沙箱执行。缺少隔离器时拒绝运行。

相同代码和工具声明复用同一不可变版本，变化的数据放入 `arguments`，不会每次生成新版本。复用已有版本/活动状态时不重写整本账本。返回包含选出的结果、调用编号、版本与逐项证据；`list_script_plugins` 可按调用编号检查完整持久回执。重启不重放调用，损坏账本保留并拒绝使用。现有256版本容量仍生效，不自动删除用户插件或历史记录；编排代码应复用而不是每次内插输入文本。

`update_script_plugin` 一次完成保存候选、核对依赖和权限、原子启用。参数是与 `save_script_plugin` 相同的 `spec`，状态 schema 变化时额外提供显式 `migration`。Python/JavaScript 无需编译，Rust 只在隔离器中编译当前插件并按已有内容缓存，不重编宿主。失败保持旧活动版本；已保存但未启用的候选可检查，不冒充更新成功。返回的 `previous` 可通过 `activate_script_plugin` 回退。

正在运行的调用和插件依赖图继续绑定原有不可变版本。更新子插件不会擅自改变父插件依赖；要采用新版本，只需发布引用新摘要的父插件，其他插件不变。不同版本保留各自状态，未知外部效果阻止不安全的状态复制，回退不重放工具。内置 Rust 宿主插件的代码变更仍走完整候选升级，这个入口用于已支持的脚本插件。

验收使用实际 Node/Python 沙箱进程，覆盖并行执行、共享预算、独立调用身份、输出选择、失败后停止、未声明工具拒绝、版本复用、旧句柄隔离、无关插件不变、重启恢复和显式回退。
