# 工具提示去重

本轮真正可调用的工具仍全部放在模型请求的 `tools` 中，保留完整说明、参数 schema 和并发约束。系统提示开头及固定宿主资料只列出真实工具名称，并保留当前可用性、授权和真实回执说明。历史之后的精简工具复核继续覆盖旧助手关于“没有工具”的过期自述。

2026-11-08 的真实冻结主会话包含 93 个工具。此前相同 `name + description` 目录在 runtime 系统提示、`CapabilitiesContext` 的 pinned 资料各出现一次，实际 `tools` 又携带完整定义。两份目录各有 57,273 字节；其中名称目录仅需 2,593 字节。研究入口与运行器资料继续保留，未修改人格或任何记忆数据。

按 runtime 的保守 JSON 估算，在同一快照仅去除这两份重复说明后，固定宿主消息从 129,364 字节 / 75,330 估算 token 降为 19,261 字节 / 9,446，节省 110,103 字节 / 65,884 估算 token。该值包含外层 JSON 转义变化及 pinned 提示补充文字；它不是提供方计费 token，也不是对上线每轮大小的承诺。真实 `tools` 的完整说明和 schema 不参与此次缩减。

相关回归覆盖：runtime 请求布局仍可发现所有注册工具，实际请求完整定义保持；dialogue-tools 能力资料在长说明下保持小目录，并保留研究入口、群历史能力和原始完整工具定义。
