# 成员命令网络

成员命令默认在 bubblewrap 独立网络内运行，不共享宿主环回；隔离不可用时不回退宿主。主人和管理员的宿主命令权限不受影响。

Linux root 部署可用 `EVE_MEMBER_NETWORK_LAUNCHER` 指定可信启动器，示例为 `scripts/member-network.py`。启动器每次命令创建独立网络命名空间与点对点 veth，公网下载可用，宿主地址、内网、链路本地和云元数据端点均被防火墙拒绝。不同成员不共享环回或连接监听。成员不继承宿主代理地址或代理凭据。

先以 root 运行 `scripts/member-network-setup.py`，再把启动器的绝对路径放入 Eve 服务环境。示例规则使用 nft 专属 `eve_members` 表与 Docker `DOCKER-USER` 中仅匹配 `eve-m+` 的放行规则，不清空既有防火墙；使用 10.254.0.0/16 地址池，部署前应确认不与宿主路由重叠。应在系统启动和 Docker 启动后重新装配规则。

地址分配在 `/run/eve-members` 锁内进行，记录进程启动身份；正常退出清理命名空间，异常强杀残留在下次申请时按进程身份清理。初始化失败拒绝执行，不回退宿主网络。验收脚本 `scripts/test-member-network.py` 实测并发公网 HTTPS、宿主与内网拒绝和清理；测试服务器仅返回合成标记。
