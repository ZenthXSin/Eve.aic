# EVE.AIC 第一版架构设计

## 1. 总体分层

```text
Plugin API
    ↓
Kernel
    ↓
Runtime Host
    ↓
Built-in Plugins
```

## 2. Plugin API

`plugin-api` 只定义插件可以看到的稳定契约：

- Plugin
- PluginManifest
- PluginContext
- PluginDependency
- ServiceId
- EventId
- StateHandle
- TaskHandle
- Permission
- PluginError

插件不应依赖 `kernel` 的内部结构。

## 3. Kernel

`kernel` 负责：

- Runtime 生命周期
- Plugin Registry
- 依赖图和启动顺序
- 插件状态机
- Context 创建
- Service Registry
- Event Bus
- State Store
- Task Manager
- Permission Checker
- 资源清理
- 错误和诊断

## 4. Plugin 生命周期

```text
Registered
    ↓
WaitingDependencies
    ↓
Starting
    ↓
Active
    ↓
Stopping
    ↓
Stopped
```

启动失败进入 `Failed`。插件是否启用是配置，不单独作为生命周期状态。

## 5. Context 边界

插件只能通过 `PluginContext` 使用 Runtime 能力：

```text
PluginContext
├── RuntimeHandle
├── EventBusHandle
├── ServiceRegistryHandle
├── StateHandle
├── TaskManagerHandle
├── Logger
└── PermissionSet
```

禁止插件获取 Runtime 内部可变结构。

## 6. 第一版插件形式

第一版采用：

```text
Rust
单进程
静态编译
可信插件
Box<dyn Plugin>
```

暂不加载任意 Rust 动态库。未来的不可信或外部插件使用 WASM 或独立进程协议。
