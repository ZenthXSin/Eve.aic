# Eve 聊天习惯与好奇心

QQ 的通知、新打开的会话和已经读取的历史页可提供风格观察。电话插件只用真实返回的消息，不额外巡群、下载图片或调用模型，不从搜索结果、代码、截断预览或 Eve 自己的回复计票。群里需要至少两人提供重复例子；私聊也要有多条不同消息。当前会话最新一条入站屏幕可以附带 `chatStyle`，旧界面不用更改。

观察有容量和时效上限。每个会话各算各的，缩写、消息开头、句尾和追加的一条都可以成为线索，最多给四个选择。不为此另存整段聊天或图片。当前版本学习窗口在手机 worker 内存中；worker 重启后从正常读到的消息重新积累，不主动补读旧群。

当事人在自己的私聊中、或主人在群里，可以明确说少用某个词；对方随后允许可以撤销。能从已读的送达回执唯一定位上一句时，也处理“别老这么说”。这不是授权、强制话术或对身份的更改。先看具体场面和关系，熟人的亲近和打趣不套给陌生人。

Eve 在已有的唤醒机会中，没急事、这次还没看过群时，优先挑一个常聊且未静音的群看最新一屏。可接眼下的新鲜事、问没懂的梗、问惦记的后续；没有新内容就跳过，不反复翻一屏。接现场不必等被点名，另开话题仍按原有夜间限制、冷却、未确认送达和主动搭话规则。不增加定时群发、唤醒频率或常驻扫描。
