# 表达学习验收（2026-10-17）

本次验证消息抽取、训练资格与当前接话策略，区分软件接线、真实模型合成对照与真人体验。

## 宿主验证

- `ConversationDistiller` 从不可变记忆快照抽取逐字片段，校验来源、修订与预算，不调用模型，不改变原始记录。
- QQ 进程测试覆盖跨用户隔离、原文及消息 ID 匹配、训练停止和重置、面板热配置、重启恢复，以及当前表达策略开关；没有额外模型请求或正式 QQ 连接。
- 当前表达约束位于历史之后，工具能力清单仍紧邻当前用户输入；策略不持久化为聊天记录，不进入研究、偏好提炼等其他用途。
- 记忆、召回、偏好提炼、自主确认、对话工具、语义召回及 Web 插件页回归通过。格式及严格 Clippy 检查通过。

## 真实模型合成对照

主模型使用操作者指定的 `ai.铁壳锈世纪.com` / `deepseek-v4.1-flash`，Chat、reasoning none。仅使用公开新写场景，不读取真实 QQ 记录，不调用工具或发送 QQ 消息。每个场景生成旧、新各一条回复；评审仅收到相同上下文及回复，不收到策略标签。身份提示、训练提示和当前接话策略都发生变化，因此结果不归因于单一因素，也不证明记忆装配或长期学习质量。

最后两组分别用 36、18 次模型请求，其中包括生成和评审；前两组也各 36 次，失败结果不覆盖。场景见 `connectors/qqbot/test/fixtures/training-public-cases.json` 和 `conversation-public-holdout.json`。

独立场景中，用户分享游戏通关后，新版仍追问“哪个游戏、哪一关”两个信息。这是尚未完全消除的复合追问，不能只靠问号计数宣布通过。模型自评也不能代替用户判断“像不像人”。本轮不宣称完整 AGI、模型权重训练、通用语义消息蒸馏或正式长期体验通过。
