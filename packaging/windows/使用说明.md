# Eve Windows 便携版

选择相符的 Windows 包：Windows 10/11 **x64**，或 Windows 11 **ARM64**。完整解压到可写目录，例如 `D:\Eve`，不要在 ZIP 内运行。x64 启动器使用系统 PowerShell，ARM64 使用随包原生 Node。无需安装 Rust、Node 或前端工具；Web 页面内嵌在 exe 中，QQ 桥接及 Node 运行时已随包提供。

1. 双击 **Start-Eve.cmd**，按提示输入主模型 API 密钥和 QQ App Secret。AppID 示例为 `102075770`，默认正式 QQ 环境。
2. 看到 `EVE_QQBOT_READY` 和 `EVE_WEB_READY` 后，双击 **Open-Panel.cmd**。复制窗口中的独立面板令牌，在浏览器登录框粘贴。默认地址 `http://127.0.0.1:8765`。
3. 向机器人私聊或在群里 @ 发送文字。启动窗口保持打开；退出时在启动窗口按 Ctrl+C，等待收尾完成。

首次配置保存为 `config.json`。它包含密钥，仅在自己的电脑保存，不上传、不公开分享。没有嵌入任何用户密钥或历史交流数据。模型地址、名称、协议、功能开关可编辑该 JSON；已有文件损坏时启动报错，不覆盖。模板 `config.example.json` 不含密钥。

默认主模型为 deepseek-v4.1-flash / Chat。要改用 OpenRouter 主模型，设置 `model.base_url` 为 `https://openrouter.ai/api`，`model.name` 为你有权访问的模型 ID，`model.api_key` 为对应密钥，`model.protocol` 为 `chat`。不根据模型名称自动选择协议。

要启用 OpenRouter 原生 TypeSafe / Jev 判断，将 `jev.enabled` 改为 `true`；下一次启动会提示填写独立 Jev 密钥，也可编辑 `jev.api_key`。默认已填入 `https://openrouter.ai/api` 和 `typesafe/jev-1.13`；主模型密钥仍单独配置。未启用时采用原有消息规则，Jev 不会隐式开启。

QQ 启动默认开启记忆、自主偏好学习、历史召回、分段、认知反思和训练统计。功能开关位于 `features`；自主学习也会开启分段。面板包含会话、任务、判断诊断、认知目标、记忆偏好和学习候选视图。正式 QQ 需开放平台已发布、群可用；程序就绪不等于已验证平台收发。

`data\qq` 保存 QQ 状态，`data\console` 保存终端对话状态；每次启动沿用同目录。保持状态目录和 AGENT.md，升级前退出并备份 `config.json`、`data` 和自定义 `AGENT.md`，再将它们复制到新版目录。不要同时打开两个指向同一状态目录的实例。坏状态会拒绝启动，不能通过删除文件“修复”；恢复不补发旧消息、不重放旧工具。

**Start-Console.cmd** 可运行独立终端聊天，不连接 QQ。`eve-cognition.exe`、`eve-memory.exe` 和 `eve-message-evaluate.exe` 是附带命令行工具，使用 `--help` 查看。面板目前随 QQ 宿主运行，不提供独立离线面板进程。

面板占用端口时可修改 `web.listen`（只支持本机 `127.0.0.1`）。双击 Open-Panel.cmd 才会显示面板令牌，它不在 URL 中；勿分享窗口截图。启动错误会保留在窗口中；设置密钥只对当前 Eve 子进程生效，不修改系统环境变量。

`build-info.json` 记录源码版本、构建目标和逐文件 SHA-256；外层 `SHA256SUMS.txt` 校验发行 ZIP。程序未进行代码签名，下载来源应与提供的构建记录和校验值相符。
