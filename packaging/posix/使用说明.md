# Eve Linux / macOS 便携版

选择与系统及 CPU 相符的包，完整解压到可写目录。Linux 包使用 Ubuntu 24.04 原生构建，需相容的 glibc 环境；macOS 需要 macOS 11 或更新版本。x64 为 Intel/AMD，arm64 为 Apple Silicon 或 ARM64。无需安装 Rust、Node 或前端工具。

macOS 双击 **Start-Eve.command**；Linux 在终端执行 **./Start-Eve.sh**。首次提示输入主模型 API 密钥和 QQ App Secret（输入不显示），并在本机生成 `config.json` 和独立面板令牌。模板 AppID 为 `102075770`，默认正式环境；模型默认为 deepseek-v4.1-flash / Chat，按实际接口编辑配置。

看到 `EVE_QQBOT_READY` / `EVE_WEB_READY` 后，打开 **Open-Panel.command**（macOS）或执行 **./Open-Panel.sh**（Linux）。脚本显示地址与令牌并尝试打开浏览器，将令牌粘贴到登录框。没有桌面浏览器时手动打开 `http://127.0.0.1:8765`。面板随 QQ 宿主运行，启动窗口需保持打开；Ctrl+C 等待收尾后退出。

默认开启记忆、持续自主偏好学习、历史召回、自然段投递、认知反思及训练统计，开关在 `features`。要启用 OpenRouter 原生 TypeSafe / Jev，将 `jev.enabled` 改为 `true`，下次启动输入独立密钥；主模型密钥单独配置。终端聊天使用 Start-Console，不连接 QQ。

`config.json` 含密钥，仅保存在本机；`data/qq` 与 `data/console` 分开保存状态。发行包不含任何真实密钥或历史交流。默认后台每六小时检查最新稳定版，下载并校验后下次启动切换；用户配置、数据和自定义 AGENT.md 保留在原目录，更新不会强制退出聊天。Linux 用 `./Update-Eve.sh`，macOS 用 `./Update-Eve.command` 立即检查；加 `--status` 查看状态、`--rollback` 安排回退。配置 `updates.enabled: false` 可关闭自动更新；下载失败继续旧版。

旧包第一次升级到含更新器的新版仍需退出、备份用户文件并复制到新目录，此后使用原目录 Start-Eve / Start-Console。程序版本在 `.eve-updates`，不要清除正在使用的版本或索引。不要同时打开使用相同状态的实例。坏配置/状态拒绝启动，恢复不补发旧消息、不重放工具。面板管理范围见随项目文档。

`build-info.json` 记录源码提交、目标与逐文件散列；Release 的 `SHA256SUMS.txt` 校验各发行包。macOS 二进制尚未签名或公证，系统阻止运行时需由你在系统设置中允许该下载的程序。Linux 不适用于 Alpine / musl，或缺少相容 glibc 的系统。
