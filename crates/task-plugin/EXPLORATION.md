# 自由探索会话的持久化

探索和普通任务共享队列、身份、授权期限、工具用量和执行检查点。宿主通过 `create_exploration` 创建会话，原子冻结 `execution.kind = exploration`、用户原话和原授权期限；接口不接收成功合同。同一来源重试返回原会话，不能把普通任务改成探索或反过来。

旧数据缺少 `kind` 时仍表示普通任务，重新编码省略默认值，避免改变旧记录的摘要。冷正文目录和调度、投递、进度目录都保存执行模式；完整正文核对时模式必须一致。坏状态拒绝打开并保留原文，不清空或按新任务恢复。

写入探索后，旧版二进制会因不认识执行模式而拒绝读取，不能把新状态降级成普通任务。发布须保存上线前的完整索引及其冷正文；需要回滚时保留新探索状态，使用兼容版本读取或明确恢复完整的部署前快照，不能只替换一半文件。

探索的所有终态在独立经历保存前都保留完整正文，不参与容量淘汰。宿主先把有界真实经历写入独立存储，再调用 `acknowledge_exploration`，最后标记本次回顾已收取。确认使用完整身份与原终态时间，只记录首次 `exploration_acknowledged_at_ms`，重试不改原结局。确认之前崩溃只补存经历或确认，不能重做工具。旧探索数据没有此字段时按未确认保留；普通任务省略字段，原容量语义不变。账本满且全部探索尚未确认时拒绝新增会话，避免用新活动覆盖尚未保存的经历。

探索用 `SessionEnded` 表示会话停止，不计为目标成功。可以没有工具、没有发现或没有小结，保留兴趣变化和暂时没看完的内容；不会调用目标验收、完成修复或成功策略学习。结算只核对同一身份的有效检查点、配对回执和实际用量，非空小结必须与已保存的输出一致。长小结在目录结果中注明截断，原输出仍在完整检查点中。

`session_end_reason` 保存宿主可观察的自然停止、工具预算耗尽、原期限到期或自动恢复次数耗尽。已有最终输出的进程重启直接结算，不能重新请求模型，也不会因重启晚于期限而改写原自然停止。没有最终输出但已耗尽资源的安全检查点可以直接停止，不要求继续完成旧方向。尚未到资源边界的安全检查点沿用原接续时点和原预算。

待执行批次或结果未知的工具回执恢复为 `Interrupted`，原检查点、真实用量、原期限和未知原因全部保留，不重放。模型或工具的已确认失败保存 `Failed`，用户取消仍优先；这些结局均不会触发自动任务完成、进度或被动通知。以后是否分享经历、继续看看或换个兴趣，由 Eve 的自主选择和既有发言机制决定。
