# 分层历史请求副本

可信组合层可通过 `LlmHost::with_history_context_planner` 装配 `HistoryContextPlanner`。运行时完成上下文授权与原历史校验后，向加载器提供可信范围、当前输入、完整原历史。加载器返回原始 `history_turns` 的零基索引和工作集，不能替换原消息，也不能授予身份、范围或工具权限。

`Some(plan)` 只接受严格递增、不重复、在界内的完整轮次索引。轮数与序列化总字节沿本轮 `HistoryWindow` 上限；工具调用和结果作为完整原轮次保留。工作集正文合计最多 16 KiB，以明确非授权资料进入上下文。原日志、会话记录、当前输入、检查点和本轮工具回执不因计划选择而删除。

审核使用的最近六条用户原话在计划选择前独立提取。采用分层计划时，六条原话合计超过 64 KiB 直接拒绝，不截断、不替换为摘要；本轮新纠正、撤销也更新独立审核原话。工作集和历史摘要不进入这条授权通道。

`None` 明确沿用原有上下文路径；未装配加载器也保持原行为。群观察组合层可以返回 `None` 保留既定锚点策略。加载器错误或 panic 停止本轮，不能发送缺少工作集的半份上下文。相关性模型失败时的确定性退路由加载器实现；运行时最多等待 10 秒，并受更早的调用期限及通道取消约束。

选取非连续子序列后，旧摘要的 `covered_turns` 不能再表示原完整历史的前缀。运行时因此不读取该次历史的持久摘要缓存，后续压缩使用 `scope=None` 生成临时摘要，不覆盖原历史摘要。当前输入与完整请求固定前缀仍计入组合层配置的总上下文上限；设置为 200,000 时不能通过缩短历史绕过它。

`tests/history_planner.rs` 使用 100、300、1000 轮历史，每轮包含 8 KiB 大工具回执，验证远期原轮次与最近轮次同时保留，实际请求字节曲线为约 28.5 KiB，未随完整历史线性增长。测试同时覆盖坏索引、期限/取消、失败关闭、审核撤销原话、工作集边界、原摘要缓存隔离和固定前缀总额。相关性、跨范围召回、原文引用工具的授权由组合层另行验收。
