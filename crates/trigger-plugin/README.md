# 条件触发通知与恢复

执行结果进入 `Pending` 后，上层先只读审视事实并由 Eve 决定是否说话。选择说话时，通道准备写出正文才调用 `delivery_for_run(id, run, Pending, Sending)`，实际回执仍绑定该周期。

选择保持安静时调用 `silence_for_run(owner, id, run)`，在同一账本事务内核对完整身份、实际周期、执行终态及 `Pending`，记录独立的 `Silenced`。重复结算同一静默周期可幂等；`Sending`、`Unknown` 和其他已结算状态不能改成静默。普通投递接口不能用 `Silenced` 伪造运输结果。替换实现未提供此能力时默认返回 `Unavailable`。

`Completed` 且通知为 `Silenced` 的周期允许 `rearm`，仍受原到期时间和总执行次数约束。失败或中断的执行不因此获得重试权限，未知投递也不能重启新周期。上层周期扫描须将 `Silenced` 纳入可重新设定条件的状态，重新设定条件后旧周期的决定不能修改新一轮结果。

首次记录 `Silenced` 将账本升级为版本 4，此后提交和恢复均保留版本 4。旧版本 1、2 仍迁移至版本 3，版本 3 的普通写入保持原格式；旧格式内出现 `Silenced` 会拒绝打开并保留原字节。重启仍把运行中的执行记为中断、发送中的通知记为未知，已保存的静默决定不转换成送达或未知。状态提交确认丢失会关闭实例，重开后只以已持久化结果恢复。
