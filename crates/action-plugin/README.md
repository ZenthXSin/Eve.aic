# 受控行动日志

`ActionPlugin` 通过公开 `StateStore` 接口保存文档行动，`ActionController` 实现
`eve-action-api::ActionJournal`。控制器只交给宿主，不注册为模型或普通插件可发现的服务。
插件按构造时的主体标识绑定日志，状态键为 `document-actions.v1`。

`begin` 在返回前保存 `Executing`。相同行动标识、相同提案仅返回已有记录和
`duplicate: true`，宿主不能再次执行；重送可以改变生成时间，其余字段必须完全相等。
相同标识换输出来源、内容摘要或超时预算会返回 `Conflict`。

`finish` 以单条记录修订执行 CAS。完成回执必须匹配提案中的产物来源、完整字节摘要和
长度。完成或阻塞后的记录不可重写。全局修订随成功保存递增，保存失败不会发布新的
内存快照；终态保存失败时原 `Executing` 记录继续保留，不能把错误当作成功。

重新启动时，所有遗留 `Executing` 先持久化为 `Blocked / Interrupted`，随后才开放
控制器。恢复保存失败则启动失败；不会清空记录或自动重放。外部文件可能已写入而回执
尚未保存，这种情况仍视为不确定的中断，由宿主展示记录供操作者处理。

日志有记录数和字节数上限；达到上限时拒绝新行动，保留旧记录的幂等约束。未知字段、
重复 JSON 键、主体不一致和无效记录会阻止启动，原始状态保持不变。插件停止后控制器
返回 `Unavailable`。这些保证依赖具体 `StateStore` 实现如实报告持久化结果。
