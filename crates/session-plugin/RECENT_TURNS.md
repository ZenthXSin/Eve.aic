# 最近轮次分页

`SessionService::recent_turns` 返回最近的完整轮次，最新在前，每页一至十六轮。`before` 是独占的轮次编号；下一页使用上一页末项编号。新增轮次不会挤入较早页，单页读出的 Pending 不会因随后完成而改变。返回结果包含成功、失败、待处理和中断状态，组合层自行生成有界视图，不能将截取的视图写回原历史。

内置热存储直接复制尾部所需轮次，冷存储直接读取索引对应的本页正文，不再先扫描或复制完整历史。完整会话身份在读取正文之前核对。所请求正文缺失、摘要不符或内容损坏时返回错误并关闭旧句柄，保存原索引和正文；不把错误当空页，不修补或删除历史。

这是只读接口，不改变旧存储格式，也不新增迁移。自定义实现默认通过 `scan_turns` 逐页收集，最多额外保留所需轮数；如果该实现只提供 `snapshot`，旧扫描兼容路径仍有完整快照的开销，应覆盖 `recent_turns` 以使用自己的索引。
