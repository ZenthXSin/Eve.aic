# 主体记忆存储

`SqliteIdleMemory` 实现 `IdleMemoryStore` 和 `AutonomyMemoryStore`。认知、兴趣修订、消费来源、探索经历和会话派发来源独立持久保存，不随后台任务或热关注的容量回收丢失。读取始终匹配完整 `SubjectScope`，存储句柄仅交给可信宿主。

`choice=explore` 无需目标、收益评分、完成合同、已有兴趣或非空线索。可选 `exploration` 仅包含 `cue` 和 `interest_key`；缺字段的旧回顾重编码保持原指纹。关联兴趣可来自历史分页，也可以已经休息或放下。旧 `act` 仍按原目标契约运行。

`record_exploration` 保存 `ExplorationExperience`。工具参数、输出和错误保留实际调用 ID、UTF-8 片段、原字节数、SHA-256 和截断标记；主观感想单独保存。单片段最多 2048 字节，每次经历最多 64 个连续调用，并保留本执行器可观察调用总数、首项偏移和整体截断状态；子代理内部轨迹不在此总数中，资源总用量由任务账本另记。数据可以覆盖长会话末尾而不声称保存了全部轨迹。会话 ID 全局唯一，相同内容重送不更改记录，换内容或换范围均拒绝。确认失败、权限拒绝和未知结果原样保留，未知回执不被重做。

`explorations(scope, before, limit)` 按写入序号倒序分页，`None` 直接读取最近经历，最多 16 条。使用返回的 `next_before` 继续读旧记录，不以毫秒时间戳作为游标。同一毫秒的经历不会互相跳过，后到达的旧时钟记录也有独立序号。翻页期间的新写入由下一次最近页读取。

回顾中的经历正文必须是已保存经历的连续工具子片段，元数据和感想不得替换。纯主观思考或仅未知调用使用 `exploration_reflection`；确认的工具反馈使用 `exploration_experience`。空会话不能伪装成新外部证据提高兴趣强度；已有兴趣可以自主休息或放下，减少强度不要求新外界证据，旧消费来源仍保留。

`reserve_exploration_source` 绑定已提交的 Explore 回顾和宿主关注 ID。同回顾同关注可幂等重试，同回顾不能派发另一个关注，同一关注也不能挪给别的回顾。新的回顾仍可再次好奇，不按兴趣键永久去重。宿主先保存经历，再调用任务账本的 `acknowledge_exploration`，最后登记任务已协调；确认时间至少为原终态时间，保存失败时只补存经历，不重新执行工具。

数据库版本 3 增加 `exploration_experiences` 和 `exploration_sources`。打开版本 1 或 2 时，先核对旧认知、兴趣及历史索引、原回顾指纹、消费与授权回执，再在一个事务内升级。旧 JSON 不重编码，迁移中断回滚，损坏数据和不支持的版本保留原文件并报错。必需标记已存在却缺数据库时不新建空库；写入无法确认后关闭当前句柄，重新打开核对真实存储。
